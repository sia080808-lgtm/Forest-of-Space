# APK0.6.15 · 햇살 바위 위 휴식, 바위·바위틈 관통 수정

2026-11-17. 사용자 제보: (1) 햇살 바위에서 쉴 때 바위 위가 아니라 근처에서 쉼, (2) 바위틈 근처를 지나갈 때 오브젝트를 관통.

- 원인: 바위 그림은 기준점 위쪽(y −0.066~0)에 그려지는데 충돌 타원은 기준점 중심 ±0.042였다. 그림 윗부분은 통과되고 그림 없는 아래 바닥은 막혔다. 햇살 바위 휴식 영역은 바위 아래 바닥(y+0.074)이었다.
- 충돌: 바위·바위틈 발자국을 그림에 맞춤(`spatial.js` STONE). 길찾기는 정확한 발자국을 먼저 쓰고, 길이 없을 때만 0.6.14까지의 발자국으로 다시 찾는다. 기존 저장 배치·쉼터 확장 입구·경로 검증이 새로 거부되지 않는다. 돌 안에 저장된 친구는 밖으로만 나갈 수 있다.
- 햇살 바위: 휴식 영역을 바위 윗면(`Space.rockTop`)으로 이동. 바위 윗면을 시작·도착점으로 하는 경로만 바위를 넘을 수 있어 지나가는 친구는 여전히 돌아간다. 바위 위·오르는 중인 친구는 바위 가림 재그리기에서 제외해 바위 위에 보인다. 회복 수치·용량·안전 조건 불변.
- 0.6.14(엘리시) 위에 적용. 저장 스키마·SRS-2.19-objects 규칙 식별자 불변. 버전 0.6.15 / versionCode 32.

검증: 자동 210/210, DOM UI PASS. `tests/forest/stone-footprint.test.cjs`(5) 추가. `tools/stone-review.cjs`: 돌 핵심부 통과 경로 바위틈 114→0/600, 햇살 바위 154→0/573(수정 전 코드 대비), 리들리·엘레판 14틱 내 바위 위 도착·휴식·하강, 렌더 상태 불변. 기존 테스트 2건은 의도 유지 조정(바위 이동에 맞춘 차단 배치 좌표, 대기 친구가 문 앞에서 기다리도록 명시). Android 실기기·WebView 화면 미검증.
