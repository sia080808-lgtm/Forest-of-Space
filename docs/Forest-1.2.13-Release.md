# APK1.2.13 · 쉼터를 옮기면 "교감·물 출처 기록을 확인해 주세요"로 막히던 문제, 쉼터·샘터 둘레에 남던 종이 바닥

2026-11-22. 사용자 제보: "쉼터도 꾸미기에서 옮기는 기능으로 수정필요함. 그리고 쉼터 옮길 때 교감, 물 수정 확인 필요하면서 안되는 거임?"

- **원인(`shelter.js` `build`):** 친구 둘이 함께 하는 일(엘레판이 잎을 넓혀 그늘을 만들어 주기, 슈퍼범 물 나눔)은 시작할 때의 배치 번호를 기억하고, 저장 검사는 그 번호가 지금 배치와 같은지 본다. 이끼·바위 같은 사물을 옮길 때는 이 일들을 먼저 끝내는데, 쉼터를 옮기거나 좌우로 뒤집거나 보관하거나 꺼낼 때는 끝내지 않고 배치 번호만 올렸다. 그래서 그런 일이 진행 중일 때 쉼터를 옮기면 저장 검사가 "교감·물 출처 기록을 확인해 주세요"로 거절했고 쉼터가 옮겨지지 않았다(엔진 재현: 엘레판 그늘 진행 중 쉼터 옮기기 5번 모두 거절).
- **수정:** 쉼터를 바꿀 때도 다른 사물처럼 진행 중인 함께 하는 일과 친구들의 할 일을 먼저 끝낸다. 친구들은 다음 초에 새 배치에서 다시 고른다.
- **쉼터·샘터 둘레에 남던 종이 바닥(누끼, `tools/cut-shelter-art.py`·`tools/cut-spring-art.py`, 사용자 "쉼터 끝부분 이거 남음. 경계선 확실하게 누끼 … 다른 오브젝트들도 마찬가지"):** 쉼터 그림과 샘터 돌 그림은 정원 그림에서 바닥째 잘라 온 것이라, 숲 바닥 위에서는 티가 안 났지만 호숫가·눈 위에서는 둘레에 옅은 종이 바닥(과 그림의 다른 조각)이 네모·둥근 덩어리로 보였다. 원본 픽셀은 그대로 두고, 쉼터는 아치와 굴 안, 샘터는 돌과 물 고이는 곳을 남기고 종이 바닥 색만 부드럽게 투명하게 했다. 붙어 있지 않은 작은 조각은 뺐다. 네 계절 그림 모두 같다. 샘터는 이제 따로 딴 그림(`spring-art.png`)을 그린다(없으면 예전처럼). 다른 사물(이끼·햇살 바위·바위틈·잎 그늘·낙엽 자리)은 물색 위에 올려 확인해 보니 이미 깔끔하게 따져 있어 그대로 두었다. 숲 바닥 위에서는 전과 똑같이 보인다. 화면 `docs/qa-1.2.13`.
- 저장 스키마·규칙 식별자 불변. 버전 1.2.13 / versionCode 99.

검증: `storage` 1.2.13 검사(엘레판 그늘 진행 중 쉼터 옮기기·뒤집기가 저장 검사를 통과; 고치기 전 코드는 실패), `storage`·`shelter-flip`·`shelter`·`social`·`package`·`render`·`season-landscape`·`inspection` 통과, UI PASS, 실제 scene.js 렌더로 쉼터(호숫가)·샘터(여름·겨울) 전후 비교. 전체는 CI. Android 실기기 미검증.
