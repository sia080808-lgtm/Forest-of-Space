# 넓이 인게임 적용 — 0.6.2

기준: 통합 SRS v2.12, S04.04 / S04.14 / S04.15, D03.11 및 사용자 승인 넓이 집기 시안. 이번 문서는 해당 범위의 구현 추가 기록이며 통합 PDF 전체 개정을 대신하지 않는다.

## 외형과 동작

- 넓이 전용 몸통, 짧은 좌우 발, 안쪽 잎, 고정 뒤쪽 잎, 앞쪽 후드를 사용한다. 팔을 생성하지 않는다.
- 몸통은 항상 온전한 한 레이어이며 발 뿌리는 몸통 뒤에 겹친다.
- 대기, 걷기/느린 걸음/달리기, 집기/버둥, 착지, 잠자기/기상, 잎 정돈은 같은 파츠로 표현한다.
- 잠자기는 감은 눈을 유지한다. 잎 정돈은 팔 대신 잎의 작은 기울임으로 표현한다.
- 기본폼은 승인된 분리 파츠를 사용하며 최근 생성한 상황표를 잘라 교체하지 않는다.
- 앞쪽 후드의 오른쪽 부분만 펼친다. 뿌리와 뒤쪽 잎은 고정한다. 연속 텍스처를 21단계로 미리 계산하며 기본 스케일을 늘리지 않는다.

## 그늘과 통과

- 기존 몸 중심 원형 그늘을 후드 아래 앞으로 치우친 타원 영역으로 변경한다. 빛과 강수 가로채기 모두 동일한 판정을 사용한다. 차광 중첩 상한 70%, 기존 물 보존 계약을 유지한다.
- 잎의 북쪽 경계를 동적 장애물로 취급하여 이동 경로와 놓기 판정에 함께 적용한다. 아래쪽 빈자리에는 진입할 수 있다. 몸체끼리의 충돌은 기존 GU 판정을 따른다.
- 펼친 앞쪽 후드는 모든 캐릭터를 그린 다음 전경에 그린다. 넓이는 펼친 동안 방향을 뒤집지 않는다.
- 넓이는 이동 전에 접힘을 완료한다. 위험/집기/배치/재실행은 관련 그늘 상태를 해제한다.
- 회복 위험이 없는 휴식 행동은 가까운 넓이의 유효한 빈자리를 선택할 수 있다. 그늘에서 샘물 급수나 쉼터 영양을 생성하지 않는다.

## 접근과 검수

- 친구 목록의 '넓이 맞이하기'로 첫 넓이를 대기 목록에 한 번만 추가한다. 기존 넓이가 있으면 추가하지 않는다. 이번 적용판의 직접 합류 경로이며 전체 방문·정착 시스템 구현 완료를 의미하지 않는다.
- 합류 시 보유 수분 35를 도착 이벤트에 기록한다. 기존 개체의 상태와 물은 변경하지 않는다. 대기 개체는 기존 대기 보존 규칙을 따른다.
- 상세의 '정원에 들이기'는 기존 5개체 제한과 자리 검사를 사용한다.
- 관리자 모드: 리들리/넓이 선택, 생활 모션, 표정, 그늘 펼침, 날씨, 성장 크기와 움직임 줄이기를 확인할 수 있다. 실제 저장과 분리된다.
