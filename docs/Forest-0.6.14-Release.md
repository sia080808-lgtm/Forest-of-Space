# 여백의 숲 v0.6.14 - 엘리시 교체 빌드

## 제품 및 시각
- 봉봉은 플레이어블 종에서 제거되고 '엘리시'(*Platycerium ellisii*)로 대체된다.
- 원본 갈색 몸통/세로 눈은 재사용, 둥근 영양엽 1장+주걱형 생식엽 2장을 독립 SVG 레이어로 합성한다.
- UI 초상화/도감/친구 목록/방문 스토리의 종 표기 변경.
- 기본 이름 '봉봉'은 과거 저장 로드에서 '엘리시'로 정정, 사용자 지정 별명은 보존.

## 능력
- 신규 '잎틈 정원'은 유효한 이끼/바위틈/습도와 건강 상태를 요구한다.
- 활성 시 돌돌이 후속 재방문 후보 확률 30%→45%. 기존 생태/수용량 제한은 준수한다.
- 봉봉의 빗물저장/물나눔 및 EC02 신규 완료 처리는 제거한다. 슈퍼범 별도 캐릭터는 후속 디자인 대상.

## 데이터/검증
- 내부 호환성 키 `bonbon`을 보존해 개체·도감·방문 진행·저장 수분·기존 관계·레벨 손실을 방지한다.
- `SRS-2.19-objects` 저장 규칙, 패키지 ID, Android 서명 인증서는 유지한다.
- 릴리스 버전 0.6.14 / versionCode 31.
- GitHub Actions 성공 및 서명 APK가 확보될 때까지 설치용 빌드 '완료'로 표시하지 않는다.
- 실기기 설치, 픽셀/애니메이션, 입력, 데이터 유지 검사는 별도.

SRS: `docs/Forest-Ellisii-SRS-v2.23-DRAFT.md`, 통합 SRS PDF v2.22가 현재 파일 원본이다.
