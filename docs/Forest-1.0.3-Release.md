# APK1.0.3 · 광합성 동작과 볕 쬐기 동작 구분

2026-11-21. 사용자 요청: "광합성 동작과 볕쬐기 동작 구분시키자" → 시안 → "햇살 바위에서 광합성 할 때는 일반 땅에서 하는 광합성 빛 이펙트보다 원이 더 컸으면".

변경 내용(렌더 전용, 상태·난수·저장 불변):
- **광합성(`rig.js` `photo`, `scene.js`):** 낮에 밖에서 가만히 서 있고, 그 자리에서 광합성이 잘 될 때(밝기 '좋음'·'조금 벗어남') 몸을 해 쪽(왼쪽 위)으로 살짝 기울이고 키를 조금 늘린 채 웃는 눈으로 5초에 한 번 천천히 숨 쉰다. 해 쪽에서 옅은 빛줄기가 내려오고 잎에서 빛 알갱이 9개가 올라간다. 빛이 너무 세거나(강함) 어두우면, 밤·쉼터·바위틈 안이거나 수분·영양이 15 이하면 보이지 않는다(광합성 규칙과 같음).
- **볕 쬐기(`rig.js` `bask`):** 햇살 바위에 볕이 남아 있을 때 바위 위에서 쉬는 친구는 반쯤 앉아 몸을 납작하게 퍼뜨리고 졸린 눈으로 6초에 한 번 깊게 숨 쉰다. 몸 둘레에 따뜻한 주황빛이 돌고 머리 위로 아지랑이가 오른다. 낮에 그 자리에서 광합성도 하면 빛 알갱이가 땅에서보다 1.8배 크다. 밤(추운 날 몸 녹이기)에는 볕 쬐기만 보인다. 잎응애 떨기는 볕 쬐기 중에는 하지 않는다.
- **광합성 판정 나누기(`vitals.js` `photoGrade`):** 기존 광합성 규칙의 밝기 판정을 순수 함수로 떼어 엔진과 화면이 같이 쓴다(규칙 수치는 그대로).
- 저장 스키마·규칙 식별자 불변. 버전 1.0.3 / versionCode 75.

검증: 관련 테스트(`rig` 1.0.3 검사 추가, `render`, `package`, `traits`, `seasons`) 통과, 전체는 CI. 화면 `docs/qa-1.0.3/runtime/photo-game.png`(`tools/photo-bask-review.cjs`, 실제 scene.js 렌더: 땅 광합성 / 바위 낮 / 바위 밤). Android 실기기 미검증.
