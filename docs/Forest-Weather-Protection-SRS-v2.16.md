## S03.10 실제 날씨 노출과 보호 범위

### WX-ENV-01 실제 노출

기존 비 강도 I, 바람 A, 지형 수분 M·고임 W, 뿌리 물 Q를 사용한다. 비는 Q 유입과 지형 젖음의 원인이고, 과습 자체는 R과 지속 시간으로 판정한다. 비 뒤 젖은 땅·기존 응결수도 같은 물 경로를 쓴다. 습도 H만으로 과습 부담을 더하지 않는다.

### WX-ENV-02 빛·비·바람 분리

차광은 한 잎 35%, 겹침은 1-곱(1-차광률), 최대 70%로 유지한다. 비 전환율은 한 유효 우산 50%, 중첩해도 최대 50%다. 바람 차폐는 유효한 한 호스트의 40%만 적용하며 곱셈 중첩하지 않는다. 세 효과를 하나의 shade 값으로 대체하지 않는다.

### WX-ENV-03 영역 계약

빛·비의 유효 바닥 범위는 현재 앞잎의 실제 투영 안이다. 바람은 그 범위 중 바람이 먼저 잎을 통과하는 아래바람 부분만 유효하다. 방향값 wind_dir를 저장하고 기본값은 월드 +x로 이전한다. 날씨 회차의 기존 weather 난수 흐름에서만 갱신하며 렌더·카메라는 방향을 추첨하지 않는다.

### WX-ENV-04 좌석·형태

## S03.11 강수 배분과 물 보존

### WX-WAT-01 기존 예산 유지

WAT-01의 구역당 분당 12×I/100×노출률, 구역별 용량·침투·배수, 샘터 공급은 유지한다. 보호받는 바닥 부분의 강수만 50%를 잎 끝의 연결 구역으로 돌린다. 구역 전체가 우산 안이라는 가정은 금지한다. 고정 공간 분할로 실제 겹친 면적을 적분하며 카메라 배율과 무관하게 계산한다.

### WX-WAT-02 한 번의 분배

외부 강수를 원장에 한 번 기록 → 우산/고정 잎의 가림과 가장자리 전환 → 남은 강수에서 봉봉 수집 → 개체 뿌리 비 유입 → 남은 물의 S 침투·W 고임 → 배수·증발 순서다. 같은 가림 구간의 잎을 중첩 계산하지 않는다. 전환된 물은 도착 구역의 지표 유입이며 새 비·새 수집 예산이 아니다.

### WX-WAT-03 뿌리 비 유입

개체 요청량은 분당 2×I/100×해당 위치의 지형 노출률×(1-비 전환율) 이내다. 해당 위치의 남은 실제 강수 예산과 Q 여유 중 작은 양만 Q에 넣는다. 여러 개체는 예산을 공정 배분한다. 그 뒤 지형 흡수는 실제 남은 S/W를 분당 최대 4만 차감한다. 이미 전환된 예산에 보호율을 또 곱하지 않는다.

### WX-WAT-04 젖은 땅은 그대로

우산을 펼쳐도 기존 S/W/Q·과습 부담은 보존한다. 우산 끝 물은 손님 자리 밖의 실제 연결 구역으로 보내고 구역이 없으면 외부 유출로 기록한다. 이미 고인 물을 삭제하거나, 우산 안이라는 이유로 근권 흡수를 0으로 만들지 않는다. 맑아져도 배수·증발 전까지 젖음이 남는다.

### WX-WAT-05 검산 예

I=60, 노출률=1인 면적 1의 바닥은 분당 7.2물. 전부 보호되면 3.6물은 가장자리로, 3.6물은 남은 수집·뿌리·지형 예산이다. 개체 뿌리의 비 요청 상한은 0.6물/분, 비보호는 1.2물/분이다. 물방울 그림은 이 원장에 새 물을 더하지 않는다.

### 기존 규칙과의 관계

WAT-02의 비 전환 최대 50%와 봉봉의 남은 비 80%·개체 6물/분·V40 제한을 유지한다. 보호 50%를 기존 차광 35%에서 유도하던 구현은 교정 대상이다. 총물 = 이전 총물 + 외부 유입 - 증발·외부 유출·생리 소모를 계속 검증한다.

## S04.07a 과습 누적·회피·회복

### WX-PHY-01 연속 젖음

기존 wetSeconds를 사용한다. 각1초 시작 시점 R≥80인 동안 증가, R<80이면 0으로 초기화한다. 처음 60초는 유예이며 61번째 초부터 +2/60씩 burden에 더한다. R=80은 증가 조건, R=60은 회복 조건이 아니다. R<60이면 매초 -4/60, 60≤R<80이면 기존 부담만 유지한다.

### WX-PHY-02 원인과 행동

뿌리 R≥85가 연속30초면 마른 자리를 선호한다. wet85Seconds는 이 조건의 연속 초를 세고 R<85이면0으로 되돌린다. 부담20부터 축축함을 표현하고, 40부터 자유 놀이·교감 대신 배수 가능한 마른 곳을 찾는다. 60 이상은 긴급 대피다. 안전 경로가 없으면 재탐색하고 가까운 유효 쉼터를 고르며, 플레이어의 수동 조작을 기다리지 않는다.

### WX-PHY-03 회복과 재개

부담40에서 시작한 회복은 부담<30이고 R<60이 될 때 종료한다. 긴급 단계는 부담<40이 되면 해제하되 회복은 계속한다. R85 조기 회피만 발동한 경우 R<60에서 종료한다. 경계 왕복으로 매초 자리·행동을 바꾸지 않는다.

### WX-PHY-04 영향·안전선

부담60 이상이면 기존 GROW 건강 조건에 따라 성장 유효 시간 누적이 멈춘다. 기존 불편 기분 규칙과 회복 우선순위만 사용하며 추가 중복 체력 피해나 영구 사망을 만들지 않는다. 과습이 있다고 해충을 자동 생성하지 않으며 기존 실제 유입·생활 단계 조건을 유지한다.

### WX-PHY-05 우산의 한계

우산은 앞으로 들어오는 비의 일부를 줄여 예방한다. 이미 젖은 땅의 흡수·Q 배수·부담 회복 속도는 그대로다. 손님 부담40 이상 또는 R85 조기 회피 조건이면 우산 아래 장기 체류를 중단하고 마른 쉼터를 안내한다. 엘레판 자신도 과습 면역이 아니다.

### 검산 기준

R80을 고정한120초는 첫60초 유예 후 부담+2, R79.99는 새 증가0이다. R59.99를 고정한60초는 부담-4, R60은0이다. 이는 경계 검산용 고정 입력이며 실제 게임에서는 Q 이동·흡수·배수에 따라 R이 변한다.
## S04.07b 강풍의 잎 손상과 회복

### WX-PHY-06 유효 바람

Aeff=월드 바람×지형 통로 계수×(1-유효 차폐율), 0~100. 기존 기본 쉼터 계수0.2를 유지하며 별도 값이 없는 지형은1이다. 엘레판 손님은 유효한 아래바람 보호에서 차폐율0.4, 나머지는0이다. 호스트는 자신의 펼친 잎으로 자가 차폐 보너스를 받지 않는다.

### WX-PHY-07 노출 시계

gustExposure는0~10초. 각 초 Aeff≥60이면 +1, Aeff<50이면 -2, 50≤Aeff<60이면 유지한다. 10초를 채우기 전에는 손상0, 채운 다음 초부터 손상을 계산한다. 순간적으로 경계를 오가거나 집었다 놓아서 유예를 무한 재발급하지 않는다.

### WX-PHY-08 피해식

Aeff≥60이고 초 시작 gustExposure=10이면 손상 속도는 분당 1+3×clamp((Aeff-60)/40,0,1)이다. 최대4/분, 매초1/60 적용. 환경+해충이 같은 잎 손상 값을 올리는 합계는4/분 이하로 제한하며 ECO-05의 해충 자체 추가 부담2/분 상한도 유지한다. 다른 상태에 피해를 중복 전가하지 않는다.

### WX-PHY-09 회복과 표시

현재 손상이 생기면 잎 끝 미세 접힘·채도 변화로 알리고, 손상10 이상은 돌봄 선호, 30 이상은 기존 성장 중단·회복 우선이다. 손상30에서 시작한 회복은20 미만까지 유지하고 다른 회복 조건도 함께 확인한다. 새 피해가 없는 안전한 편안한 휴식에서 -1/분, CARE 안전 돌봄은 기존 -1/분이다. 피해와 회복을 같은 초에 상쇄해 피해를 숨기지 않는다. 파츠·콜라이더를 잘라 손상을 표현하지 않는다.

### WX-PHY-10 검산과 한계

Aeff75를 강제로70초 유지하면 유예10초 뒤60초 동안 손상2.125. Aeff65는1.375/분, 유효 보호 시39여서 새 풍해0이다. 실제 개체는 위험을 인지하면 먼저 대피하므로 이 수치는 노출 고정 검사값이다. 성격·FPS는 내성·계산량을 바꾸지 않는다.

### 발동 범위

일반 게임의 실제 활동·이동 중에만 신규 날씨 피해를 계산한다. 대기·조경·종료 안전 휴식에서는 새 피해0이며 기존 손상은 보존한다. 첫600초 튜토리얼에는 신규 풍해0을 적용하고 시간은 저장해 재접속으로 재발급하지 않는다.
## S05.13 대표 협동의 실행과 중단

## S05.14 엘레판의 한 친구 보호

## D05.56 젖음·과습·잎 손상 표현

## A04.09 날씨 부담과 보호의 소리

### WX-A01 비 가림

### WX-A04 사건과 중단

session+event 또는 individual+state-entry 키로 중복을 제거한다. 보호 취소·집기·탭 전환·저장 복구는 미완료 단발을 쌓아 재생하지 않는다. 사건이 없는 관리자 정지 프레임은 무음. 실제 피해량·물 이동은 오디오가 바꾸지 않는다.

음원은 기존 큐 재사용을 우선하고 새 강풍·보호 안내 파일 필요 여부는 실제 믹스 후 정한다. 동시 재생 예산·접근성·무음 모드·출력 상한은 A04.07을 따른다. 신규 파일 제작·실기기 청취 완료로 표시하지 않는다.
