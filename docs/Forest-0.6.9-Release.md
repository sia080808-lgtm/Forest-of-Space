# APK0.6.9 · SRS2.19 유한 자원 및 필요별 행동

- 이끼: 물5/7/9, 실제 이용 시간에 체력+2/분(75까지)·기분+1/분(80까지). 마른 상태도 회복. 기본 보유수2, 부수 급수0.5/분, 원천 차감.
- 샘터: 자동 충전0. 실제 비·눈 융해만 반영. 용량60/90/120. 부족 시 다음 날씨에 보정 비를 예약하며 10초 전환+120초 강우, 예약만으로 물을 지급하지 않음.
- 낙엽: 원형L/거름U/운반0.5를 합산한 공동 용량100/150/200. 일일 유입20/30/40. 놀이 분해3배 및 종료 후120초, U에서만 영양 흡수. 중단/저장/재진입 시 낙엽 복제 방지.
- AI: 위험·실제 필요·효과·재고·공간·경로 확인. 영양은 낙엽, 수분은 샘터, 기분/체력은 이끼 등 실제 후보 선택. 보송/봉봉/엘레판 등 기존 종별 렌더와 도움 동작 유지.
- 쉼터: 실제 입실 후 체력만 회복. 원격 급수/영양/기분 지급 제거. 기존 첫 좌석 막힘→다른 좌석 탐색 및 캐릭터 교착 회귀 유지. 부족 자원을 얻으러 안전하게 퇴실.
- 오프라인: 물·낙엽·B/Q/V·영양·기분·부담·손상은 동결. 체력 회복과 적격 성장만 최대8시간. 실제 위치는 그대로.
- UI: 잔량/일일 유입/이용 시간/확장 조건, 취소 가능한 확장 미리보기. 승인 원화를 균일 확대하며 새 원화를 만들지 않음. 확대해도 재고는 그대로. 관리자 OBJ-MOSS/LEAF/FOOD/RAIN은 별도 복제 상태로 실행.
- 표현: 마른 이끼에서도 얼굴을 드러내는 전경 덮임, 낙엽별 접지 그림자와 실제 수량, 거름 표현, 비례 수면. 집기/놓기는 사건당 한 번, 음수는 실제 접점·유량 기반. 렌더에서 자원을 수정하지 않음.
- 일관성 보완: 적은 물을 저장하는 이끼는 가득 차도 고인물W=0이므로 돌돌이 서식의 보습 상한은100%로 해석. 첫 음수 경험은 실제 행동으로 확정하여 화면 가시성에 따라 성장/경로/생리가 달라지지 않음; 관찰 기록은 보이는 경우만 표시.

검수 근거: docs/qa-0.6.9. 자동 회귀·자원 보존·원자 저장 및 실제 Canvas 렌더를 확인한다. Android 실기기 설치/오디오 포커스/프레임 성능, 장기 재미 밸런스는 미검수다. 새 전용 확장 원화 및 이전 버전에서 남겨 둔 종별 부모 행동/음원 제작은 이번 완료 범위에 포함하지 않는다.
