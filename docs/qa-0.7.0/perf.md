  1. 출발점과 도착점 사이 타원(직선 거리 + 0.3) 안의 친구만, 그중 길목에 가까운 10명까지만 경유점을 둔다.
  2. 다익스트라 → A*(남은 직선 거리 휴리스틱, 최단 경로는 같음).
  3. 쉼터 모양과 세계 범위를 객체별로 캐시한다(저장하지 않음).
