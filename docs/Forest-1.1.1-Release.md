# APK1.1.1 · 호숫가에서 그 자리에 잠들던 문제, 관리자 '호수 생명 채우기', 반딧불 밤새 유지, 목마름 안내 빼기

2026-11-21. 사용자 제보(1.0.3, 관리자로 여름 전환): "쉼터가 비워져 있는데 호숫가에서 쉴 곳이 없어 그대로 잠들어버렸다 … 몇몇은 자고 있지도 않아", "연꽃 구현은 안 되어 있나? 호수 생명체들은 없던데", "반딧불이 이벤트는 0.5초 정도 나왔다가 사라지던디", "엘리시 목이 말라서 물을 찾아가요 라고 안내문구 뜨는데 … 잎 그늘 밑에서 쉬고 있음" → "그런 생리적인 안내보고는 안 해도 될 듯", 호수 채우기 "2번(관리자 버튼 따로)".

변경 내용:
- **먼 호숫가에서 걷다 포기하던 문제(`objects.js`):** 할 일을 정하면 도착 기한이 최대 30초(한 번 연장해 45초)였다. 호수 동쪽 끝에서 쉼터까지는 60~90초가 걸려 걷다가 포기하고 다시 고르기를 되풀이했고, 그사이 쉼터 자리는 먼저 출발한 친구들이 잡아(화면엔 아직 비어 보임) 남은 친구가 그 자리에서 잠들었다. 이제 기한은 걸리는 시간 + 10초(최대 4분).
- **그 자리에서 잠든 친구가 다시 찾기(`engine.js`):** 한 번 그 자리에서 잠들면 밤새 다시 찾지 않았다. 이제 20초마다 빈 자리를 다시 찾는다(자리가 생기면 걸어간다).
- **관리자 '호수 생명 채우기'(`world.js` `fillLake`, `admin.js`, 설정 > 관리자 > 호수):** 관리자로 계절을 바꾸면 그 계절 첫 순간처럼 호수가 비어 있다(실제 게임에서는 봄 끝부터 서서히 생긴다). 이 버튼은 지금 계절에 있을 만큼 연꽃(여러 단계, 최대 8)과 물가 이웃을 바로 채운다. 여름 약 22개, 가을 약 13개, 봄 첫날은 개구리알만, 겨울은 채우지 않는다. 계절 바꾸기 자체와 실제 게임 진행은 그대로다.
- **반딧불 밤새 유지(`world.js` `fireflies`):** 맑고 바람 30 미만인 밤에 한 번 떠오르면, 비·눈이 오거나 바람이 60 이상이 되기 전까지 그 밤 동안 남는다(이전에는 바람이 30만 넘어도 바로 꺼짐).
- **목마름 안내 빼기(`forest-app.js`):** 월드 하단의 "(이름) · 목이 말라 물을 찾아가요" 안내를 없앴다. 옛 기준(수분 35 미만 고정)이라 실제 행동과 달랐다(레벨이 오른 친구는 35 아래도 적정). 목마름은 친구 카드 문구로 보인다.
- 저장 스키마·규칙 식별자 불변. 버전 1.1.1 / versionCode 77.

확인(엔진): 관리자 여름 전환만으로도 연꽃 5분 2개 → 35분 10개, 물가 이웃 5~11마리가 정상으로 생긴다(이전 버전도 같음). 반딧불은 날씨가 받쳐 주면 약 2분 넘게 켜져 있었고 0.5초 만에 꺼지는 장면은 재현되지 않았다. 호숫가 잠은 큰비 밤 장면으로 재현·확인했고, 사용자 화면과 똑같은 장면(쉼터가 빈 채 맑은 밤)은 재현하지 못했다.

검증: `lake.test.cjs` 1.1.1 검사(호수 채우기·겨울 거부·저장 검증, 반딧불 바람 40 유지·비에 꺼짐, 동쪽 끝 친구가 밤에 집으로 걸어옴), 관련 테스트 68/68, UI PASS. 전체는 CI. Android 실기기 미검증.
