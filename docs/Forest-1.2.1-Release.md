# APK1.2.1 · 기후 선택이 안 되던 문제, 라이트·다크 모드와 월드 시간 분리, 켤 때마다 첫 화면

2026-11-21. 사용자 제보(1.2.0): "설정에 온화한 숲 촉촉한 숲 이런거 선택이 안됨", "설정에 화면 시간에 맞게 바꾸는 것이 아니라, 원래 월드 시간에 따라 밤이면 어두워지고 낮이면 밝아지는 시스템이고, 그냥 라이트 모드, 다크모드만 있을 뿐", "첨 켤 때 여백의 숲 시작하며 들어가야 하는데 그냥 들어가짐".

변경 내용:
- **기후 선택(`forest-app.js`):** 기후를 고르면 30초 뒤 천천히 바뀌도록 예약만 되고, 카드는 지금 기후(아직 그대로)에 불이 들어와서 눌러도 아무것도 안 고른 것처럼 보였다. 이제 예약한 기후 카드가 바로 선택으로 보이고, 아래에 "→ 온화한 숲(으)로 30초 안에 천천히 바뀌어요"가 뜬다. 지금 기후를 다시 고르면 예약을 지우고 고정만 한다. '계절마다 바뀜'을 고르면 남아 있던 예약도 지운다.
- **라이트·다크 모드(`forest-app.js`·`environment.js`·`scene.js`·`audio.js`):** 설정 '화면'은 '라이트 모드 · 다크 모드' 두 가지(앱 화면 색만). 예전에는 '어둡게'를 고르면 월드도 늘 밤 조명이 되고 밤 배경음이 나왔으며, '밝게'는 늘 낮이었다. 이제 월드 조명·밤 배경음·밤 표시는 설정과 상관없이 숲의 시간(하루 1,200초)을 따른다. 예전 '시간에 맞게'로 저장된 기록은 라이트 모드로 보인다(저장 값은 그대로).
- **켤 때마다 첫 화면(`forest-app.js`):** 이미 시작한 숲은 앱을 켜면 바로 월드로 들어갔다. 이제 켤 때마다 '여백의 숲' 첫 화면이 나오고 '숲에 들어가기'를 눌러 들어간다(앱이 뒤로 갔다 돌아올 때는 그대로).
- **관리자 패널(`forest-app.js`·`forest.css`, 사용자 "특정 항목 고르면 컨트롤창이 맨 위로", "스크롤 내릴 때 특정 항목 눌려져서", "계속 맨 앞에 있는 스킬 대기 없애기만 클릭되어 있음"):**
  - 버튼을 누를 때마다 패널을 새로 그리면서 스크롤이 맨 위로 돌아갔다. 같은 탭이면 스크롤 위치(와 탭 줄의 가로 위치)를 그대로 둔다.
  - 손가락이 10px 넘게 움직였거나 패널이 스크롤된 뒤 끝나는 터치는 누름으로 치지 않는다. 슬라이더 위에서 세로로 밀면 슬라이더가 아니라 패널이 스크롤된다.
  - 친구 탭의 '스킬 대기 없애기'만 진한 초록(눌린 것처럼 보이는 색)이었다. 다른 버튼과 같은 색으로 바꿨다.
- **관리자: 친구 고르면 확대해서 따라가기(`forest-app.js` `adminFocus`·`adminFollowStep`, 사용자 "다른친구에서 특정 케릭터 고르면 그 케릭터 위치로 화면이 가지 않는 버그 … 확대해서 화면이 따라가게"):** 예전에는 친구가 화면 위·아래로 벗어났을 때만 세로로 조금 옮겼다. 이제 이름 버튼이나 월드에서 친구를 고르면 2배 이상으로 확대해 패널 위 보이는 곳 가운데에 두고, 걸어가는 동안 따라간다. 화면을 직접 끌거나 확대·축소하면, 패널을 닫으면, 다른 친구를 고르면 따라가기를 멈춘다. 친구를 골라도 지금 열린 탭은 그대로다(전에는 친구 탭으로 넘어감).
- **관리자: 이웃을 부르면 그 자리로 클로즈업(사용자 "이웃들 버튼 클릭했을 때 해당 이웃으로 화면 클로즈업"):** 잎에 붙는 이웃(잎응애·솜깍지·잎지기·점박이)은 그 친구를 3배로 확대해 따라가고, 뿌리날파리·흙지기·톡토기는 사는 낙엽 자리·더미, 짐꾼개미는 둥지로 2.4배 확대한다.
- **관리자: 시간 버튼(`admin.js` `time`, 사용자 "아침 한낮이런거 누르면 해당 시간으로만 가야하는데 계절 앞뒤로 바뀌는 버그"):** 시계를 앞으로 돌리면서 계절 달력도 함께 넘어가 계절·날짜가 바뀌었다. 이제 계절 달력 시작점도 같이 옮겨 계절과 날짜는 그대로, 하루 시각만 바뀐다. '해 질 녘'(640 → 570)·'깊은 밤'(800 → 1000)·'새벽'(1100 → 1170)이 실제로는 다른 시간대(밤·깊은 밤)에 떨어지던 것도 맞췄다.
- **관리자: 실제로 진행(사용자 "1분, 10분, 하루 누르면 너무오래걸리면서 해당 시간으로 이동함"):** 엔진 1초를 한꺼번에 돌리는 동안 화면이 멈췄다(친구 6명 하루 = 컴퓨터에서도 약 6초, 대부분 길찾기). 이제 한 화면에 약 40ms씩 나눠 돌려 월드가 움직이는 채로 진행되고, 패널에 "실제로 진행하는 중 · n / 20분"과 '멈추기'가 뜬다. 전체 계산량은 같아서 휴대폰에서는 하루에 여전히 시간이 걸린다.
- **관리자: 기후 버튼(`admin.js` `climate`, 사용자 "계속 서늘한 숲으로만 선택되는 버그"):** 플레이어 설정처럼 30초 뒤로 예약만 해서 지금 기후(예: 서늘한 숲)가 계속 선택돼 보였다. 관리자 기후는 바로 바꾼다(기온·습도는 평소처럼 60초에 걸쳐 섞임).
- **관리자: 사물 탭(사용자 "햇살바위 가득채우기 눌러도 가득 안 채워지고 비워도 안 비워지는", "낙엽자리 관리자 기능 직관적이지 않음"):** 값은 바뀌었지만 패널 어디에도 보이지 않았다. 버튼마다 위에 지금 값(샘터 물, 햇살 바위 볕, 숲 바닥 낙엽·더미, 낙엽 자리 낙엽·거름)을 보여 준다. '낙엽 10장'·'거름 채우기'는 10장·30까지 올리기만 해서 두 번째부터는 아무 일도 없었다 → '낙엽 +10장'·'거름 +30'으로 더하고(가득 차면 알림), 바람처럼 숲 바닥에 떨어뜨리는 '낙엽 10장 떨어뜨리기'(`floorLeaves`, 칸·바닥 상한 지킴)를 더했다.
- **관리자: 보기 탭 사물 상태(사용자 "햇살바위의 햇살 양, 이끼의 물양 등도 표시"):** '쉼터 자리·물 양'을 '사물 상태'로 바꿔 쉼터 빈자리·샘터 물에 더해 햇살 바위 볕·이끼 물·바위틈 고인 물·잎 그늘 흙 물·낙엽 자리·웅덩이 물을 사물 아래에 보여 준다. (스킬 범위 설명·표시를 더했다가 사용자 "스킬범위 기능 이해됨"으로 되돌렸다. 친구를 골라도 열린 탭이 그대로인 것은 남김.)
- **비·폭풍·추위에 아무도 피하지 않던 문제(`objects.js`·`social.js`·`weather-care.js`·`shelter.js`, 사용자 "폭풍인데도 아무도 쉼터로 안 들어가고 엘레판도 … 잎 안씌워주고 … 바위틈·잎 그늘로도 안 들어가고", "비가 많이 와도 아무도 쉼터로 들어가질 않음", "날씨 추운 한겨울에도 아무도 쉼터로 들어가질 않음"):**
  - 원인 1: 행동 고르기에서 '목마름'이 '비 피하기'보다 먼저였다. 수분이 띠 아래(35)인 친구는 샘터로만 가려 했고, 샘터 자리가 차 있으면 그대로 큰비 속을 서성였다(앱 재현: 강풍 → 큰비로 바꾸자 쉼터에서 나와 돌아다님). 이제 비가 오면(강수 0.25 이상, 수분 20 이상) 비가 몸을 적시므로 물 마시러 가지 않고 비 피하기·추위 판단으로 넘어간다. 큰비에는 시작한 일(물·거름 5분 붙잡기)도 끊고 피한다.
  - 원인 2: 마실 물이 없으면(샘터 빈 겨울 등) 목마른 친구가 "샘터에 물이 모이길 기다리며" 밖에서 서성였다. 마실 곳이 없으면 피하기·몸 녹이기·쉬기로 넘어간다.
  - 원인 3: 추위는 기운이 떨어진 뒤에야 쉼터로 갔다. 이제 추운 날(기온 35 미만이나 눈) 추위에 약한 친구는 먼저 몸을 녹이러 간다(쉼터, 볕이 남은 햇살 바위; 카드 "포근한 쉼터 안에서 몸을 녹이고 있어요"). 쉼터가 차면 8초 뒤 다른 곳으로.
  - 원인 4(엘레판 잎 우산): 수분이 낮은 친구는 우산 대상이 아니어서(건강 조건), 엘레판 곁 친구가 비를 맞으며 서성였다. 비가 올 때는 수분이 낮아도 우산 아래 들 수 있고(비가 물을 준다), 엘레판 곁 친구와 엘레판은 우산이 펴질 때까지 그 자리에서 기다린다. 우산을 씌울 친구가 곁에 없으면 엘레판도 비를 피한다.
  - 측정(엔진, 친구 5명, 큰비 60초): 고치기 전 리들리·코로나가 계속 물 마시러 가거나 서성임 → 모두 쉼터·바위틈·잎 그늘·햇살 바위로. 겨울(서늘한 숲, 맑음, 15분): 추위에 약한 친구가 몸 녹이기·쉼터 안에 있는 시간 대부분, 슈퍼범(추위에 강함)은 그대로. 엘레판 곁 건강한 친구 보슬비·큰비 우산 120초 중 120초.
- 저장 스키마·규칙 식별자 불변. 버전 1.2.1 / versionCode 87.
