최종 앞잎의 변형 결과에서 시각 경계·보호 바닥 범위·접점 검수 데이터를 함께 만든다. 손님은 잎 아래 공간에만 배치하고 겹치는 앞잎은 손님보다 앞에서 그린다. 단순 원형 충돌체 하나로 전체 그림을 대체하지 않는다. 세부 경로·마스크는 적용 후 검증한다.


## D03.24 직접 들기와 착지

### 동작 순서
0.35초 길게 누르기 → 안전 중단과 들기 수락 → 몸이 떠오름 → 공중에서 전신 버둥 → 유효 위치 확인 → 저장 성공 후 발 접촉 → 0.6~1초 안정과 자율 복귀.

### 버둥 공통 규칙
팔다리의 독립 회전과 몸 기울임을 사용한다. 통째 이미지의 띠 변형을 팔다리 애니메이션으로 대신하지 않는다. 머리 부착점·몸통·팔 뿌리의 겹침이 모든 프레임에서 유지되어야 한다.

### 종별 변형
봉봉: 동그란 팔은 몸 앞, 짧은 발로 버둥. 보송: 긴 팔은 몸 뒤, 앞머리 잎은 몸과 함께 부착. 넓이: 팔 없이 두 발·몸·앞잎·뒤 잎으로 버둥. D03.11 최종 5개 레이어와 부착부 겹침을 유지한다. 주렁: 팔 없이 양발과 드리운 띠잎.

### 시간과 위치
검토 GIF는 집기 전·후가 포함된 10초 반복이다. 검토 영상의 공중 길이를 실제 제어 시간으로 가져오지 않는다. 실게 임 최대 공중 5초, 무효 위치·멀티터치·잠금의 복귀 계약을 유지한다. 논리 위치는 배치 성공 전 원점이다.

### 소리와 효과
공중에서는 발소리·급수·물 흡수·자원 획득을 발생시키지 않는다. 착지 성공 후 SFX_PLACE_CONFIRM 또는 재질 접지음 중 1개만 낸다. 강제 복귀를 배치 성공으로 표시하지 않는다.

### 수용 기준
몸통 파임 0, 머리와 몸의 틈 0, 넓이·주렁 팔 0. 봉봉 앞팔/보송 뒤팔 순서를 지킨다. 양눈과 얼굴은 승인 시안의 가 림 범위를 유지한다. APK 적용 여부는 별도 구현 상태표에서 판정한다.


## D03.27 넓이 성장·방향

### CHR-F03 · CH-SPC-03
CH-G01~04 성장 단계는 Lv.1~2 / 3~5 / 6~8 / 9~10, 표시율 65/78/90/100%를 유지한다. 같은 단계 리들리 대비 1.5배를 적용한다. 기본 폼은 D03.11 최종 원형으로 통일하고 구형 성장 시트의 다른 외형은 사용하지 않는다.

정면·3/4·뒤·초상은 최종 원형을 기준으로 제작한다. 비대칭 앞잎·뒤 잎과 피벗은 함께 반전 검수한다. 아직 없는 뒷모습·성장별 별도 원화를 완성했다고 표시하지 않는다. 잠자기는 기존 감은 눈을 유지하고 기능을 삭제하지 않는다.

### 납품 상태
기본 5개 PNG와 승인 후드·그늘·우산 렌더는 확보했다. 모든 성장·방향·생활 모션 및 기기 검수 완료를 뜻하지 않는다.


## A04.08 넓이 모션의 음향 연결

### S2-AUD01 기존 적용
기존 음원 및 리들리 음수·잎 정돈·잠자기·환경 재생 계약을 유지한다. 이번 업데이트는 새 음원 생성이나 게임 음향 적용 완료가 아니다.

### NEO-A01 잎의 접점
그늘·우산 펼침은 기존 SFX_LEAF_OPEN, 후드 내림·복귀의 작은 마찰은 SFX_LEAF_BRUSH 계열을 재사용한다. 상태 진입·실제 움직임 접점에서만 재생하며 매 프레임 반복하지 않는다. 유지 중 별도 잎 루프를 깔지 않는다.

### NEO-A02 비·물방울
A02 환경 비와 A04 기존 낙수 접점 계약을 재사용한다. 잎끝에 실제 표시된 방울 낙하와 소리를 동기화하고 화면 방울마다 무제한 단발음을 만들지 않는다. 물 전달이 아닌 우산 낙수는 급수·획득 소리를 내지 않는다.

### NEO-A03 중복과 중단
A12의 두 넓이는 최대 두 잎 음원을 배분하며 휴식 인원만큼 추가하지 않는다. session+event 접점을 중복 제거한다. 강풍·집기·이동·복구 시 불필요한 잔류음을 종료한다. 봉봉의 V→B 실제 전달 접점 규칙은 유지한다.

### 검수 상태
승인된 모션에 대한 큐 연결 명세 완료. 음량·접점·중복·실기기 청취는 구현 후 AQ 검수로 기록한다. GIF는 무음 시안이다.
