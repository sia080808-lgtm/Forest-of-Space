# APK0.9.5 · 동쪽 호수 확장, 왼쪽 아래 노란 조각, 멈춰 있던 친구들, 설정 정리, 관리자 도구(창조주 영역)

2026-11-20. 사용자 요청: "노란조각 수정하고, 호수는 확장시켜 놓자"(풀잎 배는 "없던 걸로"), "오브젝트로 가는 길을 찾고 있는 버그, 그리고 케릭터들 웰케 정적으로 멈춰만 있냐", "설정창 좀 깨끗하게 카테고라이징", "관리자 창도 … 테스트 할 수 있는 모든 경우의 수", "특정 해금 푼다던가 하는 것까지 있는 창조주 영역", "레벨 … 리셋", "다 관리자 기능으로".

변경 내용:
- **동쪽 호수 확장(`world.js`·`scene.js`·`tools/build-lake-floor.py`):** 물가 지역이 x 1.25~3.3으로 넓어져 호수 전체와 북·남·동쪽 물가가 열린다. 배 없이 호수 둘레를 걸어서 돌 수 있다. 0.9.0~0.9.4에 물가를 연 저장도 넓어진 땅으로 불러온다. 호수 그림(물가 풀밭·부들·겨울 얼음)을 x 3.3까지 다시 구웠다(동쪽 물가 부들 세 무리 추가). 수련은 동시에 최대 7 → 12, 수련·물가 이웃·반딧불은 호수 전체에 나타난다. 물 마시러 갈 물가, 봄에 얼음 위 친구가 걸어 나올 물가는 호수 둘레에서 가장 가까운 곳을 고른다.
- **왼쪽 아래 노란 조각(`scene.js`):** 화면 바탕을 그리는 종이 조각이 고사리 잎 끝 하나를 포함하고 있었다. 빈 종이 부분만 쓰도록 바꿨다.
- **멈춰 있던 친구들(`objects.js`·`engine.js`·`shelter.js`):** 잘 곳·비 피할 곳이 모두 차 있으면 그 자리에서 잠들고("쉴 자리가 없어 그 자리에서 잠들었어요"), 강풍에 피할 곳이 없으면 몸을 낮춘다. 자리를 기다릴 때는 주변을 거닌다. 산책 확률 30 → 40%, 산책지·자유 들르기 머무는 시간을 줄였다. 쉼터 안에서 쉬는 친구가 "쉬어 갈 자리를 찾고 있어요"로 보이던 문구를 바로잡았다. 측정(엔진): 낮 정지 78~80% → 69~71%, 밤 "찾고 있어요" 최장 125초 → 5초 이하.
- **설정 정리(`forest-app.js`):** 화면 / 움직임 / 소리 / 숲(기후·쉼터 공간) / 기록 / 관리자 / 정보 일곱 묶음. 오래된 개발 안내 문구를 뺐다.
- **관리자 도구(새 `admin.js`, 설정 > 관리자 > 열기):** 실제 정원 기록을 바로 바꾸고 저장 검증을 거친다(되돌리려면 백업). 묶음마다 접고 펼친다.
  - 시간: 아침·한낮·해 질 녘·깊은 밤·새벽으로(시계는 앞으로만), 1분·10분·하루 실제 진행
  - 계절: 봄·여름·가을·겨울 첫날로
  - 날씨: 맑음·흐림·보슬비·큰비·안개·눈·강풍(눈 오는 계절의 비는 눈), 기후 4종
  - 친구: 대상(모두/한 친구), 레벨 1~10 맞추기, **모든 친구 레벨 초기화**(확인 창), 상태 바꾸기(넉넉하게·목마르게·과습하게·지치게·배고프게·영양 과잉·잎 다침), 아직 없는 친구 부르기·바로 들이기, 입구 손님 돌려보내기
  - 해금(확인 창): 호수 물가 열기, 쉼터 넓히기 열기, 샘터·이끼·낙엽 자리 3단계까지 열기
  - 사물: 샘터 가득·비우기, 낙엽 10장, 거름 채우기
  - 작은 이웃: 돌려보내기(짐꾼개미는 남김)
  - 검수 화면: 애니메이션 검수, 대표 장면 검수(실제 기록은 바뀌지 않음)
  - 도구로 친구·샘터에 넣거나 뺀 물은 물 원장 `ledger.admin`에 남겨 물 합계가 맞는다. 실행할 때마다 기록에 "관리자 · …"가 남는다.
- 저장 스키마·규칙 식별자 불변(저장에 `ledger.admin` 추가, 없으면 그대로 불러옴). 버전 0.9.5 / versionCode 71.

함께 정리한 기획(코드 미반영): SRS v2.34 능력치 개편(`docs/Forest-Stats-SRS-v2.34.md`·`.pdf`) — 수분·영양·기운, 육각형 종족값, 광합성 성장, 오브젝트 역할. 1.0 개편으로 진행 예정.
