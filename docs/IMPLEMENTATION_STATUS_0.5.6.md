## 단계의 단일 기준

SRS S08.03의 1~5단계를 유일한 진행 기준으로 사용한다. 현재는 1단계 ‘작동하는 정원’의 단일 리들리·C01 맑음/비 구현 및 검수다. 과거 작업 번호 0(추적/보존), 1(단일 정원), 2(기본 행동/환경/소리)는 이 1단계를 나누어 작업한 번호이며 최신 SRS 2단계와 다르다. APK 버전은 단계 완료 수가 아니다.

## 현재 단계 경계와 미관측 항목

단일 정원의 기존 동작을 보존하는 회귀 검수이며 SRS 전체 완성 판정이 아니다. 복수 개체 겹침 선택·사회 예약·낙엽 운반 세션 관련 AC-122/130/135는 대상 시스템을 구현하는 2단계 이후 통합검사 대상으로 유지한다. 종별6외형·다방향/잎 성장 전용 에셋·전체 26모션·4기후·34음향큐·해충/천적·협동·두리 정착은 후속 단계이며 현재 공용 리들리나 기본17파일로 완료 처리하지 않는다.

Android 실제 기기의 업데이트 설치·물리dp·오디오 청취·배터리/메모리/장시간 성능은 관측하지 못했다. 따라서 1단계 전체 수용 완료 또는 출시 준비 완료로 표시하지 않는다. GitHub 업로드는 중단 상태다. CodeQL 성공을 주장하지 않는다.

## 재발 방지

모션 교체 시 Inspector.motions 전체, 기본6표정, 기존 저장 이전, 몸통 내부 보존, 실제 음향 접점, UI 중단을 함께 실행한다. tests/forest/lifecycle.test.cjs가 잠자기 얼굴·6표정·낮밤 믹스·60초 휴식·강풍 우선순위 누락을 검출한다. 시안 파일·런타임 그림·검수 결과를 단계와 따로 기록한다.
