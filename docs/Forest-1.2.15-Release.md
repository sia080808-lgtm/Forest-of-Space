# APK1.2.15 · 화면 아래쪽 친구를 누르면 바로 '자세히 보기'로 넘어가던 문제

2026-11-22. 사용자 제보: "화면 아래에서 케릭터 누르면 바로 케릭터 자세히 들어가는 버그 있음 디바깅 pr".

- **원인(`carry.js` 월드 누르기):** 월드에서 친구를 누르면 손가락을 뗄 때(pointerup) 친구 카드가 화면 아래쪽에 바로 열린다. 그 뒤 브라우저가 '클릭'을 한 번 더 보내는데, 일부 WebView는 이 클릭을 그때 손가락 아래에 있는 것에 보낸다. 친구가 화면 아래쪽에 있으면 손가락 아래가 막 열린 카드의 '자세히 보기' 버튼이라 바로 자세히 보기로 넘어갔다. 이 뒤따르는 클릭을 막는 코드(0.7초)는 월드 그림과 친구 버튼만 막고 카드는 막지 않았다.
- **수정:** 월드를 누른 직후 0.7초 동안은 친구 카드(사물 카드 포함)와 그 자리의 안내 말풍선에 오는 클릭도 막는다. 카드의 버튼은 그 뒤에 누르면 평소대로 눌린다. 꾸미기 창·관리자 패널 등 다른 버튼은 그대로.
- 저장 스키마·규칙 식별자 불변. 버전 1.2.15 / versionCode 101.

검증: UI 검사에 1.2.15 단계 추가(월드에서 친구를 누른 뒤 카드의 '자세히 보기'로 가는 클릭이 와도 자세히 보기가 열리지 않음 — 고치기 전 코드는 실패), UI PASS, `package` 통과. 전체는 CI. Android 실기기 미검증.
