# APK0.6.37 · 바위틈에 한 친구씩, 쓸 수 없게 된 자리에서 멈추지 않기

2026-11-19. 사용자 제보: "베이치가 바위틈으로 향하고 있어요 상태가 뜨고 가만히 있음. 바위틈에는 코로나가 있는 상황. 코로나가 바위틈에서 나오니 갑자기 이끼에 있던 엘리시가 바위틈으로 향해요 상태가 되며 바위틈으로 감. 베이치는 여전히 그 자리 그대로 멈춰서 바위틈으로 가고 있어요 상태".

- **원인(`objects.js`):** 0.6.35부터 바위틈 쉬는 자리는 돌 바로 앞의 좁은 띠(0.07×0.015)이고 친구는 틈 안으로 들어가 앉는다. 그런데 바위틈은 여전히 두 친구까지 받았다(자리 8). 두 친구가 거의 동시에 바위틈을 고르면 띠의 양 끝 자리를 하나씩 받는데, 먼저 간 친구의 몸이 길을 막아 뒤 친구가 다가가지 못했다. 몇 초 뒤 포기했다가 다시 바위틈을 골라서, 제자리에 멈춘 채 "바위틈으로 향하고 있어요"로 보였다.
- **수정 1:** 바위틈은 한 번에 한 친구만 쓴다. 다른 친구가 이미 바위틈을 골랐거나 쉬고 있으면 바위틈은 "편히 머물 빈 자리를 찾고 있어요"로 빠지고 다른 쉼 자리를 고른다. 그 친구가 떠나면 다시 고를 수 있다.
- **수정 2(안전장치):** 친구가 자리에 도착했지만 그 자리가 쓸 수 없게 된 경우(바위틈이 젖거나 바람이 세짐, 샘물이 마름 등), 예전에는 '도착'으로 쳐서 막힘 시간 제한이 걸리지 않았다. 이제 5초 뒤 과제를 내려놓고 실제 이유("안전하게 머물 곳을 찾고 있어요" 등)로 기다렸다가 다시 고른다.
- 저장 스키마·규칙 식별자 불변. 버전 0.6.37 / versionCode 54.

검증: 자동 287/287(`rest-spots`: 코로나가 바위틈에 있으면 베이치에게 바위틈 자리를 주지 않고, 코로나가 떠나면 다시 고를 수 있음), DOM UI PASS. 엔진 장시간 검사(친구 5명, 이끼를 바위틈 바로 아래에 둔 배치, 10시드 × 3게임일, 최종 코드)에서 "…로 향하고 있어요" 상태로 15초 이상 멈춘 친구는 없었다. 다만 사용자 화면과 똑같은 장면을 엔진에서 그대로 재현하지는 못했고, 코드 경로로 원인을 판단했다. Android 실기기 미검증.
