# APK 0.6.8 · 입구가 열린 다른 자리 탐색

사용자 제보: 빈 쉼터인데 성체 리들리 카드에 입구가 막혔다고 표시된다. 사진만으로 실제 저장 배치를 확정하지는 않았다. 코드 검사에서 지형을 합법적으로 이동한 배치에서도 첫 좌석의 입구만 검사하고, 다른 좌석의 열린 입구를 시도하지 않는 별도 문제가 확인됐다.

수정: 형상·용량·다른 친구와의 겹침을 통과한 좌석을 순서대로 검사하며 실제로 접근 가능한 입구를 가진 좌석을 예약한다. 어느 좌석에도 진입할 수 없을 때 경로 안내를 표시한다. 기존 크기·실제 입실 판정·공간 원장·대기 요청은 유지한다.

재현: 성체 리들리(.12,.65), 바위(.12,.36). 조경 검증이 허용하는 배치에서 첫 좌석 입구는 막히나 다른 좌석을 통해 전체 몸이 입실한다. 기존 입구 교착 회귀와 쉼터·패키지 검사 및 UI 흐름을 재검수했다. 검수 근거 docs/qa-0.6.8. 실제 사용자의 저장 및 Android 실기기 설치는 미확인이다.

SRS 연결: S09.15 / SH-TRAFFIC-03. 0.6.7 캐릭터 충돌 우회는 유지하며 이번 문제는 좌석 선택을 보완한다. 버전0.6.8, versionCode25, 같은 Android 패키지·인증서.
