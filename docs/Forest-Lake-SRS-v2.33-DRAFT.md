# 여백의 숲 · 동쪽 호수 지역 SRS v2.33 (초안)

2026-11-20. 상태: **기획 초안, 구현 전**. 앱 코드·버전 변경 없음(APK 0.8.7 그대로).

사용자 요청과 결정:
- "이제 영역 넓히자. 일단 호수지역", 인게임 시안 확인 뒤
- 물가: "물가 경계는 이 컨셉이 나음"(번지는 수묵 담채, 또렷한 먹선 물가는 쓰지 않음)
- "연꽃은 좀 더 크게", "징검다리와 중간에 섬 … 맘에 안듦"(징검돌·섬 없음)
- "이쪽까지 다 물로"(호수는 지역 동쪽 끝까지 물), "이후 맵이 넓어지면 해당 잘린 호수 전체 연장해서 보이게 할 거임. 이건 염두"
- "연꽃봉오리들이 서서히 피어나는 구조", "호수에서 랜덤으로 생성", "물 위에 피지 않음?" → 꽃이 물 위에 피는 수련으로
- "호수가 생물들도 좀 추가하자" → 후보 7종 "넣어줘"

## LK-01 원칙

- 지저분하지 않고 고요한 수묵화 힐링. 빈 물은 여백으로 남긴다.
- 상태 엔진은 1초 고정 단계, 렌더는 상태·난수를 바꾸지 않는다. 새 무작위는 독립 난수(`rng.lake`)를 쓴다.
- 기존 저장·좌표·숲 규칙은 그대로다. 호수는 0.7.0의 '열린 지역' 목록(`s.world.regions`)에 `lake`를 더하는 방식으로 붙인다.

## LK-02 위치·크기·땅

- 지역 `lake`: x 1.25 ~ 2.2, y −0.25 ~ 1.25(숲 동쪽에 붙음, 숲 한 변의 약 0.63배).
- 땅 구성(서 → 동): 숲에서 이어지는 종이 바닥 → 점점 촉촉해지는 물가 풀밭(풀포기가 물가로 갈수록 많아짐) → 번지는 물가 → 호수. 호수는 지역 동쪽 끝까지 물이고, 위·아래에는 물가가 있다.
- 숲과의 경계: 바닥 종이 질감을 이어 그려 숲이 끝나는 선이 보이지 않는다.
- 다음 지역으로 이어짐: 호수 그림과 물 판정은 동쪽 끝이 잘린 채 다음 지역(더 동쪽)이 열리면 이어 그릴 수 있게 만든다(물 모양은 지역 경계가 아니라 세계 좌표 기준의 하나의 호수).
- 걷기: 물 위는 걸을 수 없다(물가 둘레만). 겨울에 얼면 얼음 위를 걸을 수 있다(LK-06).
- 징검돌·섬은 두지 않는다.

## LK-03 해금 (결정 대기)

후보: ① 숲 성장 조건 ② 동쪽 끝 산책에서 발견("물 냄새가 나요") ③ ①을 채운 뒤 ②로 발견. 처음부터 호수 전체를 열지, 물가만 먼저 열지도 결정 대기.

## LK-04 수련 (물 위에 피는 꽃)

생애주기(그림 시안: 스크래치 `waterlily-cycle.png`, 저장소 미포함):

| 단계 | 모습 | 시기 |
|---|---|---|
| 새 잎 | 물 위에 작은 갈라진 잎 | 봄 |
| 봉오리 | 잎 곁 물 위로 분홍 봉오리 | 여름 첫날 |
| 반쯤 핌 | 바깥 꽃잎부터 벌어짐 | 여름 1~2일째 |
| 활짝 핌 | 꽃잎 다 열림, 노란 꽃술 | 여름 2~3일째 |
| 오므림·잠김 | 오므린 채 물속으로 가라앉음(끝만 보임) | 가을 |
| 시듦 | 잎이 갈색으로 바래고 말림 → 겨울에 사라짐 | 늦가을 |

- 무작위 생성: 늦봄~여름에 일정 간격마다 확률로 호수 물 위 빈자리(물가에서 조금 떨어지고 다른 수련과 간격 유지)에 새 수련이 생긴다. 동시에 최대 6~8송이. 수련마다 피는 날이 달라 여름 내내 피고 지는 꽃이 섞인다. 위치·단계는 저장한다.
- 하루 리듬(렌더 전용): 아침에 열리고, 한낮에 활짝, 해 질 녘에 반쯤 오므리고, 밤에는 닫힌다. 큰비에는 오므린다.
- 그림: 연잎(수련 잎)은 수채(가장자리 물감 고임, 밝은 왼쪽 위, 연한 잎맥, 물 위 옅은 그림자), 꽃은 크게(시안 1.8배).

## LK-05 물가 이웃 (7종)

숲의 작은 이웃과 같은 출현 공통 규칙(조건이 이어지면 후보, 확률로 도착, 무리 상한, 조건이 깨지면 떠남)을 쓴다. 호수 이웃은 숲 이웃의 8무리 상한과 따로 센다(호수 상한은 구현 때 정함). 이름은 가칭이다.

| 이름(가칭) | 실제 생물 | 사는 곳 | 하는 일 |
|---|---|---|---|
| 물땡땡이 | 소금쟁이 | 잔잔한 물 위 | 물 위를 미끄러지며 떨어진 작은 벌레를 먹음. 비·강풍이면 수련 잎 아래로 숨음 |
| 방울이 | 물달팽이 | 수련 잎 뒷면·물가 | 시든 수련 잎·물때를 먹는 분해자. 너무 많아지면 새 잎도 갉음 |
| 꼬물이 | 개구리알 → 올챙이 → 청개구리 | 봄 얕은 물가 | 봄에 깨어나 여름에 개구리가 됨. 개구리는 수련 잎 위에서 쉬며 날벌레를 잡음 |
| 잠잠이 | 잠자리(애벌레는 물속) | 부들·갈대 | 여름에 애벌레가 부들 줄기를 타고 올라와 날개돋이. 다 자라면 물가 위를 날며 모기를 잡음 |
| 동글이 | 물방개 | 물속·물풀 | 물속에서 올챙이·작은 벌레를 먹음. 가끔 물 위로 올라와 공기 방울 |
| 반짝이 | 송사리 | 얕은 물 | 수련 사이를 떼 지어 다니며 장구벌레를 먹음. 그림자가 지면 흩어짐 |
| 장구벌레(해충) | 모기 애벌레 | 고인 잔잔한 물 | 따뜻하고 잔잔한 물에 생겨 물가 친구를 성가시게 함(기분 소폭 감소). 반짝이·잠잠이·개구리가 먹어 줄임 |

먹이 관계: 장구벌레 ← 반짝이·잠잠이(애벌레·성충)·개구리. 올챙이 ← 동글이. 시든 수련 잎 → 방울이(분해). 숲의 해충·천적 관계와 같은 구조로, 천적이 없어도 날씨(큰비·추위)로 해충이 줄어 회복될 수 있게 한다.

계절: 봄 개구리알·올챙이, 여름 잠자리 날개돋이·송사리 떼·장구벌레, 가을 수가 줄고, 겨울 얼음 아래 겨울잠(새 출현 없음).

그림: SRS 작은 이웃 시트 화풍(수채, 따뜻한 갈색 윤곽). 다리·날개·꼬리는 숲 이웃처럼 부위별 리그.

## LK-06 날씨·계절

- 호수 둘레는 늘 촉촉하고 아침 안개가 잦다(지역 미기후).
- 큰비: 물이 불어 물가가 조금 잠긴다(걷는 물가 폭이 좁아짐). 가뭄: 물가가 드러난다.
- 겨울: 호수가 언다(수묵 흰빛 얼음). 언 동안 얼음 위를 걸을 수 있다. 수련·물가 이웃은 보이지 않는다.

## LK-07 친구와의 상호작용·이벤트

사용자 결정: 기본 상호작용은 모두 넣고, 이벤트는 "4개 다 넣어줘"(개구리 깜짝·잠자리 날개돋이·여름밤 반딧불·겨울 얼음 놀이).

### 기본 상호작용

| 상호작용 | 내용 |
|---|---|
| 물가에서 물 마시기 | 샘터처럼 몸 물을 채운다. 호수는 늘 물이 있어 마르지 않지만 멀어서 목마를 때 고르는 곳 |
| 발 담그기 | 더운 여름 한낮 물가에 앉아 발을 담근다. 기분·체력 소폭 회복, 비를 좋아하는 종(특성 `rain` > 0)은 더 크게 |
| 수련 잎 그늘 쉬기 | 물가 가까운 큰 수련 잎 곁에서 쉰다 |
| 물가 바라보기 | 산책 중 활짝 핀 수련·소금쟁이·송사리 떼 앞에서 멈춰 바라본다(산책 동작에 이어서) |
| 종별 반응 | 베이치(과습에 약함)는 물가에 오래 머물지 않음, 슈퍼범은 둥지잎에 물을 떠 감, 엘레판은 큰 잎으로 물을 튀김 |
| 호수 주워 오기 | 호수 산책에서만 줍는 꾸미기 아이템(매끈한 물돌, 마른 수련 씨방, 부들 이삭, 조개껍데기 등) |

### 이벤트

| 이벤트 | 조건 | 장면 | 효과 |
|---|---|---|---|
| 개구리 깜짝 | 여름, 개구리가 수련 잎 위에 있고 친구가 0.1 안으로 다가올 때 | 개구리가 '퐁' 뛰어들고 물결, 친구가 깜짝 놀라 뒤로 한 걸음 | 놀람 표정(렌더), 같은 친구는 하루 한 번 |
| 잠자리 날개돋이 | 여름 아침, 잠자리 애벌레가 다 자랐을 때 | 부들 줄기에서 날개를 말리다 날아감, 근처 친구가 지켜봄 | 지켜본 친구 기분 소폭 상승, 발견 기록 |
| 여름밤 반딧불 | 맑은 여름밤, 바람 약함 | 물가 위로 반딧불이 천천히 떠다님, 잠들기 전 친구들이 잠깐 바라봄 | 그날 밤 잠자리 기분 소폭 상승, 발견 기록 |
| 겨울 얼음 놀이 | 겨울, 호수가 얼었을 때 | 친구가 얼음 위를 조심조심 걷다 가끔 미끄러짐, 얼음 위 자국이 남았다 사라짐 | 기분 소폭 상승, 미끄러짐은 렌더 전용 |

- 이벤트는 자주 나오지 않게 한다(같은 이벤트는 하루 한 번 안팎). 숫자는 구현 때 측정으로 정한다.
- 반딧불은 이 이벤트 전용의 빛 연출이다(작은 이웃 무리로 세지 않음).
- 물가를 좋아하는 새 친구 종(결정 대기).

## LK-08 결정 대기

1. 해금 방법(LK-03 ①·②·③), 처음부터 다 열지
2. 새 친구 종을 이번에 넣을지
3. 물가 이웃 가칭 이름 확정
4. 호수 이웃 무리 상한, 수련 최대 수(6~8 중)

## LK-09 작업 순서(안)

1. 지역 `lake` 추가(세계 범위·걷는 땅·물 판정·카메라), 호수 바닥 그림(시안 방식으로 원본 종이 질감 + 물 담채)
2. 수련(무작위 생성·생애주기·하루 리듬·그림)
3. 물가 이웃 그림(SRS 시트 화풍) → 생태 규칙 → 친구 관계
4. 날씨·겨울 얼음, 해금
5. 테스트(새 지역 저장 호환·물 위 걷기 금지·수련 생성 재현성·이웃 보존식)·SRS 확정·버전
