# 여백의 숲 · 엘리시 캐릭터 전환 명세 (SRS v2.23 변경안)

- 기준: 통합 SRS v2.22 / 제품 APK 0.6.13
- 상태: 기능 브랜치 구현/검증 진행. **v2.22 전체 통합 PDF를 덮어쓴 문서는 아님**
- 변경 ID: ELL-SPC-01 ~ ELL-AC-08
- 요구사항 매핑: S04.01 / S04.04 / S04.05 / S05.01-02 / S05.06-10 / S05.12 / D03.10 / D07 / S09
- 이전 저장을 안전하게 이어가기 위해 `species=bonbon` 내부 ID는 마이그레이션 전환기 동안 남기고 UI의 종명만 엘리시로 바꾼다.

## ELL-SPC-01 · 정체성
- 캐릭터 표기: **엘리시**. 실제 모티프: *Platycerium ellisii*.
- 기존 **봉봉** 이름과 `P. superbum` 종 연결은 플레이어블 캐릭터 목록에서 제거.
- 전용 생식엽 2장과 둥근 영양엽 1장, 기존 봉봉의 갈색 몸통/아이보리 세로 눈/아주 작은 발을 유지한다.
- 머리 둥근 잎은 지나치게 여러 번 갈라지지 않는 단순한 주걱형 곡선. 영양엽은 몸 앞을 감싸는 볼륨.
- 리들리·엘레판과 공통된 2D 종이 결, 낮은 채도, 무입·무볼터치·과한 그림자/하이라이트 금지.
- 초상화·도감·친구 목록·선택 카드·월드 스프라이트·방문 UI에 동일 인상을 유지한다.

## ELL-SPC-02 · 능력: 잎틈 정원
- 역할: **미세 서식처 제공자**. 작은 생물의 행동에 유리한 장소를 제공하는 환경 보조.
- 현실 생태와 게임 의인화를 구분한다. 실제 엘리시가 해충을 직접 죽이거나 생물을 소환하는 것은 아니다.
- 발동 전제(초기 시뮬레이션): 엘리시가 활성 편성/미목부작/건강(몸 수분 B≥35, 체력≥40, 과습 부담<40, 잎 손상<30)이며 바람<60. 이끼 실제 보유 수분율 40~75, 바위 틈의 고인 물<5, 습도 지수 H 40~85, 엘리시와 바위 틈의 거리<0.20.
- **현재 구현**: 기존 돌돌이의 재방문 판정에서 적합한 엘리시가 있을 때만 확률을 30%→45%로 조정한다. *첫 방문 보장, 기존 서식처 필수 조건, 유입 제한, 관찰·도감 기록, 물·영양 원장 불변*. 조건 불충족 시 기존 확률 사용.
- **후속 확장 (미구현)**: 실제 먹이·접근 경로·밀도와 종별 수용량 검증을 전제로 잎지기 등 천적의 유효 체류 안정성에 간접 효과. 천적 자동 생성/무조건 해충 감소/무한 보상 금지.
- 능력 표현: 영양엽 가장자리가 아주 조금 들리며 작은 생물이 잎틈을 살피는 모션. 구현된 생물 실체가 없다면 가짜 생성 애니메이션 금지.

## ELL-SPC-03 · 슈퍼범 및 구능력 분리
- 기존 봉봉의 `A04` 물 나눔, `K01` 물 릴레이, `K02` 물그늘과 `EC02` 봉봉의 빗물 나눔은 **신규 엘리시에서는 비활성**.
- 기존 물수집 코드는 강수를 원래 물 원장으로 되돌리고 엘리시는 물을 직접 저장/급수하지 않는다.
- 과거 세이브에 이미 기록된 자원, 사용자 지정 별명, 개체 ID, 성장과 도감·발견 기록은 임의 삭제하지 않는다. 과거 수분량은 보존하되 신규 급수에는 사용하지 않는다.
- **향후 슈퍼범 캐릭터 별도 제작**: 완성된 원화와 새 종 식별자, 별도 방문/편성/물 전달 SRS가 승인된 뒤 도입하며 지금 즉시 자동 생성하지 않는다.

## ELL-SPC-04 · 기존 저장과 UI
- 내부 종 키 `bonbon`은 이전 저장과 테스트를 위한 **호환성 별칭**이다. 사용자에게는 '엘리시'와 `P. ellisii`만 보인다.
- 이전 캐릭터 이름이 정확히 '봉봉'이고 사용자가 별명을 지정하지 않았다면 저장 로드 마이그레이션에서 '엘리시'로 치환. 사용자 지정 별명은 유지.
- `recruitment.progress.bonbon`, 개체 ID, 관계, 레벨, 경험치, 활동 편성, 기존 도감 보존. 방문 목표는 '잎틈 확인 1회 + 건강하게 120초 머무르기'로 대체.
- 오래된 A04 진행 세션은 신규 세션을 만들지 않고 안전 종료. 이미 실제로 완료된 물 이동은 되돌리지 않는다.
- 동일 5개체 제한 및 SRS의 생물 개체/종 수 제한을 유지.

## ELL-SPC-05 · 시각 및 리깅
- 현재 `species-rig.js`의 통합 잎 그림 대신 `ellisii-fertile-left.svg`, `ellisii-fertile-right.svg`, `ellisii-shield.svg`를 독립 렌더 레이어로 도입.
- 원래 `bonbon.png`의 몸통·눈·팔다리 스프라이트는 보존하고 눈썹/입/볼터치는 추가하지 않는다.
- 뒷부분 생식엽 둘은 동작을 아주 미세하게 달리하고, 앞 영양엽은 안정되게 가려 준다. 움직임 줄이기 옵션에서는 시간 기반 잎 흔들림을 끈다.
- UI용 단독 초상화 `ellisii-portrait.svg` 별도 사용. 개별 이미지는 렌더 에셋이며 물 자원/게임 상태를 변경하지 않는다.
- 그림자의 깊이와 선택 링은 기존 2.22 규칙을 변경하지 않는다.

## ELL-SPC-06 · 조합 설계 (신규 추가는 후속)
- 리들리 + 엘리시: 작은 이웃 관찰(진짜 생물 방문/이동이 있을 때).
- 엘리시 + 엘레판: 서식처 미세환경 유지. 엘레판 차광 상한/자리를 우회하지 않는다.
- 엘리시 + 주렁: 운반된 유기물과 실제 접점이 맞을 때 미세 서식처 후보.
- 엘리시 + 보송: 실제 수분 조건에서 서식처 위치 안내.
- 엘리시 + 향후 슈퍼범: 실제 물 공급 거래가 성립할 때만 수분 서식처 조합. 새 물 생성 금지.
- 위 조합의 새 고유 애니메이션/도감 사건/환경 수치 보너스는 별도 수용 기준 전까지 **미구현**.

## ELL-AC · 수용 기준
1. 기존 봉봉 기본 실루엣 및 갈색 몸통과 두 세로 눈 유지. 엘리시 특징은 '생식엽 2 + 영양엽 1'로 보임.
2. 도감·초상·월드·선택 카드·방문 이름에서 '엘리시' 일치.
3. 새 강수 입력으로 엘리시 내부 저장수/친구 전달 0. 구 EC02 신규 발행 없음.
4. 진짜 이끼 수분·바위틈 물량·습도·거리 조건을 벗어나면 서식처 보너스 0.
5. 건강한 엘리시의 서식처가 참일 때만 돌돌이 후속 재방문 후보 확률 45%. 필수 생태 조건은 유지.
6. 저장 재개 시 user-custom name, 관계/성장, 이전 수분 및 도감 변동 없음.
7. 비/강풍/집기/전원 끄기 시 생태 효과 일시 중단, 상태·물·소품 원장 보존.
8. JS 단위/환경/리깅/UI 회귀, GitHub CI, APK 빌드·서명, 실기기 업데이트/저장 복구 순서로 검증. 증거 없는 '최종 적용' 선언 금지.

## 리스크와 후속
- 원래 `bonbon` 문자열은 과거 저장 파일·테스트 ID·출처 추적 때문에 제거가 아니라 호환 별칭으로 둔다.
- SRS v2.22 PDF의 구 봉봉/물 나눔 장은 그대로 유지되는 **이력**이다. 이 문서는 새 변경이 우선하는 v2.23 **개정안**이며 완전한 통합 PDF 대체본이 아니다.
- 모든 UI 스크린, 장비별 Canvas/WebView, 48dp 선택 영역, 성체/유체 모션은 실제 에셋 검수 후 별도 승인 필요.
