# APK1.2.8 · 새 입장 화면(안개가 걷히고 친구들이 걸어 들어옴), 켤 때 흰 화면이 먼저 뜨던 문제, 인게임 안개

2026-11-22. 사용자 요청: "여백의 숲 앱 눌렀을 때 입장하는 화면 디자인 좀 개선 … 브랜드 컨셉 잘 드러나고" → 시안 A(여백)·B(숲의 창)·C(밤의 숲) → "Abc 저 상태에서 좀 더 개선" → "트렌드 상 어떤 게" → 낮·밤 조합 시안("너무 폰스럽거나 유치하지 않게") → "낮 시안에서 리들리, 엘리시, 슈퍼범만 화면 좌측에서 화면 중앙으로 걸어오는 거지. 주변에 반딧불이 떠 있고. 낮인데 밤연출 … 숲에 들어가기 버튼은 확실하게 잘 보여야 함" → "안개가 천천히 걷히고 이 연출 좋은 듯" → "이걸로 일단 하고, 앱 켜자마자 흰색 화면 뜨더니 입장화면으로 드러가는 버그 … 디버깅해서 pr".

- **입장 화면(`index.html`·`forest.css`·새 `welcome.js`):** 잘린 옛 정원 그림과 반투명 흰 상자, 둥근 버튼을 없앴다. 종이 바탕에 해 질 녘 같은 금빛(위는 옅은 푸른 저녁빛, 아래는 노을빛), 옅은 고사리 액자, 오른쪽 세로 제목 '여백의 숲'·세로 부제·가는 세로 선·낙관 '숲', 왼쪽 위 MARGIN FOREST. 켜면 안개가 천천히 걷히며(2.6초) 제목이 떠오르고, 리들리 → 엘리시 → 슈퍼범이 화면 왼쪽에서 가운데로 걸어 들어와 나란히 선다(약 7초, 게임의 걷기 동작 그대로). 반딧불 16개가 금빛으로 떠다니고, 옅은 안개 띠가 계속 흘러간다. 버튼은 짙은 이끼색 띠(화면 폭 거의 전체, 안쪽 가는 테두리)로 2.4초부터 보이고, 아래에 지금 숲의 계절·시간·날씨. 화면을 누르면 연출을 건너뛰고 바로 마지막 장면. 동작 줄이기에서는 처음부터 마지막 장면으로 멈춰 있다. 렌더 전용(게임 기록을 읽거나 바꾸지 않음).
- **켤 때 흰 화면(원인):** 입장 화면이 `index.html`에서 `hidden`으로 시작하고, 스크립트 30여 개를 모두 읽은 뒤에야 나타났다. 그동안은 빈 앱 틀(머리글과 빈 월드)이 크림색으로만 보여 흰 화면처럼 보였고, 그 뒤 입장 화면이 갑자기 나타났으며 큰 배경 그림은 그보다 늦게 떴다. Android 쪽 창·WebView 배경색은 이미 같은 크림색이라 원인이 아니었다.
- **수정:** 입장 화면을 처음부터 보이게 두고, 종이·액자·제목·버튼은 HTML/CSS만으로 첫 화면에 그린다(배경 그림은 작게 줄인 전용 `welcome-paper.jpg` 22KB와 액자를 미리 불러옴). 첫 장면은 옅은 안개 너머로 제목이 이미 보인다. 걸어 들어오는 친구·반딧불·흘러가는 안개는 게임 그림이 다 불러와지면 시작한다.
- **인게임 안개(`world-effects.js` `fog`, 렌더 전용, 사용자 "인게임 안개 연출은 안개 느낌이 안듦" → 시안 C(먹빛 안개 덩어리) → "시야가 너무 안나오고 … 번지기" → "섞어봐" → "좋네"):** 화면을 가로지르던 옅은 가로 띠를 없앴다. 안개 낀 날은 화면 전체가 옅게 잿빛으로 가라앉고(곱하기 0.22), 크고 아주 흐린 안개 덩어리 5개가 천천히 흘러가며, 화면 가장자리에 조금 더 짙은 덩어리 12개가 모여 살짝 일렁인다. 가운데는 트여 있어 친구들이 보인다. 안개 세기(전환 포함)를 따른다. 덩어리 그림 3장을 처음 한 번만 만들고(흐림 필터는 그때만) 한 장에 그림 17번만 붙인다(크롬 약 0.17ms). 동작 줄이기에서는 멈춰 있다.
