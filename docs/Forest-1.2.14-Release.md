# APK1.2.14 · 비 올 때 호수 전체에 빗방울이 떨어지지 않던 문제

2026-11-22. 사용자 제보: "비 올때 호수 전체에 빗방울 떨어지지 않음."

- **원인(`scene.js` 호수 빗방울, 렌더 전용):** 빗방울 동그라미는 0.9.3에서 호수 물가가 x 1.25~1.75였을 때 만든 것이라, 그 좁은 띠(x 1.36~1.86)에만 흩뿌렸다. 0.9.5에서 호수가 x 1.5~3.0까지 넓어졌는데 빗방울 범위는 그대로여서 호수 가운데와 동쪽에는 빗방울이 하나도 없었다.
- **수정:** 빗방울을 호수 모양(가운데·반지름) 전체에 흩뿌리고, 넓어진 만큼 개수를 늘려 밀도를 예전과 같게 했다. 얼음 위에는 여전히 없고, 빗줄기 세기를 따른다. 렌더 전용(게임 기록·난수 불변).
- 저장 스키마·규칙 식별자 불변. 버전 1.2.14 / versionCode 100.

검증: 실제 scene.js 렌더로 호수 가운데 비교(`docs/qa-1.2.14/lake-rain-before-after.png`, 왼쪽 고치기 전 빗방울 없음 / 오른쪽 호수 전체), `render`·`lake`·`package` 통과. 전체는 CI. Android 실기기 미검증.
