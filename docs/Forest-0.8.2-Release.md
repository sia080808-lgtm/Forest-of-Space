변경 내용(`index.html`·`forest-app.js`·`forest.css`·`shelter.js`·Android `MainActivity.java`):
- **계절 표시:** 밤 화면에서 계절 칩 글자가 밝은 색이라 연한 바탕에 묻혔다. 글자를 늘 진한 먹색으로 그린다.
- **조경 모드 삭제:** 머리의 '게임/조경' 버튼과 전환을 없앴다. 조경 모드로 저장된 기록은 불러올 때 게임 모드로 돌아온다. 꾸미기 탭(배치)은 그대로다.
- **보기 버튼(하나):** '전체 보기' 큰 버튼 대신 오른쪽 위에 작은 반투명 아이콘 하나를 둔다(사용자 "두 개로 나누지 말고 한 개 버튼"). 평소에는 '전체 보기' 아이콘이고, 누르면 숲 전체를 보여 준다. 전체 보기 중에는 '기본 배율' 아이콘으로 바뀌고, 누르면 처음 화면 크기·정원 가운데로 돌아간다.
- **사진(카메라 아이콘):** 지금 화면 구도(확대·축소·끌어 본 그대로)의 월드만 사진으로 저장한다. 버튼·안내·카드는 사진에 들어가지 않고, 친구 선택 링도 빼고 찍는다. 찍을 때 화면이 살짝 하얗게 번쩍인다. Android는 갤러리 `사진/여백의 숲`에 PNG로 저장한다(`MainActivity.savePhoto`, Android 10 이상 MediaStore라 권한이 필요 없음). 브라우저에서는 파일로 내려받는다.
- **계절 표시 자리:** '여백의 숲' 제목 바로 옆으로 옮겼다.
- **안내 문구:** 늘 떠 있던 안내 말풍선을 없앴다. 손님이 찾아올 때, 친구가 목마를 때, 비가 오기 시작할 때, 바위틈에 작은 이웃이 왔을 때만 월드 하단 가운데에 5초 동안 떴다가 사라진다. 같은 안내는 상황이 바뀌기 전에는 다시 뜨지 않는다. 손님 안내는 떠 있는 동안 누르면 만남 화면으로 간다.
- **친구 수:** '6 / 5' 대신 '6명'으로 보여 준다(0.6.33부터 정원 인원 제한 없음).
- **함께 지낼 예정 명단:** 친구들 화면에서 뺐다. 쉼터 확장 판단은 이제 정원의 모든 친구를 다 자랐을 때 크기로 계산한다(예전에 저장한 명단도 함께 센다).
- 저장 스키마·규칙 식별자·게임 규칙 불변. 버전 0.8.2 / versionCode 60.
