# APK0.9.4 · 물가 이웃 도감, 물가에서 물 마시기

2026-11-20. SRS v2.33 초안 LK-07. 사용자 요청: "1, 2 ㄱㄱ"(물가 이웃 도감, 물가에서 물 마시기).

변경 내용:
- **물가에서 물 마시기(`objects.js` `lakeDrink`, `world.js` `shorePoint`):** 물가가 열리고 얼지 않았을 때, 목마른 친구는 물가가 샘터보다 가깝거나(샘터 거리의 0.8 안) 샘터 물이 거의 없으면(2 미만) 가장 가까운 물가로 걸어가 물을 마신다. 샘터와 같은 빠르기(분당 10)로 몸 물 65까지, 물가에서 최대 7분. 호수는 마르지 않고, 마신 양은 물 원장 `ledger.lake`(호수에서 들어온 물)로 남겨 물 합계가 맞는다. 겨울 얼음 위에서는 마시지 않는다. 카드 "목이 말라 호수 물가로 가고 있어요" / "호수 물가에서 물을 마시고 있어요".
- **물가 이웃 도감(`forest-app.js`):** 도감 '작은 이웃' 탭 아래에 '물가 이웃' 7종(소금쟁이·물달팽이·개구리·잠자리·물방개·송사리·장구벌레). 호수에 한 번이라도 나타나면 게임 그림(동작 그림 첫 칸)과 설명이 채워지고, 아직이면 실루엣과 "아직 못 만났어요". 개구리는 알·올챙이·개구리, 잠자리는 애벌레·잠자리 중 하나만 봐도 채워진다. 물가가 닫혀 있으면 "숲 동쪽 물가가 열리면 만날 수 있어요". 기록은 `world.lake.seen`(이번 버전부터, 그 전에 왔다 간 이웃은 다시 나타나면 채워짐).
- 저장 스키마·규칙 식별자 불변(저장에 `world.lake.seen`, `ledger.lake`, 산책 기록의 `lake` 추가, 없으면 그대로 불러옴). 버전 0.9.4 / versionCode 70.

검증: `lake.test.cjs` LK-08(목마른 친구가 물가로 가서 물 위가 아닌 물가에서 마심·원장 기록·저장 검증, 얼면 없음, 이웃 기록, 잘못된 기록 거부), 관련 `stroll`·`shelter-sleep`·`objects219`·`rain-splash221`·`package` 통과, UI PASS(작은 이웃 10종 검사는 물가 이웃을 빼고 셈). 전체는 CI. 화면 `docs/qa-0.9.4/runtime/lake-dex.png`(실제 앱 Chromium). Android 실기기 미검증.
