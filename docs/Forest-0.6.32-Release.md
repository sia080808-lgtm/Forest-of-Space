# APK0.6.32 · 작은 이웃 도감에 그림, 주렁→코로나

2026-11-18. 사용자 제보: "곤충이 나와도 도감이 채워지지 않음". 추가 요청: "주렁 이름은 코로나로 변경".

- **작은 이웃 도감:**
  - 진단: 기록(`objects.creatures.seen`)은 정상이었다. 실제 앱(Chromium)에서 이웃이 온 저장으로 확인했다.
  - 문제는 화면이었다. '작은 이웃' 탭은 글만 있는 카드였고, 만난 이웃과 못 만난 이웃의 차이가 작은 "아직 못 만났어요" 표시 하나뿐이어서 채워진 느낌이 없었다.
  - 이제 만난 이웃은 게임 그림(`assets/forest/creatures`)을 보여 준다. 못 만난 이웃은 옅은 그림자 실루엣과 회색 카드로 보인다. 맨 위에 "만난 이웃 n / 10"을 보여 준다.
  - 기록은 0.6.28부터 시작했다. 그 전에 왔다가 떠난 이웃은 다시 와야 채워진다.
- **주렁 → 코로나:** 종 이름을 *Platycerium coronarium*에 맞춰 '코로나'로 바꿨다(도감·방문·영입 목록).
  - 저장된 주렁은 사용자가 이름을 바꾸지 않았다면 불러올 때 '코로나'가 된다. 입구에서 기다리는 손님도 같다.
  - 별명은 그대로 두고, 내부 종 키 `jureong`도 바꾸지 않는다(0.6.30 베이치와 같은 방식).
- 저장 스키마·규칙 불변. 버전 0.6.32 / versionCode 49.

검증: 자동 274/274, DOM UI PASS. 추가한 검사:
- `ui-smoke`: 작은 이웃 10개 항목, 만난 1종만 채워짐, 모든 항목 그림, "만난 이웃 1 / 10"
- `names-030`: 코로나 이름과 저장 이전
