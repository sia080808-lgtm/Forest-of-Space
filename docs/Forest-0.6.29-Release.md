# APK0.6.29 · 슈퍼범: 빗물 모으기와 물 나눔, SRS v2.26

2026-11-18. 사용자 요청: "자 이제 수퍼붐 만들자". 그림은 사용자가 승인한 회종안을 그대로 쓰고("이거랑 똑같이"), 크기는 리들리의 1.7배다("엘레판보다 커 보여야지"). 레이어 순서는 사용자 지시대로 얼굴 → 다리·눈 → 양 옆 잎 → 머리 잎이다. 전체 규칙은 `docs/Forest-Superbum-SRS-v2.26.md`에 있다(PDF `docs/Forest-Superbum-SRS-v2.26.pdf`).

- **그림:** 회종안 두 그림(마른 둥지·물 고인 둥지)에서 원본 픽셀 그대로 레이어 6장씩을 땄다(`tools/cut-superbum.py`, `tools/rig-superbum.py`).
  - 레이어: 넓은 둥근 얼굴, 몸에 붙은 두 발, 볼을 덮는 양 옆 잎, 맨 위의 머리 잎이다.
  - 가려진 부분은 같은 부위의 원본 픽셀로만 채웠다.
  - 둥지 물(`V/40`)이 0.12 이상이면 '물 고인 둥지' 그림으로 바뀌기 시작해 0.3이면 완전히 바뀐다.
- **모션(`superbum.js`):** 가만히, 걷기·천천히·서두르기, 달리기, 들어 올림, 쉬기·잠·이끼, 잎 정돈, 물 마시기, 물장구, 빗물 모으기, 물 나눔.
  - 옆잎은 볼에 붙은 채 아래쪽만 휜다.
  - 물이 있으면 머리 잎을 평평하게 들고 조심조심 걷는다. 달리거나 들리면 물방울이 떨어진다.
- **빗물 모으기:** 둥지잎에 실제로 내린 비를 1초에 최대 0.1씩, 40까지 모은다. 받은 양은 강수 원장에 기록해 물 보존식을 지킨다. 쉼터 안·목부작·들린 상태에서는 모으지 않는다.
- **물 나눔(A04):**
  - 둥지 물이 10을 넘는 건강한 슈퍼범이 몸 물 35 미만인 친구에게 다가가 나눈다. 한 번에 2씩, 한 번 나눌 때 합계 10까지다.
  - 비에서 모은 물을 나누면 EC02 발견 기록이 남는다.
  - 엘리시는 계속 모으지도 나누지도 않는다. 엘리시가 주던 옛 A04 기록은 은퇴로 끝난다.
- **쉬기:** 쉼터 자리는 성장 단계에 따라 5/6/8/10을 차지한다.
  - 다 자라면 넓힌 쉼터(2단계 이상)부터 들어간다. 맞는 휴식 자리가 없어서 지칠 때는 둥지잎을 접고 제자리에서 쉰다(분당 1.5, 75까지).
  - 이 규칙이 없으면 체력이 평균 40에 머물렀다. 넣은 뒤에는 평균 66이었다.
- **영입:** 샘터 물이 30% 이상이고 샘터로 가는 길이 열려 있으면 찾아온다(180초 → 35%, 세 번 놓치면 보장). 첫 손님이 엘리시인 규칙은 그대로다.
  - 첫 만남 단계: 익숙해지기 30초, 샘터 살피기, 하늘 올려다보기, 쉬기 20초.
  - 초상화와 도감 항목을 새로 넣었다.
- 저장 스키마 버전 불변. 버전 0.6.29 / versionCode 46.
