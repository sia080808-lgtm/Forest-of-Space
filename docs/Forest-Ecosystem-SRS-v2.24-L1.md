## 규칙

| ID | 내용 |
|---|---|
| L1-01 섹터 | 월드 좌표 x 0.08~0.92, y 0.15~0.91을 4열×3행, 12개 고정 섹터로 나눈다. 카메라 줌과 무관하다. |
| L1-02 낙하 | 매초 `P = 1 − exp(−하루한도 × F / 1200)` 확률로 한 장(L=1)씩 떨어진다. 하루 한도는 20/30/40(낙엽 자리 레벨). 하루 시작에만 `arrivedToday`를 초기화한다. 떨어지지 못한 잎을 나중에 몰아서 주지 않는다. 독립 난수 `rng.litter`를 쓰므로 기존 날씨·행동 난수는 바뀌지 않는다. |
| L1-03 배율 F | `F = min(2, max(날씨, 바람))`. 날씨: 맑음·흐림 1, 약한 비 1.1, 강한 비(강도 0.6 이상) 1.2, 안개 0.85, 눈 0.6. 바람: 45~59는 1.5, 60 이상은 2. |
| L1-04 착지 | 수용 여유가 있는 섹터를 가중 추첨한다. 기본 1, 바람이 불어 가는 쪽 3개 섹터는 2. 섹터 안에서 걸을 수 있는 땅을 고르며, 샘터·지형 오브젝트·쉼터·다른 더미 근처는 피한다. 8번 시도해도 자리가 없으면 그 잎은 버린다. 이때 하루 한도는 차감하지 않고 `missed`에 기록한다. |
| L1-05 상한 | 바닥 낙엽(낱잎 + 더미 L + 더미에서 들고 간 잎) **40**, 한 섹터 **12**. 이 기준이 낙하를 막는다. 영양 U는 낙하를 막지 않는다(P0-2 해결). |
| L1-06 더미 | 낱잎이 한 섹터에 5장 쌓이면 다섯 번째가 떨어지는 순간 그 섹터에 더미 하나가 생긴다(L=5). 섹터당 더미는 하나다. 더미가 있는 섹터에 떨어진 잎은 더미 L에 더한다. 더미는 L<1이고 U>0이면 '낮은 부식층'으로 표시한다. L=U=0이고 이용·운반 예약이 없을 때 사라진다. |
| L1-07 분해 | 분해는 **더미와 기존 낙엽 자리에서만** 일어난다(P0-1). 낱잎은 분해되지 않는다. 각 더미에 `0.5 × Fm × Fplay` L/분을 따로 적용한다. Fm은 기존 계수이고, 더미의 물기는 가장 가까운 지형 패치의 M·고인 물 W를 따른다(P0-3). Fplay는 그 더미에서 놀고 난 뒤 120초 동안 3이다. 분해는 L→U로 1:1 옮긴다. |
| L1-08 영양 상한 | 숲 전체 U(더미 + 기존 자리)의 상한은 낙엽 자리 레벨 용량(100/150/200)이다. 넘는 분해량은 흙으로 스며든 유출(`ledger.soil`)로 기록한다. 그래서 U가 가득 차도 분해와 낙하가 멈추지 않는다. |
| L1-09 바람 이동 | 바람이 60 이상이면 10초마다 낱잎마다 한 번씩 판정한다(60~69는 18%, 70 이상은 30%, 이동 후 30초 쿨다운). 바람이 불어 가는 쪽 이웃 섹터로만 옮긴다. 가장자리 섹터의 잎은 맵 밖으로 나가지 않는다. 더미는 움직이지 않는다. |
| L1-10 이용 | 낙엽 놀이와 영양 흡수는 실제 더미로 가서 한다. 후보는 가까운 더미 2개와 기존 낙엽 자리다(길찾기 비용 때문에 2개로 제한). 들고 간 0.5 L은 그 더미에서 빼고, 끝나면 같은 더미로 돌려놓는다. 더미 공간은 4포인트다. 확장 진행도는 낙엽 자리에 함께 쌓인다. |
| L1-11 보존식 | `바닥 L + 기존 자리 L + 전체 U + 운반 + 누적 흡수 + 누적 흙 유출 = 초기 + 누적 낙하`. 검사 `tools/litter-review.cjs`, `tests/forest/litter-sectors.test.cjs`. |
| L1-12 새 게임 | 낱잎 3장(바람이 불어 가는 쪽 섹터에 2장, 다른 섹터에 1장)과 기존 낙엽 자리 U10으로 시작한다. 기존 70/30 시작값은 새 게임에서 쓰지 않는다. |
| L1-13 기존 저장 | 처음 불러올 때 한 번만, 기존 낙엽 자리 L을 가장 가까운 섹터부터 **더미 3개(각 12)**로 옮긴다. 남은 L과 U는 기존 자리에 둔다. 이 자리는 '거름 자리'로 계속 쓰며 낙하를 막지 않는다. 예: L70/U30 → 더미 12·12·12, 기존 자리 L34/U30. 합계 100은 그대로이고, 첫 낙하는 120초 안에 일어난다. |
| L1-14 화면 | 낱잎은 지형 그림의 잎 조각 한 장이다. 더미는 L만큼의 잎을 낮게 쌓은 모양이고, 아래에 U만큼 거름 점을 찍는다. 더미를 누르면 카드가 열린다(L·U·바닥 낙엽 40 기준·분해 속도·오늘 낙하). 렌더는 상태와 난수를 바꾸지 않는다. |
| L1-15 조경 | 정원 배치를 바꾼 뒤 돌·샘터에 덮인 낱잎이나 더미는 같은 섹터의 빈 자리로 옮긴다. |

## 초안 대비
- 기존 L70 이전: 초안 검토는 '더미 최대 5개'였으나 3개(36)로 줄였다. 5개(60)로 옮기면 바닥 L이 40을 넘어 첫 낙하까지 1~1.6게임일이 걸렸다(시뮬레이션). 3개면 120초 안에 낙하한다.
- 기존 낙엽 자리는 거름 자리로 남기고 낙하 판정에서 뺐다. 결정 "바닥 낙엽 L만"의 대상은 섹터의 낱잎·더미다.
- U 상한을 넘는 분해량을 흙으로 유출: 초안에는 없던 규칙이다. U 상한 때문에 낙하가 다시 막히는 것을 피하려고 넣었고, 자원을 새로 만들지 않는다.
- 섹터 낙엽 상한: 레벨과 관계없이 40으로 둔다(초안 L04).
