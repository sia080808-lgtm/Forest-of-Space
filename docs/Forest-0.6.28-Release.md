# APK0.6.28 · 쏙쏙이·돌돌이, 식물과의 관계, SRS v2.25 작은 이웃

2026-11-18. 사용자 요청: "다 넣고, 얘네들 생태계 로직 같은 것도 설정 다 하고 식물들과의 메커니즘도 다 넣고 SRS에 정리하고 업데이트하자". 전체 규칙은 `docs/Forest-SmallNeighbours-SRS-v2.25.md`에 있다(PDF `docs/Forest-SmallNeighbours-SRS-v2.25.pdf`, 6쪽).

- **쏙쏙이**(Dalotia coriaria, 반날개)
  - 두 번째 뿌리 천적이다. 뿌리날파리 유충·알 5 이상, 물 빠진 촉촉한 흙, 바위틈·햇살 바위 은신처(0.3 안)가 있으면 ECO-07로 온다.
  - 분당 최대 8 먹는다. 흙지기와 같은 자리에서는 둘이 합쳐 분당 12까지다(ECO-08 구역 합계).
  - 대체 먹이가 없어 먹이가 없으면 120초 뒤 떠난다(ECO-12). 최대 2무리.
  - 화면: 젖은 낙엽 주변을 찾아다니다 바위 뒤로 쏙 숨었다 나온다.
- **돌돌이**
  - SRS 시트 그림(걷는 모습·말린 공)으로 바꿨다. 바위틈 앞을 천천히 걷다가, 친구가 0.08 안에 오거나 바람이 60 이상이면 공처럼 말린다.
  - 머무는 동안 바위틈 0.25 안 낙엽 자리의 분해를 ×1.1 돕는다(분해자). 방문 규칙은 그대로다.
- **식물(친구)과의 관계**
  - 자기 잎에 잎응애나 솜깍지가 있으면, 자유 행동에서 잎 정돈 확률이 25%에서 55%가 된다.
  - 잎응애가 있으면 그늘·샘터를 먼저 고른다.
  - 뿌리날파리 유충이 사는 낙엽에서는 놀지 않고, 영양을 먹을 때도 그곳을 마지막으로 고른다.
  - 엘레판이 펼친 잎 아래 친구의 잎은 그늘 식물 아래처럼 마르지 않는다.
  - 기존 난수 추첨을 그대로 써서 재현 가능하다.
- **도감:** 작은 이웃 10종 모두에 이름·분류·하는 일을 보여 준다. 실제로 숲에 온 적이 없으면 "아직 못 만났어요"로 표시한다(`objects.creatures.seen`).
- **그림:** 원본 픽셀 그대로 GrabCut으로 땄다(`tools/cut-neighbour-grabcut.py`).
  - 돌돌이 다리는 흙과 색이 같아 엉덩이에서 발끝까지 손으로 짚은 마스크를 썼다.
  - 다리·더듬이 리그를 더했다(돌돌이 다리 7·더듬이 2, 쏙쏙이 다리 4·더듬이와 입 3).
- 저장 스키마 버전 불변. 버전 0.6.28 / versionCode 45.
