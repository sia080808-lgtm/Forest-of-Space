# APK0.6.19 · 엘리시 잎 가장자리 선 제거, 눈 쌓임

2026-11-17. 0.6.18 검토에서 남긴 한계 2건 수정.

- 잎 가장자리: 들어 올리거나 걸을 때 영양엽이 들리면 왼쪽 가장자리에 가는 어두운 선(영양엽 밑에 숨어 있던 몸통 테두리)과 크림색 테두리(원화 배경이 남은 반투명 가장자리)가 보였다. `tools/defringe-ellisii.py`로 다섯 레이어의 크림색 가장자리를 지우고 남은 부드러운 가장자리를 안쪽 물감 색으로 다시 칠했으며, 영양엽에 덮인 몸통 테두리(위쪽, 10px)를 잎 안쪽으로 넣었다. 잎 끝 아래 몸통은 그대로 둔다. 초상화를 다시 구웠다.
- 눈 쌓임: 다른 종 잎과 같은 마스크(`ForestEffects.snow`)로 엘리시의 생식엽·영양엽 윗면에 눈이 쌓인다. 렌더 전용.
- 그림 모양·모션·저장 스키마·종 ID·규칙 불변. 버전 0.6.19 / versionCode 36.

검증: 자동 220/220(`ellisii-legacy` 5번째 검사: 레이어 가장자리 크림색 화소·눈 쌓임 — 수정 전 레이어에서 몸통 957화소로 실패), DOM UI PASS. 들어 올림 4개 위상 전후 비교·눈 쌓임 렌더 `docs/qa-0.6.19/runtime`. Android 실기기 미검증.
