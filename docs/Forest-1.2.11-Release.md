# APK1.2.11 · 관리자 '날씨 고정'에서 강풍이 약해지던 문제

2026-11-22. 사용자 질문(SRS v2.38 남은 결정): 강한 바람이 90초 뒤 45로 약해지는 규칙, 촉촉한 숲 겨울 맑은 날을 추위로 볼지 → "뭐가 합리적임?" → 추천(보통 게임 규칙은 그대로, 관리자 고정만 고치기, 촉촉한 숲 겨울은 그대로) → "ㅇㅋㅇㅋㄱㄱ".

- **원인(`forest-app.js` 관리자 날씨 고정):** 날씨 고정은 날씨가 바뀌기까지 남은 시간만 늘려 두었다. 그런데 바람 60 이상이 90초 이어지면 45로 약해지는 규칙(`environment.js`)은 따로 돌아서, 관리자로 강풍을 걸고 고정해도 90초 뒤 약해졌다. 강풍 대피를 오래 지켜볼 수 없었다.
- **수정:** 날씨 고정이 켜져 있는 동안은 강풍이 이어진 시간을 0으로 맞춰, 고정을 풀 때까지 강풍이 그대로 분다. 보통 게임(고정 안 함)은 예전처럼 90초 뒤 45로 약해진다(돌풍은 잠깐, 오래 거센 날씨는 폭풍이 맡음).
- **그대로 둔 것(사용자 결정):** 촉촉한 숲 겨울 맑은 날(기온 43)은 추위로 치지 않는다. 눈 오는 날은 지금처럼 추위로 친다.
- 저장 스키마·규칙 식별자 불변. 버전 1.2.11 / versionCode 97.

검증: `admin-panel` 1.2.11 검사(고정한 강풍은 300초 동안 60 이상 — 엔진 측정 75 유지, 고정 안 하면 45로 약해짐; 앱 틱에서 고정 중 타이머를 되돌리는지), `admin`·`package` 통과. 전체는 CI. Android 실기기 미검증.
