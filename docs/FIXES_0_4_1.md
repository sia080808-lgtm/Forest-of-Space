# 0.4.1 렌더링·음향 수정

- 휴식 시 원래 눈 위에 추가한 눈 선과 0.84 세로 압축을 제거했다. 원본 얼굴과 체형을 유지하고 작은 호흡 움직임을 사용한다. 전용 감은 눈 표정은 후속 분리 에셋 제작 대상이다.
- 잎 정돈 시 복사 팔을 덧그리는 코드를 제거했다. 양팔은 원본 두 개를 유지하며 몸과 잎을 가볍게 움직인다. 실제 팔을 들어 머리를 쓰다듬는 동작은 부위 분리 후 적용한다.
- 젖은 바닥의 긴 타원 회전을 제거하고 세로 반경을 줄였다. 물기와 실제 고인 물의 파문은 유지한다.
- 물 전달량만으로 급수음을 내지 않는다. 샘터를 목표로 실제 drink 동작을 할 때만 효과음을 낸다. 쉼터 돌봄의 수분 회복량과 저장 상태는 유지한다.
- 설정 아이콘은 중심이 같은 8개 대칭 톱니와 원형 허브로 변경했다. 버튼 48×48, SVG 24×24, 축소 없는 고정 비율을 지정했다.

44개 자동 검사와 DOM 입력 하네스 통과. 추가 렌더링 회귀 검사는 휴식 얼굴 덧그림/압축, 정돈 시 추가 팔 이미지, 바닥 타원 기울기, 쉼터 회복과 샘터 급수의 음향 조건을 검사한다. 실제 Canvas 코드로 확대 포즈·정원·SVG 톱니 이미지를 생성해 확인했다. 전체 브라우저와 Android 실기기 검수는 미수행이다.

APK는 versionCode 6, 동일 패키지·기존 인증서 유지. 새 코골이·수면 효과음은 추가하지 않았다.
