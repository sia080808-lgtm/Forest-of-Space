# APK 0.6.6 · SRS v2.18 구현 및 검수

2026-11-16. 사용자 승인 ENV218 색감과 네 가지 업데이트를 적용했다. 같은 패키지 `com.ridleydesk.mobile`, versionCode 23, 기존 개인 인증서 서명으로 배포한다.

## 이번 구현

- 친구: 6종 환경 조건, 독립 영입 난수와 실패 보장, 목표 지정, 1명 방문, 별도 만남 장면. 준비 30초 후 실제 목적지 이동과 물/낙엽/햇빛/그늘/휴식 행동을 거쳐 정착한다. 정착 거래는 중복·50명 한도·저장 실패를 검사한다. 편성 한도 5명은 정착과 분리했다.
- 확장: 현재 점유뿐 아니라 성체 예상과 사용자 확인 예정 명단(최대 5명)을 계산한다. 어린 리들리와 엘레판은 현재 1.5공간이어도 성체 3공간 수요로 확장을 해금한다. 권한은 유지한다.
- 쉼터: 실제 노출 기반 긴급/회복/일반 우선순위, 지속되는 요청 ID와 대기 시간, 회복 10초와 안전 출구 확인, 정상 30초 점유/60초 대기 양보, 다음 손님 우선권, 완전 퇴실 후 공간 반환, 재입실 유예 60초. 성장으로 넘치면 안전하게 나올 때까지 표시 크기를 보류한다.
- 환경: 4기후와 시기별 가중치, 5기본 날씨와 바람/태풍, 20/60/30초 태풍 단계, 10초 날씨 전환, 30초 예고/60초 기후 전환. 눈/응결/융해는 물 원장에 포함하고 비/눈은 한 강수 예산에서 나눈다. 친구 머리의 눈은 개체와 함께 이동하며 정돈 시 떨어진 눈도 보존한다. 지붕 융해수는 가장자리 배수로 넘긴다.
- 화면: 승인한 6시간대×7날씨의 명도·채도·색조를 전체 월드 버퍼에 한 번 적용한다. 배경 연장, 물, 지형, 앞테두리, 캐릭터 파츠, 지연 후드, 집기가 모두 포함된다. 선택과 발광, HTML 정보 화면은 뒤에 합성한다. 파츠 상단 적설, 눈/비, 안개, 강풍 낙엽을 연결했다.
- 원형: 엘레판 최종 5레이어/1.5배 유지. 봉봉·보송·주렁은 기존 v2.12 파츠를 이식했다. 두리는 기존 분기잎 원형과 공통 온전한 몸통 리그를 사용했다. 주렁/엘레판은 팔이 없고 보송 팔은 몸통 뒤다. 실제 원형의 윤곽으로 신규 종 쉼터 형상 프로필을 만들었다.
- 음향: 기존 환경음 재사용, 폭풍 절정 음악 약 5dB 감쇠, 눈 접지 3개와 눈 정돈 3개의 낮은 음량 변형 제작 및 접점 연결. 새 비명/천둥 섬광은 없다.

## 실제 확인한 근거

- 기존 포함 자동 검사 153개 통과 + 추가 경계 검사 4개 통과: 총 157개 고유 검사. 추가 4개는 6종 환경 누락, 50명 정착 보존, 큰 친구를 위한 순차 양보, 이동하는 머리 적설 보존을 검사한다.
- 10,000tick 눈·안개·융해 물 보존 오차 1e-6 이내, 12시간 기존 생태 회귀. 동일 시드·가시성 독립과 이전/저장 롤백.
- 실제 Canvas 42개 날씨/시간 조합, 6종 원형, 30프레임 렌더 상태 불변 검사. 관리자 선택 42조합은 실제 저장을 변경하지 않았다.
- UI smoke: 기존 집기·배치·백업·쉼터 화면, 신규 영입 조건·만남·시계 정지·정착·예정 명단·관리자 흐름 통과.
- WAV 길이·피크·해시 검사. 실제 Android 기기에서 설치, 프레임 P95, 청음과 사용자 체감은 미실행이다.

## 검증 범위와 남은 항목

AC218은 하위 조건 묶음이다. 자동 157개를 AC218 전체 조건의 실기기 통과로 간주하지 않는다. 전체 기후의 장기 통계 분포, 모든 장애물 배치의 출입 경로, 12이웃 최대 부하, 모든 클립의 눈 마스크 접점과 음향 청음은 추가 기기 검수가 필요하다. `Acceptance-218.csv`에서 확인/부분 확인을 구분한다. 방문 장면의 종별 필수 행동은 구현됐으며 전체 월드 협동·기존 미연결 성격 부모 행동 전부가 완료된 것은 아니다.
