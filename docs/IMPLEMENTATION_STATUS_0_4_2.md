## 남은 검수·후속 범위

Android 실기기 업데이트 설치, 물리 dp·핀치·상단 들기 보정, 장시간 플레이, 배터리·발열·메모리·오디오 포커스·체감 품질은 미관측이다. 브라우저 전체 UI 실행은 socket 제한으로 불가했다. CodeQL을 이번 작업에서 실행하지 않았으며 통과라고 주장하지 않는다.

대표형 제한 모션과 명세 기획 시트는 유지한다. 6종·4성장·모든 방향의 파츠별 완성 에셋, 사회 행동·전체 기후·34개 음향 큐 완성은 후속 범위다. REV-AC-01~14 전체 통과를 주장하지 않는다.
