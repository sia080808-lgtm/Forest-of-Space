# 여백의 숲 · SRS v2.25 변경안 ELL1 — 첫 손님 엘리시, 두리 방문 제외

2026-11-18. 적용 APK: 0.6.22(엘리시 서식 조건), 0.6.23(두리 제외·첫 손님). 통합 명세 PDF는 아직 v2.22이며, 아래 표의 쪽을 이 문서대로 읽는다.

## 사용자 결정
- 2026-11-18 "두리 빼자. 그 자리를 엘리시로 대체."
  - 두리(*P. bifurcatum*)는 전용 승인 시안이 없었다. 리들리 몸통에 분기잎만 얹은 형태였다.
  - 그래서 방문·영입 후보에서 뺀다.
- 2026-11-18 "ㄱㄱ": 엘리시 서식 조건을 현재 이끼 규칙에 맞게 바꾼다(아래 ELL1-03).

## 규칙

| ID | 내용 |
|---|---|
| ELL1-01 두리 은퇴 | 두리는 방문 후보, 영입 목록, 첫 손님에서 빠진다(`Recruitment.retired=['duri']`). 이미 함께 사는 두리는 삭제·변환하지 않으며, 리그·초상화·도감도 유지한다. 도감에는 함께 사는 두리가 있을 때만 보인다. |
| ELL1-02 첫 손님 | 첫 방문(`serial=0`) 전에는 엘리시만 후보가 된다. 게임 240초 이후 엘리시 조건이 맞고 안전하면 바로 찾아온다(35% 추첨 없음). 1,200초가 지나도록 첫 방문이 없으면 다른 친구도 후보가 된다. |
| ELL1-03 엘리시 서식 | 아래 조건을 모두 만족해야 한다. 같은 기준을 영입과 잎틈 정원(돌돌이 재방문 30→45%)에 쓴다. 이끼 촉촉함 상한 75%는 없앤다. 이끼가 물을 5만 머금어 비 한 번이면 100%가 되므로 상한을 두면 거의 성립하지 않는다(8시드×3게임일 시뮬레이션에서 충족 1~3%). |
| ELL1-04 기존 저장 | 엘리시가 아직 없으면, 입구에서 기다리던 두리 손님이나 대기열의 두리는 엘리시 방문으로 바뀐다. '먼저 기다리기' 대상이 두리였다면 해제한다. 진행도·실패 횟수는 보존한다. |
| ELL1-05 안내 | 친구들 화면에 엘리시 조건 5항목과 현재 값을 보인다. 조건이 180초 이어지면 35% 확률로 찾아오고, 세 번 놓치면 다음에는 반드시 찾아온다는 점도 안내한다. 손님이 입구에서 기다리는 동안 준비 시간이 멈춘다는 안내도 보인다. |

ELL1-03 엘리시 서식 조건:
- 이끼 촉촉함 40% 이상
- 지금 큰비(강수 0.6 이상)가 오지 않음
- 바위틈 고인 물 5 미만
- 이끼와 바위틈 사이 거리 0.32 미만
- 입구에서 이끼와 바위틈까지 가는 길이 열려 있음

## 검증
- APK 0.6.22: 수정 전 코드에서 4시드 중 엘리시 방문 0건, 수정 후 3건 이상. 8시드×3게임일 시뮬레이션에서 7시드는 3~12분, 1시드는 약 71분 뒤 방문.
- APK 0.6.23: 새 게임 8시드 모두 첫 손님이 엘리시(180~240초). 저장 이전 확인(기다리던 두리 → 엘리시, 함께 사는 두리 보존). 자동 231/231, DOM UI PASS.
- 미검증: Android 실기기. 통합 PDF 재조판은 하지 않았다(이 문서가 해당 쪽을 대체).
