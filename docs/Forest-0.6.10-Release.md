# APK0.6.10 · SRS2.20 객체별 정보 카드

2026-11-16. 사용자가 오브젝트 클릭 시 각기 해당하는 수치 표시를 승인했다. 7종 카드가 실제 상태를 읽도록 적용했다. 라이브 자원 규칙은 SRS-2.19-objects를 유지하며 저장 스키마를 바꾸지 않는다.

- 낙엽: 놀이용 L, 거름 U, 전체 용량, 운반/뿌리 보관분을 뺀 빈공간. 현재 분해 속도와 촉진 시간, 오늘 유입/한도 및 더 들어올 수 있는 양.
- 이끼: 실제 저장수·사용/전체 공간·예약·기분/체력의 분당 회복과 상한. 물이0이어도 안전한 환경에서 회복 가능.
- 샘터: 현재 물/확장 용량·실제 유입·음수 속도·물장구 최소량. 잎 그늘: 빛/비 차단·그늘의 실제 빛·회복. 바위·바위틈: 각각 젖음/배수, 고인물/방향별 바람 및 회복.
- 쉼터: 사용·예약·빈 공간과 실제 입실 인원 구분. 성체 리들리1, 엘레판2공간 설명. 기존 확장·추가·옮기기·보관 유지.
- 핵심 수치4개 뒤 조건 상세를 접어 둔다. 라이브 갱신에서 펼침·스크롤·요약/버튼 포커스를 유지하고 값이 같으면 DOM을 재작성하지 않는다. 다른 객체를 누르면 접힘/스크롤을 초기화한다.
- 작은 양수는 0으로 오인하지 않도록 0.1 미만으로 표시한다. UI는 자원·난수·저장에 쓰지 않는다. 낙엽 분해 표시와 고정 단계가 같은 계산을 공유한다.

검수: 32개 대상 자동 검사 통과 및 DOM UI 흐름 통과. docs/qa-0.6.10 참조. 이번 카드의 브라우저 픽셀 검수는 Chromium 프로세스/로컬 접근 환경 제한으로 미완료다. Android 설치·터치·큰 글자·회전·성능·야간 실제 화면·청음도 미검수다. DOM 테스트를 실제 레이아웃 확인이나 CodeQL로 보고하지 않는다.
