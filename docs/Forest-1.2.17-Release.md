# APK1.2.17 · 리들리가 머리를 쓰다듬으면 자기 잎도 스킬 수치만큼 털어 냄

2026-11-23. 사용자 질문 "리들리 자기는 자기 스스로 못 터나" → "리들리가 스스로 머리 쓰다듬으며 터는 능력은 다른 친구들은 없는 능력인가?"(아니다: 머리 정돈은 모두 같은 효과, 한 번에 약 0.5) → "리들리 자기 머리 쓰다듬는 능력만 자기 고유 스킬 수치를 따라가도록 하자. 레벨업별".

- **변경(`skills.js` `selfBrush`, `engine.js`):** 리들리가 머리 정돈(손으로 머리 쓰다듬기, 8초)을 마치면 자기 잎의 잎응애·솜깍지를 '잎 털어 주기'와 같은 레벨별 양만큼 털어 낸다: Lv1~2 15, Lv3~5 30, Lv6~8 50, Lv9 75, Lv10 전부. 대기 시간도 같은 표(Lv1~8 180초, Lv9~10 120초)지만 친구를 털어 주는 대기와 따로 센다(자기 잎을 털어도 친구를 도와주는 데 막히지 않음). 기운은 털어 주기처럼 1 쓴다. 벌레가 없으면 쓰지 않는다.
- 다른 친구의 머리 정돈은 그대로(한 번에 약 0.5). 친구 자세히 보기·도감의 고유 스킬 설명에 "머리를 쓰다듬어 정돈할 때는 자기 잎도 같은 만큼 털어 내요", 수치 줄에 "(자기 머리 정돈도 같음)".
- 저장 스키마·규칙 식별자 불변(친구 스킬 대기 기록에 `self` 추가). 버전 1.2.17 / versionCode 103.

검증: `skills` 1.2.17 검사(Lv1 15·남은 만큼만·대기 180초·친구 털어 주기 대기와 따로·리들리만·엔진에서 정돈이 끝날 때 실행), `skills`·`admin-panel`·`leaf-mites`·`soil-and-mealy`·`pest-spread`·`rig`·`package` 통과, UI PASS. 전체는 CI. Android 실기기 미검증.
