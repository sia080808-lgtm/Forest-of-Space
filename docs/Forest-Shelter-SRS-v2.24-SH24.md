# 여백의 숲 · 기본 쉼터 3명 (SRS v2.24 SH24 변경안, APK 0.6.17 구현)

- 근거: 사용자 확정 원칙 "초기 기본 쉼터에서 일반 성체 최대 3명 동시 휴식, 실제 크기·입구·충돌 제약은 유지", 생태계 SRS v2.24 초안 A04(ECO24-A04), 이슈 #15 검토.
- 상태: **구현·자동 검증 완료(0.6.17)**. 422쪽 통합 PDF(v2.22)는 아직 덮어쓰지 않았다. 통합 시 아래 조항을 교체한다.

## SH24-01 용량과 인원

| 쉼터 단계 | 공간 포인트 | 성체 리들리 환산 | 동시 인원 상한 |
|---|---:|---:|---:|
| 기본(레벨1) | 12 | 3공간 | 3명 |
| 넓은(레벨2) | 16 | 4공간 | 4명 |
| 큰(레벨3) | 24 | 6공간 | 5명 |

- 입실은 **두 조건을 모두** 만족해야 한다: `남은 포인트 ≥ 성장 단계 점유` AND `현재 입실·예약 인원 < 인원 상한`. 형상(내부 폴리곤에 몸과 잎 전체)·다른 친구와의 겹침·입구 경로 검사는 그대로다.
- 성장 단계 점유는 그대로 유지한다: 일반 종 2/3/4/4, 엘레판 4/5/6/8.
- 예: 성체 일반 3명 = 12/3명(허용). 성체 엘레판 + 성체 일반 1명 = 12/2명(허용). 성체 엘레판 + 성체 일반 2명 = 16(거절). 어린 일반 4명 = 8포인트지만 인원 상한 3으로 1명은 밖에서 기다린다.
- 대기 사유: 포인트 부족 '쉼터 공간이 모자라 자리를 기다리고 있어요', 인원 초과 '쉼터에 친구가 가득해 자리를 기다리고 있어요'.

## SH24-02 좌석

- 엘레판은 기본 쉼터에서 더 이상 중앙 좌석을 우선하지 않는다. 한쪽 좌석을 써서, 남은 4포인트로 일반 친구 1명이 연속된 자리를 실제로 얻을 수 있게 한다.
- 쉼터 원화·내부 폴리곤·입구는 변경하지 않는다. 실제 렌더에서 성체 3명과 엘레판+일반 1명이 모두 내부에 들어감을 확인했다(`docs/qa-0.6.17/runtime`).

## SH24-03 호환

- 저장 스키마는 바뀌지 않는다. 이전 8포인트 기준에서 어린 친구 4명이 이미 기본 쉼터 안에 있던 저장도 그대로 로드된다. 인원 상한은 새 입실에만 적용하고, 이미 들어간 친구를 강제로 내보내지 않는다(자연 퇴실 후 정상화).
- 확장 해금: 예상 성체 점유 합계가 전체 포인트를 넘거나, 활동 친구 수가 전체 인원 상한을 넘으면 해금한다.
