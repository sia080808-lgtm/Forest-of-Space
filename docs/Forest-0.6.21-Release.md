2026-11-18. 사용자 제보: (1) 거름 자리·더미 둘레의 점이 "좁쌀"처럼 보임, (2) 엘리시를 데려오려 해도 정보가 없음, (3) "두리이 찾아왔어요".

- 거름 표시: 거름을 점 43개 대신 옅은 흙빛 얼룩(방사형 4겹, 거름이 많을수록 조금 진하게)으로 그린다. 기존 낙엽 자리(거름 자리)에 남은 낙엽이 없으면 색이 바랜 잎 3장을 함께 그린다(처음 시안의 짙은 갈색·어두운 잎 조각은 "불에 탄 것 같다"는 의견으로 옅게 바꿈). 더미 둘레의 거름도 같은 얼룩으로 그린다. 렌더 전용.

- 조사: 이름 뒤 이/가·을/를을 받침에 맞춘다(두리가, 엘리시가, 바위 틈을). 손님 알림, 환영·보호 기록, 조건 문구에 적용했다.
