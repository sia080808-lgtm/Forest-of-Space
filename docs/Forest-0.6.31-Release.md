# APK0.6.31 · 햇살 바위 위에서 쉬는 친구가 바위에 가려지지 않게

2026-11-18. 사용자 제보(0.6.30 실기기 화면): "케릭이 햇살바위에서 쉬고 있을 때 다른 케릭이 햇살바위 근처로 지나가면 갑자기 햇살바위가 쉬고 있던 케릭터 위로 올라옴".

- **원인:**
  - 화면은 친구를 뒤(y가 작은 쪽)부터 그린다. 친구 하나를 그린 뒤, 그 친구보다 앞에 있는 돌(햇살 바위·바위틈·잎 그늘)을 그 위에 다시 그려 몸을 가린다.
  - 바위 윗면에서 쉬는 친구는 바위보다 뒤에 있어서 먼저 그려진다. 이 친구 자신에게는 바위를 다시 그리지 않는다(0.6.15).
  - 그런데 다른 친구가 바위 뒤쪽 옆을 지나가면 그 친구를 가리려고 바위를 다시 그리고, 이때 먼저 그려 둔 '바위 위 친구'까지 덮였다.
- **수정(`scene.js`, 렌더 전용):** 이번 화면에서 바위 위에 있는 친구를 기억해 둔다. 다른 친구 때문에 햇살 바위를 다시 그린 직후, 그 친구들을 바로 위에 다시 그린다. 지나가는 친구는 그대로 바위에 가려지고, 바위 위 친구는 계속 보인다.
- 상태·난수·저장 불변. 버전 0.6.31 / versionCode 48.

검증: 자동 273/273, DOM UI PASS. `rock-rider.test.cjs`가 실제 scene.js 렌더로 바위 위 친구 자리의 화소를 비교한다(지나가는 친구가 있을 때와 없을 때). 수정 전 코드에서는 화소당 차이 255로 실패하고, 수정 후에는 통과한다. 수정 전·후 비교 `docs/qa-0.6.31/runtime/rock-rider-before-after.png`(`tools/rock-rider-review.cjs`). Android 실기기 미검증.
