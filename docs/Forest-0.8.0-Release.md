# APK0.8.0 · 사계절: 달력, 기후 × 계절 날씨, 계절 낙엽·성장·작은 이웃, 계절별 그림

2026-11-19. SRS v2.31(`docs/Forest-Seasons-SRS-v2.31.md`·`.pdf`).

사용자 요청과 결정:
- "계절순환, 지역별 특색 이런 거 가져오고 싶음"(생존 게임 장르의 시스템만 참고, 다른 게임의 캐릭터·그림·이름은 쓰지 않음)
- 계절당 3일(실제 1시간), 기후 위에 계절, 계절 먼저·지역은 다음
- "1 적용, 2 계절별 그림 따로, 3 표대로"

변경 내용:
- **달력(`environment.js`):** 봄 → 여름 → 가을 → 겨울, 계절마다 3,600초(게임 3일), 한 해 14,400초. 새 게임은 봄 1일째, 기존 저장은 처음 불러온 순간이 봄 1일째다. 기후를 바꿔도 달력은 이어진다. 계절이 바뀔 때 기록이 남는다.
- **날씨:** 기후마다 숨어 있던 철(습한·마른·추운 철)을 사계절로 바꿨다. 기후 × 계절 표로 기온·비·안개·바람·눈이 바뀐다. 예: 촉촉한 숲 여름 장마(폭풍은 여름), 마른 숲 여름 가뭄과 눈 없는 겨울, 서늘한 숲 겨울 눈 80%. 계절이 바뀌는 120초 동안 값이 섞인다.
- **낙엽(`objects.js`):** 하루 낙엽 = 단계별 45/68/90 × 봄 0.6·여름 0.8·가을 2·겨울 0.3(올림). 바닥 상한 90은 그대로다.
- **친구(`engine.js`):** 성장 시간이 봄 1.25배·겨울 0.75배로 쌓인다.
- **작은 이웃(`creatures.js`):** 겨울에는 개미 군락이 둥지에서 겨울잠을 자고(떠나는 시간도 멈춤), 해충·천적이 새로 오지 않는다. 겨울 낮(기온 20 이상)에는 톡토기가 45%로 찾아온다. 봄 첫날에는 개미·톡토기가 빨리 돌아온다.
- **계절별 그림(`tools/build-season-art.py`, 원본 픽셀에서 만듦):** 고사리 액자, 새 땅의 고사리 덤불 6종, 잎 그늘 식물의 봄(연두)·가을(적갈·주황·황토)·겨울(빛 바랜 회녹색과 눈) 그림 24장. 여름은 원본이다. 계절이 바뀔 때 120초에 걸쳐 바뀐다.
- **화면:** 계절 색(봄 연두빛·여름 따뜻함·가을 호박빛·겨울 차가움), 가을 낙엽 색, 머리에 "봄 1일째" 계절 표시(누르면 계절 설명).
- 저장 스키마 버전·규칙 식별자는 바꾸지 않았다. 저장에는 `environment.calendar.start`를 추가했다. 버전 0.8.0 / versionCode 58.
