# APK0.6.11 · SRS2.21 비 시인성 및 물장구 급수

2026-11-16. 사용자 요청에 따라 비 시인성과 물장구 중 실제 음수를 개정했다.

- 비: 실제 강수 비율r에 따라 최대100줄, 길이9+13r·굵기0.8+0.8r·기본 불투명도0.38+0.24r·속도220+160r. 개별 깊이0.78~1과 바람 방향 반영. 밝은 중심과 옅은 어두운 외곽을 그려 밝은 종이 배경에서도 대비 확보.
- 합성: 카메라 좌표 복구 후 viewport CSS px로 비를 한 번 그리고 공통 월드 조명에 합성한다. 줌과 빗줄기 크기를 분리. 동작 줄이기는 동일 크기/대비의 정적30%. 기존 눈·낙엽과 총120개 예산. 실제 강수10초 전환을 읽으며 렌더에서 물/난수/저장을 수정하지 않는다.
- 물장구: 실제 샘터 이용점·형상/안전·잔량20% 조건에서만 몸B로 최대6/분·목표65까지 전달. 실제 샘물 차감과 공정 배분. 기분2/분·체력-1/분은1회. 상한에서는 놀이 유지, 과보충/음수원 생성 없음. 생리 소모는 별도로 계산하므로 순증과 전달량을 구분한다.
- 실제 물 전달량>0일 때 간헐적 숙임/입가 물기·음수 안내·음향 마커를 연결한다. 놀이만 할 때에는 음수 마커를 재생하지 않는다. 목표 도달 완료는 물장구 세션당1회로 기록한다.
- 기존 몸통/팔다리·엘레판5레이어와1.5배·쉼터 실제 입실·물/낙엽 보존·SRS2.20의7종 카드를 유지. 저장 스키마와 SRS-2.19-objects 식별자를 유지하며 APK버전만0.6.11/versionCode28로 증가.

검수 근거는 docs/qa-0.6.11 원본 로그·verification.json. 강도/시간6장면·2확대배율·정적 동작 줄이기·물장구1/10/20초를 실제 원형과 scene.js/native Canvas로 확인했다. Android 실기기 설치·프레임 성능·터치·큰 글자·청음·WebView 화면은 미검수이며 native Canvas와 구분한다. 잎/지붕의 정밀 강수 가림 마스크와 장기 밸런스는 별도다.
