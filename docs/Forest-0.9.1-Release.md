# APK0.9.1 · 호수 수련: 호수에서 무작위로 피어나고 지는 수련

2026-11-20. SRS v2.33 초안 LK-04. 사용자 요청: "수련부터 ㄱㄱ"(앞선 결정: 연꽃 봉오리가 서서히 피어나는 구조, 호수에서 랜덤 생성, 물 위에 피는 수련, 연꽃 크게).

변경 내용:
- **수련(`world.js`):** 물가가 열린 뒤 봄 마지막 날부터 여름 끝 무렵까지 90초마다 30%로 호수 물 위 빈자리(물가에서 떨어진 곳, 다른 수련과 간격 0.08)에 수련이 생긴다(동시에 최대 7). 수련마다 자기 나이에 따라 새 잎 → 봉오리 → 반쯤 핌 → 활짝 핌 → 물속으로 잠김 → 시듦을 거쳐 사라진다(활짝 핀 때가 가장 김, 약 20분). 그래서 여름 내내 여러 단계가 섞여 보인다. 가을이 되면 아직 꽃이 있는 수련은 하나씩 잠기고 시들며, 겨울에는 얼음 아래로 모두 사라진다. 독립 난수 `rng.lake`, 위치·나이는 저장(`world.lake.lilies`).
- **하루 리듬(`scene.js`, 렌더 전용):** 밤과 큰비에는 꽃이 봉오리처럼 오므리고, 해 질 녘·새벽에는 반쯤 연다. 물 위에서 천천히 살짝 흔들린다(동작 줄이기에서는 멈춤).
- **그림(`tools/draw-waterlily.py`):** 사용자가 고른 수채 시안 그대로 6단계 그림(`assets/forest/lake/lily-*.png`). 수련마다 크기와 좌우 방향이 조금씩 다르다.
- **관리자: 호수 물가 바로 열기(사용자 "관리자 권한으로 해금 조건 푸는 설정"):** 설정 > 개발 검수에 '호수 물가 바로 열기' 버튼. 확인 창 뒤 숲 성장 조건과 동쪽 산책을 건너뛰고 물가를 연다(다시 닫을 수 없음, 이미 열렸으면 버튼이 없음). `World.openLake`.
- 저장 스키마·규칙 식별자 불변. 버전 0.9.1 / versionCode 67.

검증: `lake.test.cjs` LK-04(봄 끝~여름 생성, 물 위·간격, 네 단계 관찰, 같은 시드 같은 수련, 가을 잠김·시듦, 겨울 비움, 잘못된 기록 거부). 전체는 CI. 화면 `docs/qa-0.9.0/runtime/lake-lilies*.png`(`tools/lake-review.cjs`: 낮·확대·밤). Android 실기기 미검증.
