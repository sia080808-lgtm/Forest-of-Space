# APK 0.6.7 · 빈 쉼터 입구 교착 수정

2026-11-16. 패키지 `com.ridleydesk.mobile`, versionCode 24. 0.6.6과 같은 개인 인증서로 업데이트하며 기존 기록을 초기화하지 않는다.

## 문제와 원인

사용자 제보는 빈 쉼터 앞에서 리들리와 엘레판 모두 대기한다는 것이다. 기본 배치에서 첫 입실은 성공했지만, 고정 시드 생활을 반복하면 두 캐릭터가 서로의 경로를 막는 상태가 재현됐다. 기존 경로 탐색은 지형만 피하고 이동 직전에 다른 캐릭터와 충돌하면 정지했다. 예약 만료 후에도 같은 경로를 다시 선택해 실제 사용 0·예약 8 상태가 120초 이상 이어졌다.

별도로 외부 대기 상태가 휴식 필요 해소 후 남을 수 있었고, 통로가 막힌 예약 실패도 만석과 동일한 문구로 표시했다. 사용자의 실제 휴대폰 저장을 받은 것은 아니므로 모든 사용자 배치의 원인을 동일하다고 단정하지 않는다.

## 수정

- 이동 경로에 다른 활성 캐릭터의 현재 위치와 기존 충돌 반경을 반영했다. 우회 경로와 실제 이동이 같은 충돌 기준을 사용한다. 캐릭터 관통·워프·축소로 문제를 숨기지 않는다.
- 오래된 저장에서 두 친구가 너무 가까우면 서로에게 접근하지 않는 방향의 연속 이탈만 허용한다.
- 대기 이유를 용량·형상·경로·통행·순번으로 구분한다. 통로만 막힌 대기를 만석으로 표시하지 않으며, 길이 막힌 친구 때문에 입장 가능한 다른 친구까지 막지 않는다.
- 쉼 필요가 끝난 외부 친구의 대기 상태를 정리한다. 실제 입실, 실제 퇴실, 용량 원장과 대기 요청 ID는 기존 계약을 유지한다.

## 검수

교착 재현 상태를 그대로 불러오면 12초 안에 두 친구가 몸 전체를 들이고 휴식을 시작한다. 원래 크기·ID·XP·위치·자원을 보존하며 이동량 상한과 연속 경로 충돌을 검사했다. 1,500초 추가 생활에서도 빈 쉼터의 장기 교착은 재현되지 않았다.
