## 직접 이동

- 짧은 누름은 선택, 100ms 눌림 표시, 350ms 길게 누름은 들기. 대기 중 8px 이상 움직이면 길게 누르기 후보를 취소한다. 휴대폰 WebView의 CSS 픽셀 기준이며 Android 물리 dp 일치 여부는 기기 검수 대상이다.
- 손가락 위에 미리보기를 띄우고 바닥에 배치 가능 위치를 표시한다. 유효하지 않으면 최대 1GU 안에서 결정적으로 보정하며, 끝까지 불가하면 원래 위치를 유지한다.
- 선택 카드의 ‘옮기기’는 위치를 누르는 방식이다. 선택 대기는 최대 30초, 들어 올리기는 최대 5초. 두 번째 손가락·포인터 취소·뒤로·탭/모드 변경·잠금에서 취소한다.
- 들어 올린 동안 좌표는 원래 위치에 예약하고 생리 시간은 계속 흐른다. 급수/휴식/이동은 정지한다. 배치 시 생리·뿌리 물·성장·별명·난수·자원량은 보존한다. 저장 실패 시 변경을 적용하지 않는다.
- 착지는 약 0.8초 시각 안정 및 최대 한 고정 단계 이동 정지. 강풍·심한 갈증은 우선한다.
- 현재 플레이 편성은 리들리 한 마리다. 향후 복수 편성의 선택 목록과 사회 예약 계약은 별도 구현한다.

## 환경·경로·모션

- 구역 배수는 거리 0.32 이내의 더 낮은 구역 중 가장 가까운 한 곳으로 전달한다. 프레임 내 재배수 없이 한 단계에서 한 번 전달하고 넘치는 양/연결 없는 배수는 외부 유출로 기록한다. 아래 방향의 비순환 연결만 사용하는 초기 구현이다.
- 수면과 두 바위의 확장된 타원 발자국을 피해 가는 결정적 가시성 그래프를 쓴다. 지형 배치 후 물가·쉼터 접근과 개체가 서 있는 자리의 충돌을 검사한다.
- 1GU=월드 가로의 0.10, 세로 거리 환산=1.6을 초기값으로 사용한다. 느림 0.6, 걷기 1.0, 갈증 1.3, 강풍 대피 1.6GU/s. 체력 부족 대피는 1.0, R80 진입/R60 해제의 느림 이력을 적용한다. 성장 크기로 실제 속도를 바꾸지 않는다.
- 실제 1초 경로를 보간한다. 기본 그림을 Canvas 영역으로 나눠 발·상체·윗잎을 움직이며 급수 숙임·휴식 낮춤·잎 정돈을 구분한다. 이는 2.8 시안의 완성된 분리 리그나 모든 모션 프레임 제작 완료가 아니다.
- 젖음은 M, 수면은 W/샘터 실제 잔량을 사용한다. 얇은 표면 물기 film은 별도 저장하며 비에 늘고 일조·바람에 마른다. film은 급수 가능한 물을 만들지 않는다. 비 종료 때 젖음이 즉시 초기화되지 않는다.
- 실제 물이 있는 표면만 파문을 그린다. 표면당 최대 2개, 7개 표면 기준 최대 14개. 비·급수 접촉 없으면 새 파문을 생성하지 않는다. 움직임 줄이기는 파문을 생략하고 주요 상태 표현은 유지한다.

## 소리

- 사용자가 준비한 `여백의숲_사운드에셋_합성시안_v0.2.zip`에서 17개 파일을 그대로 적용했다. `assets/audio/manifest.json`에 바이트 해시가 있다.
- 낮/밤 BGM FULL 2개만 사용한다. 6초 음악 전환, 10초 환경음 전환. 음악 2·환경 4·일회음 6, 전체 12개 상한. 상한에 걸리면 퇴장 중 환경 루프를 먼저 종료한다.
- 실제 이동 경로의 발 접점, 양수의 물 전달, 잎 정돈, 들기/놓기에 소리를 연결한다. 접점 키로 반복 프레임 중복을 막고 음원이 늦게 로드돼도 지난 소리를 재생하지 않는다.
- 발소리는 흙/잎/돌/나무 공통 시안을 사용한다. 전용 젖은 발소리·성장·발견 스팅어·사회 행동 큐는 아직 연결하지 않았다. 등록됐으나 미사용인 UI 클릭 큐는 향후 UI 사운드 조정 대상이다.
- 전체·음악·환경·효과음 4개 음량을 저장한다. 첫 사용자 조작 후 소리가 열리며 다른 탭/잠금/저장 오류에서는 멈춘다.

## 실제 검사 범위

- Node 기능 검사 40개: 기존 12시간 물 수지/8시간 안전 휴식과 이동 보존/실패 롤백/경로/속도/음향 접점/표면 물기 등을 검사했다.
- DOM 입력 하네스: 부팅, 카드 이동, 350ms 길게 누름, 두 번째 손가락 취소, 실패 저장, 소리 슬라이더, 조경 취소, 잠금/복귀 이벤트 연결을 확인했다. 브라우저 레이아웃·실기기 터치 검사를 대체하지 않는다.
- 실제 Canvas 렌더 코드로 맑음/비/급수/휴식 화면을 그려 이미지 확인. Chromium은 실행 환경의 socket 권한 오류로 열리지 않아 전체 브라우저 화면 검수는 미수행이다.
- Android API 35 컴파일, APK 정렬·서명, 이전 0.3.1 APK와 인증서 일치, 번들 파일 일치를 확인한다. 결과 파일은 `android-build.txt`, `signature-verification.txt`, `release.json`에 기록한다.
- Android 실기기 설치/업데이트, 음향 청취, 파일 선택기, 배터리/발열/성능 및 감성 품질은 미검증이다.
- CodeQL은 기능 검사와 별개다. 기존 실행은 저장소의 결과 등록 제한으로 실패했다. 이번 커밋의 실행 결과를 별도 확인하며 성공 전에는 통과라고 표시하지 않는다.
