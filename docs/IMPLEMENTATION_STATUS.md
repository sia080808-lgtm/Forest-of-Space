## 구현 선택 기록

- 엔진 교체 없이 기존 Android WebView 셸을 재사용했습니다. 모든 JS·그림·글꼴은 APK 내부에 번들됩니다.
- 단계1의 날씨 분포는 C01의 맑음20/비45를 재정규화합니다. 흐림/안개는 후속 확장에서 추가합니다.
- SRS에 초기 지형의 실제 저장 물량이 확정되지 않아 초기값을 별도 지정했습니다: 바위1, 이끼22, 그늘4, 틈2, 쉼터3, 낙엽6물. 최초 총량에 포함되며 배치·재접속으로 재지급하지 않습니다. 검증 중인 초기값입니다.
- 다중 배수망을 가짜로 구현하지 않았습니다. 현재 각 구역 배수는 명시적 외부 유출이며, 잎의 비 차단량만 인접 하류 한 구역에 한 번 전달합니다. 1단계 전체 승인 전에 연결 배수·경로 검증을 보강해야 합니다.
- 아기/성장 크기는 단계별 비율을 반영한 임시 스케일 표현입니다. 최종 성장 원화/분리 모션은 별도 제작 대상입니다.
- 타 종은 도감의 향후 대상 설명만 표시합니다. 실제로 획득/편성할 수 있는 것처럼 보상이나 카운트다운을 만들지 않았습니다.
- 앱에서는 내부 구현 설명을 핵심 플레이 흐름에 넣지 않았고, 개발 범위는 설정 하단에만 짧게 표시합니다.

## 사람의 확인이 필요한 것

자동 검사를 통과하면 후속 구현을 계속할 수 있습니다. 단계마다 별도 승인 절차를 요구하지 않습니다. 다만 AC-95~98, AC-120의 원인 이해·재미·성격 구별, Android 실제 설치/사용감은 별도 확인이 필요합니다. 관찰하지 않은 결과를 통과로 쓰지 않습니다.

## 2026-11-15 작업 재개 확인

- 복원한 0.3.0 소스로 기능 검사 26개 및 JavaScript 3개 문법 검사를 다시 통과했습니다.
- 보관된 APK의 SHA-256과 크기가 release.json과 일치하며 ZIP 무결성을 확인했습니다. 번들 자산 12개는 소스의 해당 파일과 바이트 단위로 일치합니다. Android 컴파일·서명·실기기 검사를 이번에 재실행한 것은 아닙니다.
- 원격 저장소 읽기·쓰기 접근은 정상입니다. 최초 업로드는 자동 승인 심사에서 보류됐으나 사용자의 명시적 파일 전송 승인 후 재개했습니다.
- GitHub push·PR 기능 검사도 통과했습니다. CodeQL은 실제 실행했으나 결과 등록이 저장소 설정에 의해 차단됐으며 통과가 아닙니다. 다음 구현은 1단계의 연결 배수·경로 검사 보강입니다.
