# APK0.6.25 · 생태계 v2.24 2단계(패치 6a): 짐꾼개미·톡토기

2026-11-18. 사용자 승인 "ㄱㄱ"(개미·톡토기를 실제 게임에 넣기). 이슈 #15 패치 6a. 작은 이웃은 캐릭터가 아니며 친구 자리(5명)를 쓰지 않는다.

- 출현(ECO24-B01): 게임 시작 600초 동안은 오지 않는다. 그 뒤 180초마다 한 번 확인하고, 새 무리는 600초에 하나만, 전체 최대 8무리. 조건이 120초 이어져야 후보가 된다. 독립 난수 `rng.creatures`를 쓴다.
- 짐꾼개미(B03·A01): 활동 중인 리들리(기분 35·체력 40 이상) 곁, 낱잎 1장 이상, 강풍(60) 아님일 때 20%. 둥지(흙 돔)는 리들리 근처 빈 자리에 생긴다. 90초마다 더미 없는 섹터의 실제 낱잎 1장을 이웃 섹터의 더미(여유 있을 때)나 낱잎 2장 이상 모인 곳으로 옮긴다. 둥지 → 잎 → 목적지를 실제로 걸어가며(거리 비례, 최소 25초), 운반 중인 잎도 바닥 낙엽 40·섹터 12에 포함된다. 잎을 만들거나 없애지 않는다. 조건이 120초 동안 맞지 않으면 떠나고, 들고 있던 잎은 가져온 자리로 돌려놓는다.
- 톡토기(A02·N01): 낙엽 3장 이상·생긴 지 60초 이상·촉촉함 35~75%·고인 물 없음·기온 40~75인 더미에 30%(근처에 엘리시가 있으면 40%). 그 더미의 분해만 ×1.25(다른 보정과 곱해 최대 3.75배 상한, 겹쳐 쌓이지 않음). 최대 2무리. 조건이 120초 안 맞으면 떠난다.
- 더미 촉촉함: 더미가 가장 가까운 지형(샘물·바위틈은 100%, 맨땅은 0%)을 따르던 것을 기존 낙엽 자리 흙의 물기로 바꿨다. 이전 방식에서는 톡토기 조건(35~75%)이 거의 생기지 않았다.
- 화면: 흙 돔 둥지와 일개미 2마리, 운반 개미(둥지 → 잎 → 목적지), 더미 위 톡토기 4마리의 점프. 동작 줄이기에서 정지. 낙엽 자리·더미 카드에 '작은 이웃' 행. 렌더는 상태·난수를 바꾸지 않는다.
- 저장: `objects.creatures`를 추가(처음 불러올 때 빈 기록으로 생성). 저장 스키마 버전 불변. 버전 0.6.25 / versionCode 42.
