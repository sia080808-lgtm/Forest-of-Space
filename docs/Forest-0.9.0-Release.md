# APK0.9.0 · 동쪽 호수 물가 열기(1단계): 물가 지역, 물 판정, 산책으로 발견하는 해금, 호수 바닥·겨울 얼음 그림

2026-11-20. SRS v2.33 초안(`docs/Forest-Lake-SRS-v2.33-DRAFT.md`) 1단계. 사용자 결정: 시안에서 번지는 물가·수채 연잎·징검돌과 섬 없음·동쪽 끝까지 물, 해금 "3번"(숲 성장 조건 뒤 산책으로 발견), "일단 물가만 열고, 나중을 대비해서 연장 영역은 염두해서 제작", 물가를 좋아하는 새 친구는 나중에.

변경 내용:
- **물가 지역(`world.js`):** 열린 지역 목록에 `lakeshore`(x 1.25~1.75, y −0.25~1.25)를 더할 수 있다. 호수 모양은 세계 좌표 기준 하나의 식(`waterD`, 타원 + 사인 3개)이고 물은 지역 동쪽 끝 너머로 이어진다. 그래서 나중에 더 동쪽 지역을 열면 세계만 넓어지고 같은 호수가 이어진다(사용자 "잘린 호수 전체 연장").
- **물 판정(`spatial.js`·`engine.js`):** 물 위는 걸을 수 없다. 사물·샘터는 물가에서 조금 떨어진 땅에만 놓을 수 있다.
- **해금(`world.js` `lakeStep`, `objects.js`):** 정원 친구 3명 이상이고 계절 달력이 시작된 지 한 계절(3,600초)이 지나면 "숲 동쪽 끝에서 바람이 촉촉해졌어요"가 뜨고 준비가 된다. 그 뒤 산책의 약 3분의 1이 숲 동쪽 끝으로 가고, 동쪽 끝(x 1.08 이상)에서 산책을 마치면 "(이름) · 동쪽에서 물 냄새가 나요"(카드 "동쪽에서 물 냄새를 맡고 있어요"). 세 번 쌓이면 "숲 동쪽에 물가가 열렸어요"와 함께 물가가 열린다. 카메라는 그대로 두고 끌어서 가 본다. 기존 저장은 닫힌 채로 불러온다. 저장에 `world.lake`(준비·냄새 수·열린 시각)를 더했다.
- **그림(`tools/build-lake-floor.py`, 렌더 전용):** 숲 바닥 종이를 이어 그린 물가 풀밭(물가로 갈수록 촉촉하고 풀포기가 많아짐), 사용자가 고른 번지는 물가와 담채 물, 물결선, 부들 무리. 겨울에는 눈 위로 옅은 회청색 얼음과 가는 금. 그림은 호수 전체(x 1.05~2.2)를 덮어 나중에 넓혀도 다시 그리지 않는다.
- 안내 문구: 위 세 안내가 월드 하단 가운데에 5초 동안 뜬다.
- 저장 스키마·규칙 식별자 불변. 버전 0.9.0 / versionCode 66.

측정(엔진, 친구 4명, 시드 3개): 준비 3,600초, 물가가 열린 시각 3,813~4,032초(준비 뒤 213~432초).

검증: 새 `lake.test.cjs` 3개(옛 저장은 숲만·물가 범위·물 위 걷기 금지·저장 왕복, 준비와 산책 세 번으로 열림·안내, 물 위 배치 거부·잘못된 호수 기록 거부). 관련 테스트(`wide-forest`·`stroll`·`package`) 통과, 전체는 CI. 화면 `docs/qa-0.9.0/runtime`(`tools/lake-review.cjs`: 숲 동쪽 끝·물가·전체 보기·겨울 얼음, 렌더 전후 상태 동일).

다음 단계(아직 없음): 수련(무작위 생성·생애주기), 물가 이웃 7종, 상호작용·이벤트 4개, 물가에서 물 마시기, 더 동쪽 호수 지역. Android 실기기 미검증.
