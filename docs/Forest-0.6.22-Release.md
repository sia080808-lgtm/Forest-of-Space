# APK0.6.22 · 엘리시가 실제로 찾아올 수 있게

2026-11-18. 사용자 질문: "이거 엘리시 들어올 수 있는 거 맞음?"

- 원인: 엘리시 영입과 잎틈 정원(돌돌이 재방문 30→45%)은 이끼 촉촉함 40~75%를 요구했다. 그런데 v2.19부터 이끼는 물을 5만 머금어 비 한 번이면 100%가 되고 오래 유지된다. 실제 엔진 8시드×3게임일에서 조건 충족 시간은 1~3%, 엘리시 방문은 1/8뿐이었다.
- 수정: 조건 문구 "촉촉하고 물이 고이지 않는 이끼"에 맞춰 이끼 40% 이상 + 지금 큰비(강수 0.6 이상) 아님 + 바위틈 고인 물 5 미만으로 바꿨다. 상한 75%는 없앴다. 거리·길·안전·180초·35%·3회 보장은 그대로다. `recruitment.js`(영입·조건 목록 5항목), `social.js`(잎틈 정원).
- 결과: 같은 시뮬레이션에서 8시드 중 7시드는 3~12분 안에, 나머지 1시드도 약 71분 뒤에 찾아왔다.
- 저장 스키마 불변. 버전 0.6.22 / versionCode 39.

검증: 자동 230/230, DOM UI PASS. `recruit-info` 갱신·추가(가득 찬 이끼 허용, 마른 이끼·큰비 차단, 4시드 중 3시드 이상 1게임시간 안 방문 — 수정 전 코드 0/4로 실패). Android 실기기 미검증.
