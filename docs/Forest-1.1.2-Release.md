# APK1.1.2 · 호수 생물이 호수를 돌아다님

2026-11-21. 사용자 질문 "현재 호수 생물들 이동 반경 어케댐" → 설명(태어난 자리에 고정, 화면에서만 제자리 몇 px 맴돎) → "2번 ㄱㄱ"(엔진에서 실제로 이동).

변경 내용:
- **호수 생물 이동(`world.js` `swim`, 매초):** 생물마다 가까운 새 자리를 골라 그쪽으로 헤엄치거나 날아가고, 도착하면 잠깐 쉰 뒤 다시 움직인다.
  - 소금쟁이: 열린 물 위를 넓게(한 번에 최대 0.5, 초당 0.004, 쉬기 4~20초).
  - 송사리 떼: 물 위를 넓게(최대 0.45, 초당 0.003, 쉬기 2~10초).
  - 물방개: 호수 가운데 쪽(최대 0.3, 초당 0.002).
  - 올챙이: 물가 얕은 물(최대 0.15, 초당 0.0012).
  - 장구벌레: 물가 얕은 물에서 아주 조금(최대 0.06).
  - 물달팽이: 물가 가장자리를 천천히 기어 다니고, 0.3 안의 시든 수련으로 기어가서 먹는다(이전에는 호수 어디든 순간 이동).
  - 잠자리: 물과 물가 위를 넓게 순찰(최대 0.6, 초당 0.012). 밤·큰비·강풍에는 쉰다.
  - 개구리: 1.5~5분에 한 번, 0.35 안의 빈 수련 잎(70%)이나 물가로 헤엄쳐 옮겨 간다.
  - 개구리알·부들의 잠자리 애벌레는 그대로.
  - 물속 생물은 물 밖으로 나가지 않는다(가는 길도 물 위인지 확인).
- **고른 자리는 생물 이름과 이동 횟수로 정한다(해시).** 호수 난수 `rng.lake`를 쓰지 않아 생물이 찾아오는 순서는 이전과 같다.
- **화면(`scene.js`, 렌더 전용):** 엔진이 1초에 한 번 옮기는 위치를 부드럽게 따라 그리고, 가는 쪽을 바라본다. 개구리는 옮겨 가는 동안 헤엄 그림. 송사리 떼는 이동 중에 한 줄로 따라간다.
- **같이 고친 것:** 잠자리 애벌레가 날개돋이할 때 잠자리 상한(3)을 보지 않던 문제.
- 저장 스키마·규칙 식별자 불변(생물 기록에 `tx`·`ty`·`rest`·`mv` 추가, 없으면 그대로 불러옴). 버전 1.1.2 / versionCode 78.

측정(엔진, 관리자 여름 채우기 뒤 20게임분): 소금쟁이 0.11~0.74, 송사리 0.61~0.68, 잠자리 0.42~1.2, 개구리 0.25~0.6 이동. 틱당 약 1.5ms.

검증: `lake.test.cjs` 1.1.2 검사(15분 동안 물 위 유지, 소금쟁이·송사리 이동, 알·애벌레 고정, 저장 검증), 관련 `lake`·`admin`·`render`·`package` 통과, 전체는 CI. Android 실기기 미검증.
