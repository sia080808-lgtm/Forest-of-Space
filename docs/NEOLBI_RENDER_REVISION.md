# 넓이 후드 렌더 수정 — 2026-11-16

0.6.2 최초 렌더는 얇은 앞 테두리를 길게 늘려 머리 덮임이 사라지고 띠처럼 보였으므로 폐기했다. 기능 검사 통과를 외형 승인으로 취급하지 않는다.

- 펼침 전용 수채 잎 파츠 extended-front-v2.png를 새로 제작했다. 넓은 바깥 면과 어두운 안쪽 면이 한 장의 연속 잎이다. 원본 부착부는 고정하고 정수리 덮임을 별도로 유지한다.
- body-blank-v2.png로 눈 없는 온전한 몸통을 제작하고 눈을 독립 렌더한다. 눈을 다른 몸통 질감으로 가리는 런타임 덧칠은 제거했다.
- 기본폼은 기존 닫힌 후드로 유지한다. 완전히 펼친 잎 폭은 몸통의 약 2.56배이며 길고 가느다란 테두리 확대 방식은 사용하지 않는다.
- 후드 아래 좌석은 캐릭터 성장 크기에 따른 높이 여유도 검사한다. 실제 게임 렌더에서 리들리와 넓이는 각각 기존 성장 스케일 그대로 사용한다.
- 코드로 만든 기본/펼침 및 동행 렌더는 qa-0.6.2/runtime에 보관한다. 해당 동행 이미지는 배치된 정적 검수 장면이며, 모든 경로와 전환 프레임을 검수했다는 뜻이 아니다.

기존 0.6.2 소스 묶음을 수정한다. 통합 SRS PDF와 설치 APK는 이번 수정에서 생성하지 않았다. 기존 APK 서명/SDK 부재와 실기기 검수 제한은 유지한다.

## 단일 후드 연결 수정

기존 닫힌 후드와 펼침 후드를 겹쳐 그리던 방식은 제거했다. 닫힌 잎과 펼친 잎의 세로 윤곽을 대응시켜 하나의 외곽선과 표면만 변형한다. 머리에 붙는 x≤8 구역은 21단계에서 동일 픽셀을 유지한다. 두 실루엣의 투명도 전환은 사용하지 않는다. 같은 영역의 색과 질감만 대응 좌표에서 보간한다.

실제 렌더에서 앞쪽 후드 1회만 그리는지, 연결부 불변/한 장의 연속 잎 면인지 검사한다. 기존 상호작용 관련 검사까지 12개 통과, UI 검사 통과. 애니메이션 GIF는 실제 게임 리그를 사용한 8초 루프이며 body/발 크기는 일정하다.
