# APK1.2.2 · 1.2.1로 업데이트 뒤 "정원을 열지 못했어요 · 친구의 적설 기록을 확인해 주세요"

2026-11-21. 사용자 제보(1.2.1 실기기, 업데이트 직후): 시작하면 "정원을 열지 못했어요 · 친구의 적설 기록을 확인해 주세요".

- **원인:** 친구 잎에 쌓이는 눈은 친구 크기(잎 넓이 × 12)까지만 쌓인다. 그런데 친구가 작아지면(관리자 레벨 초기화·레벨 낮추기 뒤 그려지는 단계가 따라 내려갈 때) 이미 쌓인 눈이 줄지 않아 한도를 넘었고, 그 상태로 저장된 기록이 다음 실행 때 저장 검사에 걸려 열리지 않았다. 같은 상태를 엔진에서 만들어 1.2.1 코드가 똑같은 문구로 여는 데 실패하는 것을 확인했다.
- **수정(`environment.js` `fitSnow`):** 불러올 때와 매초, 친구 잎(과 사물·쉼터 지붕)에 한도보다 많이 쌓인 눈은 미끄러져 흘러내린 것으로 처리한다(물 원장 `ledger.outflow`, 넘친 비·눈과 같은 처리). 이미 이 상태로 저장된 정원도 이제 그대로 열린다. 원래 기록은 지우지 않았다.
- 저장 스키마·규칙 식별자 불변. 버전 1.2.2 / versionCode 88.

검증: 새 `snow-fit.test.cjs`(작아진 친구의 눈이 넘친 저장 → 원래 검사에서는 실패, 불러오면 한도 안으로·흘러내림 기록·이후 검사 통과), `package`·`seasons`·`engine` 통과. 전체는 CI. Android 실기기 미검증 — 1.2.2로 업데이트한 뒤 '다시 열기'를 누르면 같은 기록이 열리는지 확인 필요.
