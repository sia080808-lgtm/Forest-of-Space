# APK0.6.34 · 엘레판 머리 정돈 까닥까닥, 베이치 낙엽 뿌리기 팔 올리기

2026-11-18. 사용자 요청: "엘레판 머리정돈은 후드모자 좀 더 빠르게 까닥까닥 거리고, 낙엽 장난에서 팔 있는 애들(리들리, 베이치)는 팔을 위로 올리며 뿌리기(시안에서 리들리처럼)".

- **엘레판 머리 정돈(`neolbi-motion.js`):** 8초에 한 번 천천히 숙이던 후드(앞잎)를 정돈하는 동안 약 0.6초마다 빠르게 까닥인다. 까닥일 때 몸도 살짝 들썩인다. '잎 맞추기'·PE05 동작은 그대로다.
- **베이치 낙엽 놀이(`species-rig.js`·`rig.js`):** 리들리처럼 웅크릴 때는 두 팔을 발치로 내려 낙엽을 모으고, 뛰며 뿌릴 때는 두 팔을 머리 위로 올린다. 리들리와 같은 시간표(`litterUp`)를 쓴다. 팔 없는 친구는 몸으로 튀어 오르는 동작 그대로다.
- 렌더 전용 변경. 상태·난수·저장 불변. 버전 0.6.34 / versionCode 51.

검증: 자동 275/275, DOM UI PASS. 영상 `docs/qa-0.6.33/runtime/groom-litter.mp4`(`tools/species-motion.cjs`로 다시 만듦). Android 실기기 미검증.
