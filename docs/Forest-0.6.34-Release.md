# APK0.6.34 · 친구별 머리 정돈(손·까닥임), 잎응애 떨기 공통 모션, 베이치 낙엽 뿌리기 팔 올리기

2026-11-18. 사용자 요청: "엘레판 머리정돈은 후드모자 좀 더 빠르게 까닥까닥 거리고, 낙엽 장난에서 팔 있는 애들(리들리, 베이치)는 팔을 위로 올리며 뿌리기(시안에서 리들리처럼)", "리들리는 기존 머리 만지는 머리정돈 가고, 팔 있는 베이치도 손으로 머리 만져서 머리정돈", "엘리시 머리 잎이 두갈래로 나뉘어져 있는데 그 두 잎이 까닥까닥", "코로나도 … 머리 까닥", "몸 부들부들 떠는 모션은 잎손상 주는 벌레가 머리에 붙었을 때 하는 공통 모션으로 가자".

- **엘레판 머리 정돈(`neolbi-motion.js`):** 8초에 한 번 천천히 숙이던 후드(앞잎)를 정돈하는 동안 약 0.6초마다 빠르게 까닥인다. 까닥일 때 몸도 살짝 들썩인다. '잎 맞추기'·PE05 동작은 그대로다.
- **베이치 낙엽 놀이(`species-rig.js`·`rig.js`):** 리들리처럼 웅크릴 때는 두 팔을 발치로 내려 낙엽을 모으고, 뛰며 뿌릴 때는 두 팔을 머리 위로 올린다. 리들리와 같은 시간표(`litterUp`)를 쓴다. 팔 없는 친구는 몸으로 튀어 오르는 동작 그대로다.
- **머리 정돈(팔 있는 친구):** 리들리는 0.6.33 이전처럼 손을 머리에 올려 매만진다(사용자 요청, 몸 털기 대신). 베이치도 오른손을 몸 옆을 따라 머리 잎까지 올려 매만진다. 손이 몸 뒤에 가려지지 않도록 정돈하는 동안 오른팔을 몸·잎 앞에 다시 그린다. 엘레판·슈퍼범은 자기 잎 동작 그대로다.
- **엘리시·코로나 머리 정돈:** 엘리시는 두 갈래 생식엽을 하나씩 번갈아 빠르게 까닥인다(잎 레이어를 두 갈래 사이 틈으로 나눠 각자 밑동을 축으로 돌림). 코로나는 늘어진 머리 잎의 양 끝을 왼쪽·오른쪽 번갈아 까닥인다(잎을 가는 세로 띠 72개로 나눠 바깥쪽일수록 크게 움직이고, 머리 위 가운데는 그대로). 이제 모든 친구가 자기 방식으로 머리를 정돈한다.
- **잎응애 떨기(공통 모션):** 0.6.33에서 팔 없는 친구의 머리 정돈으로 썼던 '웅크렸다 부르르 떨기'를, 잎 손상을 주는 잎응애(밀도 5 이상)가 잎에 붙은 친구의 공통 모션으로 옮겼다. 모든 종이 7초마다 1.35초 동안 하던 동작 위에 떤다(친구마다 시점이 다름). 들려 있거나 쉬기·잠·이끼·착지 중에는 떨지 않는다. 렌더 전용(`scene.js`가 `Creatures.onLeaf`를 읽기만 함).
- 렌더 전용 변경. 상태·난수·저장 불변. 버전 0.6.34 / versionCode 51.

검증: 자동 276/276(`rig.test` 잎응애 떨기: 6종 모두 떨고, 7초 중 일부만, 잠잘 때는 안 떪, 옵션 불변), DOM UI PASS. 영상 `docs/qa-0.6.33/runtime/groom-litter.mp4`(머리 정돈·낙엽 놀이·잎응애 떨기 3줄)(`tools/species-motion.cjs`로 다시 만듦). Android 실기기 미검증.
