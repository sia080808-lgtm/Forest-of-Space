# APK0.6.35 · 바위틈에서 쉴 때 틈에 쏙 들어가 앉기

2026-11-18. 사용자 제보(0.6.34 실기기 화면): "바위틈에 있지 않은데 바위틈에 쉬고있다고 뜸". 화면에서 코로나는 바위틈 아래에 놓인 이끼 위에 있었다.

- **원인(`objects.js`):** 바위틈에서 쉬는 자리가 바위틈 기준점보다 0.07 아래(가로 ±0.067)였다. 돌 그림은 기준점 위(y −0.066~0)에 있어서, 쉬는 자리가 돌에서 한참 떨어진 빈 바닥이었다. 사용자 배치처럼 이끼를 바위틈 바로 아래에 두면, '바위틈에서 쉬는' 친구가 이끼 위에 서 있게 된다. 상태 문구는 실제로 고른 쉼 자리(바위틈)를 보여 줘서 정상이지만, 위치가 맞지 않았다.
- **수정:** 쉬는 자리를 돌 바로 앞(기준점 +0.003, +0.03, 반지름 0.07×0.015)으로 옮겼다. 돌 발자국은 기준점 +0.004에서 끝나고, 친구 몸 너비만큼 넓힌 판정(0.6.30)을 지나도 이 자리는 걸어갈 수 있다. 회복 수치·용량·안전 조건은 그대로다. 다 자란 슈퍼범은 이전처럼 바위틈 자리에 들어가지 못한다(용량).
- **틈에 쏙 들어가 쉬기(`scene.js`, 렌더 전용):** 사용자 질문 "바위 틈에 쉬는 연출 저게 맞음?"에 따라 사용자가 고른 연출이다. 바위틈에 도착해 쉬는 친구는 큰 돌 아래 그늘진 틈 입구(바위틈 그림 512px 타일의 (246, 345))에 0.6초에 걸쳐 들어가 앉고, 앞쪽 작은 돌(타원 (368, 305) 98×55)을 친구 위에 다시 그려 몸 일부를 가린다. 엔진의 쉬는 자리·상태·난수는 바뀌지 않고, 화면 위치(`display`)와 선택 링만 틈으로 옮긴다. 다른 돌 다시 그리기에서는 이 친구에게 바위틈을 다시 덮지 않는다. 엘레판처럼 큰 친구는 틈 입구에 앉아 큰 잎이 돌 위로 덮인다.
- 저장 스키마·규칙 식별자 불변. 버전 0.6.35 / versionCode 52.

검증: 자동 278/278(`rest-spots`: 리들리·엘리시·엘레판·베이치·코로나가 돌 바로 앞(기준점 아래 0.05 안)에서 쉬고 그 자리가 걸어갈 수 있음 / `rock-rider`: 쉬는 친구가 틈 안(기준점 위 0.05 안)에 그려지고 렌더 전후 상태 동일, 쉼 과제가 없으면 원래 자리), DOM UI PASS. 전후 비교 `docs/qa-0.6.35/runtime/crevice-rest.png`(`tools/crevice-review.cjs`, 이끼를 바위틈 아래에 둔 배치, 코로나·리들리·엘레판).
