# APK0.6.35 · 바위틈에서 쉴 때 틈에 쏙 들어가 앉기, 슈퍼범 둥지 물 증발·스스로 마시기

2026-11-18. 사용자 제보(0.6.34 실기기 화면): "바위틈에 있지 않은데 바위틈에 쉬고있다고 뜸". 화면에서 코로나는 바위틈 아래에 놓인 이끼 위에 있었다.

- **원인(`objects.js`):** 바위틈에서 쉬는 자리가 바위틈 기준점보다 0.07 아래(가로 ±0.067)였다. 돌 그림은 기준점 위(y −0.066~0)에 있어서, 쉬는 자리가 돌에서 한참 떨어진 빈 바닥이었다. 사용자 배치처럼 이끼를 바위틈 바로 아래에 두면, '바위틈에서 쉬는' 친구가 이끼 위에 서 있게 된다. 상태 문구는 실제로 고른 쉼 자리(바위틈)를 보여 줘서 정상이지만, 위치가 맞지 않았다.
- **수정:** 쉬는 자리를 돌 바로 앞(기준점 +0.003, +0.03, 반지름 0.07×0.015)으로 옮겼다. 돌 발자국은 기준점 +0.004에서 끝나고, 친구 몸 너비만큼 넓힌 판정(0.6.30)을 지나도 이 자리는 걸어갈 수 있다. 회복 수치·용량·안전 조건은 그대로다. 다 자란 슈퍼범은 이전처럼 바위틈 자리에 들어가지 못한다(용량).
- **틈에 쏙 들어가 쉬기(`scene.js`, 렌더 전용):** 사용자 질문 "바위 틈에 쉬는 연출 저게 맞음?"에 따라 사용자가 고른 연출이다. 바위틈에 도착해 쉬는 친구는 큰 돌 아래 그늘진 틈 입구(바위틈 그림 512px 타일의 (246, 345))에 0.6초에 걸쳐 들어가 앉고, 앞쪽 작은 돌을 친구 위에 다시 그려 몸 일부를 가린다. 엔진의 쉬는 자리·상태·난수는 바뀌지 않고, 화면 위치(`display`)와 선택 링만 틈으로 옮긴다. 다른 돌 다시 그리기에서는 이 친구에게 바위틈을 다시 덮지 않는다. 엘레판처럼 큰 친구는 틈 입구에 앉아 큰 잎이 돌 위로 덮인다.
  - 작은 돌은 실제 그림 윤곽(틈 그늘이 끝나는 왼쪽 가장자리, 위·오른쪽 둘레)을 재서 다각형으로 다시 그린다. 처음 타원 모양으로 덮었을 때는 틈의 어두운 그늘까지 친구 위에 덮여 경계에 검은 줄이 남았다(사용자 제보 "검정색 조각 남아있잖아").
  - 틈에 있는 동안은 작은 돌 영역과 그 아래 바닥 쪽으로 친구를 그리지 않는다. 처음에는 발·손 끝이 돌 아랫단 밑으로 검게 삐져나왔다.
- **슈퍼범 둥지 물이 마르고, 스스로 마신다(`social.js` `nest`):** 사용자 질문 "슈퍼범 머리에 고인 물은 마르나?" → 선택 "증발 + 스스로 마시기".
  - 이전에는 둥지 물(`V`)이 친구에게 나눠 줄 때만 줄었고, 나눔은 10에서 멈춰서 한 번 비를 받으면 계속 '물 고인 둥지'로 보였다.
  - 증발: 비·안개·눈이 아니고 쉼터 지붕 아래가 아니면, 샘물과 같은 식 (0.2 + 0.6×빛/100 + 0.4×바람/100)/60 per 초로 마른다. 증발량은 물 원장 `ledger.evaporation`에 기록한다. 맑은 낮이면 하루(1,200초)에 약 13까지 줄고, 밤에는 느리다.
  - 스스로 마시기: 슈퍼범의 몸 물이 45 아래면 둥지 물을 분당 3까지 몸으로 끌어와 55까지 채운다. 물은 둥지에서 몸으로 옮겨질 뿐이라 총량은 그대로다.
  - 기본 기후(비가 잦음)에서는 비가 자주 다시 채워서 엔진 측정(2시드·6게임일) 동안 둥지가 '마른 둥지' 그림까지 내려가지는 않았다. 맑은 날이 사흘쯤 이어지면 마른다.
- 저장 스키마·규칙 식별자 불변. 버전 0.6.35 / versionCode 52.
