# APK0.6.24 · 첫 만남 카드: 진행 표시, 손님별 장면

2026-11-18. 사용자 제보(엘리시 맞이 카드 스크린샷): "맞이하는 카드의 캐릭터 창이 왜 이럼?", "어떤 조건을 충족해야 데려오기가 활성화되나, 지금 버전에서 가능한가".

- 진단: '함께 살기'는 정상 동작했다(엔진 시뮬레이션에서 카드를 연 지 149초에 활성화). 엘리시는 30초 적응 → 잎틈 살피기 5초 → 편안한 시간 120초를 채우면 된다. 다만 카드에 진행 표시가 없었다. 캐릭터는 42px로 작았다. 어느 손님이든 같은 소품(그늘 식물·샘물·낙엽)이 빈 바탕에 떠 있었고, 엘리시가 살피는 잎틈(이끼·바위틈)은 그림에 없었다.
- 진행 표시: `Recruitment.steps()`(읽기 전용)로 손님별 단계와 현재 값을 보여 준다. 예: 새 자리에 익숙해지기 30초, 잎틈 살피기, 편안하게 머물기 n/120초. 준비 전에는 "만남 화면을 열어 둔 동안만 시간이 흐르고, N분이 더 지나면 잠시 돌아가요" 안내도 보인다. 인사하기 버튼은 리들리, 물 있는 곳 알려주기 버튼은 보송일 때만 보인다.
- 장면(`drawVisit`): 월드와 같은 종이 바탕에 밝은 빈터를 깔고, 그 손님이 실제로 쓰는 소품만 그린다. 엘리시는 이끼·바위틈, 보송은 샘물, 엘레판은 그늘 식물·햇빛 자리, 주렁은 낙엽·마른 돌이다. 캐릭터는 이전의 약 2배로 키우고 접지 그림자와 앞뒤 순서를 넣었다.
- 제목 조사 "엘리시과 첫 만남" → "엘리시와 첫 만남".
- 영입 규칙·저장 스키마 불변. 버전 0.6.24 / versionCode 41.
- 함께 들어감(게임 미연결 시안): 톡토기 그림(`springtail-rest/jump.png`, SRS 화풍)과 개미굴 그림(`ant-nest.png`, "비스킷 같다"는 의견으로 흙 알갱이 둔덕으로 다시 그림).

검증: 자동 232/232(`recruit-info`에 진행 단계 검사 추가), DOM UI PASS. 카드 장면 렌더 `docs/qa-0.6.24/runtime/visit-cards.png`(`tools/visit-review.cjs`). Android 실기기 미검증.
