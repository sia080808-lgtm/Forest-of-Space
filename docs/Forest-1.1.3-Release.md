변경 내용(`skills.js` `LEVEL`, 레벨 3·6·9, 코로나·리들리는 Lv10도; Lv1은 1.1.0 값):
- **베이치 물 찾기:** 웅덩이 최대 물 8/10/12/14, Lv6 찾는 범위 0.6 → 0.75, Lv9 대기 600 → 480초.
- **코로나 낙엽 모으기(방식 변경):** 한 번에 모으는 낱잎 1/2/3/4/5장(Lv10). 근처 낙엽 더미로, 더미가 없으면 다른 낱잎 곁으로 쓸어 모아 더미를 만든다(Lv1도 2장 더미). Lv6 시작 기운 50% → 40%. 이전에는 한 칸의 낱잎을 장수 제한 없이 그 자리에서 더미로 쓸었다.
- **리들리 잎 털어 주기:** 털어 내는 해충 15/30/50/75/전부(Lv10), Lv6 범위 0.4 → 0.5, Lv9 대기 180 → 120초.
- **엘리시 촉촉한 잎 곁:** 범위 0.15/0.18/0.21/0.25, Lv6 잎 습도 +15 → +20, Lv9 천적 부르는 범위 0.25 → 0.3.
- **슈퍼범 빗물 나눔(`social.js`):** 한 번에 나누는 물 10/12/14/16, 둥지 최대 40 → 45(Lv6) → 50(Lv9).
- **엘레판 잎 우산(`weather-care.js`·`social.js`):** 비 막기 50/60/70/80%, 바람 막기 40/45/55/65%, 견디는 바람 70 → 75(Lv6) → 80(Lv9). Lv9도 쉼터(비 90%·바람 80%)보다 약하다.

- 저장 스키마·규칙 식별자 불변(코로나 스킬 기록에 `pile`·`anchor`, 슈퍼범 둥지 물 검증 상한 40 → 50). 버전 1.1.3 / versionCode 79.
