# APK1.1.0 · 친구 고유 스킬: 베이치 물 찾기, 코로나 낙엽 모으기, 리들리 잎 털어 주기, 엘리시 촉촉한 잎 곁

2026-11-21. SRS v2.36(`docs/Forest-Skills-SRS-v2.36.md`·`.pdf`). 사용자 요청: "케릭터별 고유 스킬들 … 잘 구현되어 있나?" → 점검(베이치·코로나는 고유 스킬 없음, 엘리시·리들리는 잘 안 보임) → "일단 이거 먼저 하자. 이게 시스템적 부분이라서" → 제안 → "베이치 같은 경우는 원래 물찾기 기능 있지 않았나"(통합 SRS v2.22의 보송 '마른 곳을 살피는 친구'·물 찾기·동료 안내) → "ㅇㅇ괜찮네 ㄱㄱ".

변경 내용(새 `skills.js`):
- **원칙:** 스킬마다 숲의 고민 하나(수분 비 온 뒤/가뭄 때, 비, 영양, 해충, 생태 손님). 조건이 맞으면 스스로 하고, 대가(기운)와 대기 시간이 있으며, 스킬 친구 자신이 목마르거나 배고프거나 지치거나 위험·밤잠·큰비면 하지 않는다. 물·낙엽은 옮겨질 뿐이다.
- **베이치 · 물 찾기:** 목마른 친구가 0.6 안에 있거나 샘터 물이 절반 아래이고 비가 오지 않으면, 흙 물이 1.5 이상 남은 자리(이끼·낙엽 자리 등)로 가서 6초 킁킁 살핀 뒤 그 흙 물의 70%(최대 8)로 웅덩이를 만든다(대기 600초, 웅덩이 최대 2개, 600초 뒤 남은 물은 흙으로). 근처 목마른 친구에게 웅덩이를 알려 준다. 숨은 물이 없으면 물이 실제로 있는 가장 가까운 곳(웅덩이·바위틈·물가·샘터)을 알려 주고 같이 걸어간다(대기 180초). 안내 받은 친구는 120초 동안 그곳만 고른다. 누구나 웅덩이에서 마실 수 있다(샘터와 같은 빠르기).
- **코로나 · 낙엽 모으기(긁어모으기):** 낮에 기운 50% 이상이면 더미 없는 칸에 흩어진 낱잎(2장 이상)의 가운데로 가서, 1장에 2초씩 늘어진 잎으로 쓸어 그 자리에 더미로 만든다(1장마다 기운 −0.5, 대기 180초). 처음 안(한 장씩 더미로 나르기)은 사용자 질문 "잎 하나씩만 긁어모으고 쿨타임 있음?" 뒤 "1번 ㄱㄱ"로 바꿨다.
- **리들리 · 잎 털어 주기:** 0.4 안의 친구에게 잎응애·솜깍지가 15 이상이면 곁으로 가서 20초 손으로 털어 15를 줄인다(그동안 그 친구는 머묾, 기운 −1, 대기 180초). 짐꾼개미 군락은 그대로.
- **엘리시 · 촉촉한 잎 곁:** 이끼 0.2 안에 있는 건강한 엘리시 곁(0.15) 친구들의 잎 습도 +15(잎응애 예방), 곁(0.25)의 천적 준비 시간 절반. 잎틈 정원·톡토기 보정은 그대로.
- **슈퍼범 빗물 나눔·엘레판 잎 우산:** 규칙 그대로, 횟수와 처음 기록만.
- **화면(렌더 전용):** 담채 웅덩이(물결), 엘리시 둘레 옅은 물안개, 코로나 좌우로 쓸기, 리들리 두 손 털기 동작, 베이치 킁킁. 카드 문구("숨은 물을 찾고 있어요", "베이치가 알려 준 물로 가고 있어요" 등). 친구 자세히 보기·도감에 '고유 스킬' 칸(이름·설명·오늘 횟수). 종마다 처음 스킬을 쓰면 발견 기록.
- 저장 스키마·규칙 식별자 불변(저장에 `skills`, 친구 `skill`·`skillRest`·`skillDay`·`skillHold`·`guideTo` 추가, 없으면 그대로 불러옴). 물 합계에 웅덩이 물을 더함. 버전 1.1.0 / versionCode 76.
