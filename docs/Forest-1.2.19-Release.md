# APK1.2.19 · 엘레판 잎 우산 아래 친구들이 쉼터 문을 막을 때 다른 친구가 매초 길을 다시 찾던 문제

2026-11-23. 1.2.18 측정에서 찾은 것 → 사용자 "우산문제도 pr".

- **원인(`objects.js`·`spatial.js`):** 비 오는 날 엘레판과 잎 우산 아래 친구가 쉼터 입구 앞에 서 있으면, 쉼터로 가던 다른 친구(슈퍼범·코로나 등)는 길을 찾지 못한다. 길을 못 찾으면 3초 동안 다시 찾지 않는 장치(1.1.4)가 있었지만, 쉼터 자리 목표가 조금씩 바뀌어 매번 '다른 목적지'로 보고 거의 매초 길을 처음부터 다시 찾았다(엔진에서 가장 무거운 계산, 한 번에 약 85~130ms). 또 꽉 찬 쉼터는 8초 뒤 포기하는데(0.8.3), 문이 막힌 경우는 '꽉 참'으로 세지 않아 자리를 다시 잡으며 수백 초 동안 쉼터만 바라보았다.
- **수정:**
  - 길을 못 찾은 기록은 목적지가 0.03 안에서 조금 바뀌어도 3초 동안 그대로 쓴다(제자리에 있을 때만).
  - 쉼터로 가는 친구가 길을 못 찾거나 돌아가는 중(쉼터 길 막힘)이면 꽉 찬 쉼터와 같이 센다. 8초 뒤 다른 곳(잎 그늘·바위틈·이끼 등)으로 가고, 5분 동안은 쉼터를 다시 고르지 않는다(꽉 찬 쉼터는 예전처럼 2분).
- 저장 스키마·규칙 식별자 불변. 버전 1.2.19 / versionCode 105.
