# APK0.8.7 · 산책지에서 가벼운 동작, 엘레판도 걷는 방향 보기

2026-11-20. 사용자 요청: "산책할 때 가벼운 모션들 먼저 업데이트 하자", "왼쪽으로 갈 땐 왼쪽 보고 오른쪽으로 갈 땐 오른쪽으로 보는 게 좋지 않음?".

변경 내용(렌더·카드 문구만, 상태·난수·저장 불변):
- **산책지 동작(`objects.js` `strollPose`, `scene.js`):** 산책지에 도착해 둘러보는 15~30초 동안 시간에 따라 바뀐다. 처음 4초는 두리번거리기(1.3초마다 좌우로 몸을 돌림) → 2.5초 고개를 숙여 풀 냄새 맡기(앞으로 기울이며 작게 끄덕임) → 다시 천천히 둘러보기 → 끝나기 7초 전부터 잠깐 앉아 쉬기 → 마지막 1초 일어서기. 카드 문구도 따라 바뀐다("숲 가장자리를 두리번거리고 있어요", "고개를 숙여 풀 냄새를 맡고 있어요", "숲 가장자리에 잠깐 앉아 쉬고 있어요"). 동작 줄이기에서는 몸을 돌리거나 기울이지 않는다.
- **걷는 방향 보기:** 다른 친구들은 이미 걷는 쪽을 보고 걸었다(엔진 확인: 리들리 1,500초에 방향 11번 바뀜). 엘레판만 늘 같은 쪽을 봤는데, 이제 잎 우산을 펴거나 접는 중이 아닐 때는 엘레판도 걷는 쪽(그리고 산책지에서 두리번거리는 쪽)을 본다. 잎 우산 아래 친구 자리가 엘레판 오른쪽에 맞춰져 있어서 우산을 펼 때는 그대로 둔다.
- 버전 0.8.7 / versionCode 65.

검증: 자동 327/327(`stroll` ST-05: 자세 순서·몸 돌림·카드 문구·상태 불변), DOM UI PASS. 화면 `docs/qa-0.8.7/runtime/stroll-poses.png`(`tools/stroll-pose-review.cjs`, 6종 × 두리번 좌·우·냄새 맡기·앉기·일어서기). Android 실기기 미검증.

함께 들어감(게임 미연결 시안): 산책에서 주워 오는 꾸미기 아이템 21종과 나뭇잎 바구니 3단계 그림(`assets/forest/forage`, `docs/qa-0.8.7-draft/forage-items.png`, `tools/draw-forage-items.cjs`).
