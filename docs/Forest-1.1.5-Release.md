# APK1.1.5 · 기운 높음·낮음 동작

2026-11-21. 사용자 요청(정해 둔 순서 1번): "1번 가자. 시안 그려줘" → "기분 낮음과 축 처짐이 좀 개선되었으면" → 한숨 표시 후보 중 "너꺼 a번 가자".

변경 내용(걷는 속도 말고는 렌더 전용, 저장 불변):
- **기운 높음(80% 이상, `rig.js` `vigor`):** 걸을 때 걸음마다 통통 튀고, 서 있을 때 3초에 한 번 제자리에서 폴짝. 웃는 눈, 머리 위로 반짝이 3개가 떠오른다.
- **기운 낮음(40% 아래):** 친구마다 자기 부위가 내려앉는다(리그 옵션 `droop`, 몸 전체를 누르지 않음).
  - 리들리: 머리 잎이 앞으로 흘러내려 눈 위를 덮고 손이 늘어짐
  - 엘리시: 몸이 가라앉고 두 갈래 생식엽이 양옆으로 처짐
  - 엘레판: 후드(앞잎)가 앞으로 숙여짐
  - 베이치: 머리 위 잎이 기울며 낮아짐, 팔이 늘어짐
  - 코로나: 늘어진 잎이 납작하게 퍼짐
  - 슈퍼범: 둥지잎이 내려앉고 양옆 잎이 아래로 벌어짐
  - 처진 눈, 머리 위 회색 그늘선. 서 있을 때는 4초마다 숨을 들이쉬며 조금 펴졌다가, 내쉬며 다시 처지고 입가에서 휘어지는 입김 한 줄기(한숨)가 나왔다 사라진다.
- **기운 바닥(15% 아래):** 가장 많이 처지고 좌우로 비틀, 식은땀 한 방울.
- 가만히 서 있기·걷기에서만 바뀐다. 쉬기·잠·들림·물 마시기·광합성·볕 쬐기·놀람 등 다른 동작은 그대로. 동작 줄이기에서는 처짐만 정지 화면으로 보이고 폴짝·비틀·한숨은 없다.
- **걷는 속도(`spatial.js` `gait`, 사용자 "속도 넣어"):** 기운 80% 이상이면 평소 걸음이 1.15배, 15% 아래면 느린 걸음이 0.45배(40% 아래 느린 걸음 0.6배는 이전부터 있음). 강풍·물 마시러 서두르기·과습 느린 걸음은 그대로.
- 저장 스키마·규칙 식별자 불변. 버전 1.1.5 / versionCode 81.

검증: `rig.test` 1.1.5 검사(6종 × 높음·낮음·바닥 그림이 바뀜, 쉬기에는 무시, 동작 줄이기 정지, 옵션 불변), `render`·`superbum`·`ellisii-legacy`·`package` 통과, 전체는 CI. 화면 `docs/qa-1.1.5/runtime/vigor.png`(`tools/vigor-review.cjs`, 실제 rig 렌더). Android 실기기 미검증.
