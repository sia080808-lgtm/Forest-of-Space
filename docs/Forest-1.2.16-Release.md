# APK1.2.16 · 리들리가 잎을 털어 주러 갔다가 바로 그만두기를 매초 되풀이하던 문제

2026-11-22. 사용자 질문 "리들리 톡톡톡 잎 털어주는 스킬 작동함?" → 측정(한 판에서 15번 출발, 2번만 털어 줌) → "원인 찾아서 고쳐".

- **원인(`skills.js` 잎 털어 주기):** 리들리가 털어 줄 친구 곁에 닿았을 때 그 친구가 물을 마시거나(샘터·이끼) 거름을 먹는 중이면, 기다리지 않고 바로 그만뒀다. 그만둘 때 대기 시간을 두지 않아 다음 초에 같은 친구를 다시 골라 출발하고, 닿자마자 또 그만두기를 친구가 다 마실 때까지 되풀이했다. 고를 때도 이미 마시거나 먹는 중인 친구를 골랐다. 측정(친구 6명, 시드 4개 × 2게임시간): 털어 준 8번에 그만둔 1,280번.
- **수정:** 마시거나 먹는 중인 친구는 처음부터 고르지 않는다. 가는 사이 그 친구가 마시기·먹기를 시작하면 곁에서 기다리다가(출발 뒤 30초까지) 끝나면 털어 주고, 그래도 안 되면 1분 쉬었다가 다시 고른다.
- 측정(같은 조건): 출발 8번, 털어 줌 7번(1번은 측정 끝까지 진행 중), 그만둔 0번. 털어 주는 횟수는 비슷하다(해충 양과 3분 대기가 정함). 카드에 "털어 주러 가고 있어요"가 깜빡이며 제자리에 서 있던 모습이 없어졌다.
- 저장 스키마·규칙 식별자 불변. 버전 1.2.16 / versionCode 102.

검증: `skills` 1.2.16 검사(마시는 친구는 고르지 않음, 가는 사이 마시기 시작하면 같은 털기를 이어 가며 기다렸다가 털어 줌 — 고치기 전 코드는 실패), `skills` 14개·`package` 통과. 전체는 CI. Android 실기기 미검증.
