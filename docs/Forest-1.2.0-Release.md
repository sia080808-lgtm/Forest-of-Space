# APK1.2.0 · 관리자 모드 패널, 새 설정 화면, 쉼터 끌어 옮기기·좌우 뒤집기

2026-11-21. 사용자 요청: "관리자창 디자인 … GUI 개선 필요함. 기능도 다 안들어가 있음 … 관리자 모드, 인게임모드 병렬로" → 시안 → "설정은 ㄹㅇ 유저가 쓰는 설정창으로 … GUI" → 시안 → "쉼터공간 빼버리자" → "쉼터 추가할 때 … 손가락으로 드래그 앤 드롭 … 좌우 방향 변경(미러)" → "PR까지만, 한꺼번에 업데이트".

변경 내용:
- **관리자 모드(`forest-app.js`·`admin.js`·`forest.css`·`index.html`):** 설정 > 더 보기 > '관리자 모드' 스위치(이 기기에만 저장). 켜면 월드 오른쪽 위에 공구 버튼이 생기고, 누르면 월드 아래쪽에 반투명 패널이 올라온다. 위쪽 월드는 계속 돌아가서 바꾼 결과를 바로 본다. 옛 '관리자 도구' 설정 페이지는 없앴다.
  - **시간 조절:** ⏸ 멈춤 · 1× · 4× · 16× 빨리 감기(한 화면에 최대 24초씩, 관리자 모드를 끄면 1×). 패널 맨 위에 계절·날짜·하루 시각·날씨·기후.
  - **친구 탭:** 월드에서 친구를 누르거나 이름 버튼을 누르면 고르고, 그 친구가 패널에 가리지 않게 화면을 옮긴다. 수분·영양(적정 띠 표시)·기운·레벨 슬라이더, 스킬 대기 없애기, 상태 바꾸기, 모두 적정하게·모두 스킬 대기 없애기·레벨 초기화(확인 창), 친구 부르기·바로 들이기·손님 돌려보내기.
  - **시간 탭:** 그 시각으로(앞으로만)·실제 진행·계절 첫날. **날씨 탭:** 날씨 7가지, **날씨 고정**(관리자 모드 동안 지금 날씨 유지), 기후 '계절마다 바뀜'과 네 기후 고정.
  - **사물 탭:** 샘터 가득·비우기, **햇살 바위 볕 가득·비우기**, 낙엽 10장·거름.
  - **생물 탭(새):** 잎응애·솜깍지·잎지기·점박이(고른 친구 잎에), 뿌리날파리·흙지기(낙엽 자리), 톡토기(낙엽 더미), 짐꾼개미(리들리 곁)를 바로 부른다. 출현 조건만 건너뛰고 그다음부터는 원래 규칙대로 움직인다. 해충은 두 종류까지(기존 규칙). 작은 이웃 돌려보내기.
  - **호수 탭:** 호수 생명 채우기, **여름 밤 반딧불**(여름 밤·맑음으로 옮기고 띄움). **해금 탭:** 호수 물가·쉼터 넓히기·사물 3단계(확인 창).
  - **보기 탭(새, 렌더 전용):** 걷는 길(점선), 할 일 글자, 고른 친구의 고유 스킬 범위, 쉼터 빈자리·샘터 물 양, 화면 속도(초당 장수·엔진 시간). 애니메이션·대표 장면 검수 화면도 여기서 연다.
  - 모든 변경은 지금처럼 저장 검사를 거치고 기록에 "관리자 · …"가 남는다. 물을 넣고 뺀 양은 물 원장 `ledger.admin`에 남는다.
- **설정 화면(`forest-app.js`·`forest.css`):** 화면 · 소리 · 숲의 기후 · 기록 · 더 보기 카드. 화면 밝기는 세 칸 버튼, 기후는 다섯 칸 카드(지금 계절·기후 표시), 줄마다 아이콘과 짧은 설명. '쉼터 공간' 줄은 뺐다(쉼터는 월드에서 쉼터를 눌러 다룬다). 지금 화면에서 '쉼터 공간'·'관리자 도구' 글자가 한 글자씩 세로로 깨지던 문제도 함께 사라졌다.
- **쉼터(`shelter.js`·`carry.js`·`scene.js`·`object-cards.js`):**
  - 추가·옮기기 때 미리보기 쉼터를 **손가락으로 끌어** 놓는다(화살표도 그대로). 쉼터 밖을 끌면 지금처럼 화면이 움직인다.
  - **좌우 뒤집기:** 추가·옮기기 화면의 '⇋ 좌우 뒤집기' 버튼, 쉼터 카드의 '좌우 뒤집기'(처음 쉼터도 제자리에서 뒤집기 가능). 그림뿐 아니라 벽·입구 판정도 함께 뒤집혀 친구가 그대로 드나든다. 저장에 쉼터 `flip`(없으면 원래 방향).
  - 고친 것: 쉼터 추가가 기본 쉼터 자리에서 시작했고, 겹침 검사가 기본 쉼터를 빼고 해서 겹쳐 놓을 수 있었다. 놓을 수 있는 범위가 맵 넓히기(0.7.0) 전 정원 크기에 묶여 기본 배치에선 빈자리가 거의 없었다 → 넓어진 숲 전체(호수 물 위 제외).
- **도감 그림 크기(`forest-app.js` `fitArt`, 사용자 "도감 케릭터 및 작은 친구들 크기 제각각인데 동일하게"):** 그림마다 빈 여백이 달라 크기가 들쭉날쭉했다. 그려진 부분만 잘라 같은 정사각형에 맞춰 보여 준다(식물 친구·작은 이웃·물가 이웃, 물가 이웃은 동작 그림 첫 칸). 화면 `docs/qa-1.2.0/runtime/guide-*.png`.
- **도감 탭 정리(`forest-app.js`·`forest.css`, 사용자 "생활기록은 없애고 … 환경 발견은 호수지역, 이끼의 숲 이런 새로운 지역 발견 도감"):** '생활 기록'·'환경 발견' 탭을 없애고 '지역 발견' 탭을 넣었다. 이끼의 숲(처음 숲)·동쪽 호수는 열린 지역이면 그림·설명·친구 수/만난 이웃 수를, 아직이면 빈칸과 단서를 보여 준다. 남쪽 바다·서쪽 산·북쪽 눈밭은 '아직 길이 이어지지 않았어요'. 발견 기록 자체(`discoveries`)는 저장에 그대로 남는다. 화면 `docs/qa-1.2.0/runtime/guide-regions*.png`.
- 저장 스키마·규칙 식별자 불변(쉼터 `flip` 추가, 없으면 그대로 불러옴). 버전 1.2.0 / versionCode 86.
