# APK0.8.4 · 겨울에 비가 오던 문제 바로잡기

2026-11-20. 사용자 질문 "날씨가 바뀌는 로직은 어케 됨. 아까부터 계속 흐림이라서" → 날씨 로직 설명과 함께 찾은 버그(겨울에 비) → "1번만 ㄱㄱ".

원인(`environment.js`): 숲이 오래 마르면(촉촉한·온화한 숲 600초, 그 밖 900초) 비를 한 번 내려 주는 장치(AC219-04)가 계절을 보지 않고 늘 비를 내렸다. 또 눈은 '물이 왔다'로 세지 않아서 겨울에는 이 장치가 10분마다 다시 작동했다. 측정(한 해, 시드 3개): 촉촉한 숲 겨울 시간의 14~20%, 마른 숲 겨울 11~13%가 비였다. 0.8.1 결정("겨울에는 비 대신 눈, 마른 숲 겨울은 비·눈 없음")과 어긋났다.

변경 내용:
- 겨울(계절 표의 눈 비율 0.5 이상)에는 이 장치가 눈을 내린다.
- 비·눈이 없는 계절(마른 숲 겨울)에는 작동하지 않는다. 기다리던 차례가 그런 계절에 오면 취소하고 평소처럼 날씨를 고른다.
- 눈이 온 것도 '물이 왔다'로 센다(비 + 눈 강수 0.35 이상 120초).
- 날씨가 바뀌는 간격(120~240초)·기후 비율·같은 날씨 두 번 연속 제한은 그대로다. 앱을 연 동안에만 날씨가 바뀌는 것도 그대로다.
- 저장 스키마·규칙 식별자 불변. 버전 0.8.4 / versionCode 62.

측정(엔진, 기후 C01·C04 × 시드 6개 × 한 해):
- 겨울 비: 가을에서 이어진 비가 겨울 처음 최대 265초 동안만 남고, 그 뒤로는 0.
- 겨울 친구 몸 물(시드 3개): 촉촉한 숲 평균 46.2 → 45.1(30 미만 3.8% → 5.6%), 마른 숲 48.0 → 44.5(최저 24.8, 30 미만 0% → 3.7%; 원래 결정대로 비·눈 없는 겨울), 온화한·서늘한 숲은 거의 같음.

검증: 자동 322/322(`seasons` SE-0.8.4: 촉촉한 숲 겨울은 눈, 마른 숲 겨울은 작동 안 함, 눈도 물로 셈), DOM UI PASS. Android 실기기 미검증.
