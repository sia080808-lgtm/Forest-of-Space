# APK1.0.2 · 작은 수정: 햇살 바위 사용, 시작한 일 5분 제한, 마른 숲 겨울 호수 화면, 기후 설명

2026-11-21. SRS v2.35 CW-13(`docs/Forest-Climate-Water-SRS-v2.35.md`). 사용자 요청: "작은 수정들 검토 먼저 ㄱㄱ", 마른 숲 겨울 화면 "B로 하되 시안 줘" → "저걸로 가자".

변경 내용:
- **햇살 바위 사용(`objects.js`):** 추위에 약한 친구가 추운 날 쉬거나 잘 자리를 고를 때 바위 점수를 고정 +45에서 "30 + 남은 볕의 절반"으로. 볕이 60 넘게 남으면 쉼터(+60)보다 바위를 먼저 고른다. 혹독한 겨울(볕 평균 85) 바위 사용 0~3% → 최대 17%.
- **시작한 일은 최대 5분(`objects.js`):** 1.0.1의 '시작한 일 끝까지'에 5분 제한을 뒀다. 마른 숲 겨울(기온 50)에 엘리시 잎에 솜깍지가 100까지 불어나 영양을 분당 2씩 빼앗는 동안, 거름 먹기(분당 0.8)가 목표 50에 닿지 못해 끝나지 않았고 잎 정돈을 한 번도 못 해 영양이 6.6까지 떨어졌다. 이제 5분 뒤 다시 고르면서 잎을 정돈한다(같은 구간 엘리시 영양 최저 6.6 → 37.7, 솜깍지 최대 100 → 15).
- **마른 숲 겨울 호수 화면(`scene.js`, 렌더 전용):** 얼지 않은 겨울에도 호수 둘레 땅까지 흰 눈을 덮고, 얼음 그림의 모양으로 잘라 낸 물만 남긴다. 숲 쪽 흰 땅과 호수 쪽 베이지 땅이 세로로 끊기던 문제. 물가 부들은 눈에 덮인다.
- **설정 기후 설명(`forest-app.js`):** '숲의 기후' 아래에 기후마다 한 줄 설명(촉촉한 숲 장마·눈, 온화한 숲 무난·추운 겨울, 서늘한 숲 안개·혹독한 겨울, 마른 숲 여름 가뭄·따뜻한 건기 겨울).
- 저장 스키마·규칙 식별자 불변. 버전 1.0.2 / versionCode 74.

측정(엔진, 친구 6명, 기후 고정 8게임시간): 촉촉한 숲 영양 적정 매시간 100%. 리들리 혼자 혹독한 겨울(시드 14) 기운 66 → 84, 수분 적정 86 → 100%.
