# APK0.7.0 · 넓은 숲(맵 1.5배), 고사리 액자, 친구 수십 명 길찾기 성능

2026-11-19. SRS v2.29(`docs/Forest-Map-Expansion-SRS-v2.29.md`·`.pdf`).

사용자 요청과 결정:
- "친구 수십명일 때를 대비하여 난 맵을 넓힐 거임"(가로·세로 1.5배, 바닥 그림만 이어 그리기)
- "군데군데 고사리화풍들이 있었으면"
- "화면 기본 디폴트 배율은 지금 설정된 화면 크기가 디폴트고 거기서 줌인 줌 아웃 가능. 그리고 기본 디폴트 배율에서 화면 드래그로 보기 가능"
- "기본배율에서 보이던 고사리 테두리 … 화면을 옮기더라도 계속 그림을 보는 것처럼"
- "1. 장식만, 2 늘림, 3. 0.7"
- 앞으로의 구상: 동쪽 호수·남쪽 바다·서쪽 산·북쪽 눈밭을 해금해 넓혀 간다.

변경 내용:
- **넓은 숲(`world.js` 새 파일):** 기존 정원 좌표(0~1)는 그대로 두고, 세계를 바깥으로 −0.25~1.25까지 넓혔다(한 변 1.5배, 면적 2.25배).
  - 기존 저장의 위치를 옮기지 않고, 친구 크기·거리 규칙도 바꾸지 않았다.
  - 세계 범위는 저장된 '열린 지역' 목록(`s.world.regions`)에서 계산한다. 0.7.0에는 숲 하나만 있다. 호수·바다·산·눈밭은 지역을 더하는 방식으로 이어 간다.
  - 정원 범위를 숫자로 적어 둔 곳(걷기, 꾸미기 배치, 쉼터, 저장 검증, 엘레판 잎 아래 자리, 입구 길)을 모두 이 범위로 바꿨다.
- **화면:**
  - 기본 배율은 지금과 같다.
  - 줌인은 3배까지, 줌아웃은 숲 전체가 보일 때까지 된다.
  - 기본 배율에서도 숲 가장자리까지 끌어 볼 수 있다.
  - 처음 화면은 기존 정원 한가운데다.
- **그림(원본 픽셀만, `tools/build-wide-garden.py`):**
  - 넓은 바닥: 종이 질감을 이어 붙였다.
  - 고사리 액자: 화면 가장자리에 고정되어 화면을 옮기거나 확대해도 늘 보인다. 바닥 위, 친구 아래에 그린다.
  - 새 땅의 고사리 덤불 11개: 장식만이고, 길을 막지 않는다.
  - 쉼터 그림: 가장자리를 투명하게 해 넓은 바닥에서 네모 경계가 보이지 않게 했다.
- **낙엽(넓이에 맞춰 늘림):** 6×5칸, 바닥 상한 90, 하루 45/68/90장이다.
  - 기존 저장은 불러올 때 낙엽 칸 번호를 다시 매긴다. 낙엽 수와 거름은 보존된다.
  - 오늘 낙하량 20/30/40은 45/68/90으로 바뀐다.
- **입구:** '입구에서 가는 길' 조건의 출발점을 숲 아래쪽 가운데로 옮겼다.
- **길찾기 성능:** 0.6.33에서 친구 수 제한을 없앤 뒤로 친구 20명에 틱당 141ms가 걸렸다. 0.7.0에서는 경로 결과가 같다.
  - 길목 근처 친구 10명까지만 경유점을 둔다.
  - A*를 쓴다.
  - 쉼터 모양과 세계 범위를 캐시한다.
  - Node 측정: 친구 30명 평균 8.2ms, 50명 24.2ms(`docs/qa-0.7.0/perf.md`).
- 저장 스키마 버전·규칙 식별자는 바꾸지 않았다. 저장에는 `world`, `objects.litter.grid`를 추가했다. 버전 0.7.0 / versionCode 56.

- 기존 테스트 6건은 새 숫자에 맞췄다: 카메라 3건, 낙엽 양 4건, 영입 길 1건, 12시간 물 보존 1건.
