# APK0.8.6 · 바위틈에 걸어 들어가기, 네모로 잘리던 친구 바로잡기

2026-11-20. 사용자 제보: "바위틈으로 들어갈 때 모션이 너무 이질적 … 엘리시가 들어갈 때 갑자기 휘리릭 달려가면서 바위틈 이미지에 네모 이미지가 생성되면서 엘리시가 들어감 … 다른 케릭터 들어갈 때도 그런가" → 분석 뒤 "ㄱㄱ".

원인(`scene.js`, 0.6.35의 '틈에 쏙 들어가기' 연출):
- **휘리릭:** 쉬는 자리(돌 앞)에서 틈 입구까지(약 0.04) 0.6초 만에, 쉬는 자세 그대로 미끄러지듯 옮겨 그렸다. 걷는 모션이 없어 순간 이동처럼 보였다. 쉬기를 마치면 한 프레임에 원래 자리로 튀어나왔다.
- **네모:** 틈에 앉은 친구의 발끝이 작은 돌 밑으로 삐져나오지 않게, 작은 돌과 그 아래 바닥 띠(바위틈 그림 타일 x 280~472, y 350~440)를 잘라 내고 친구를 그렸다. 이 잘라 내기가 들어가기 시작하는 순간부터 적용돼서, 아직 돌 앞에 서 있는 친구 몸의 오른쪽 아래가 직사각형으로 잘려 바닥이 비쳐 보였다. 작은 돌도 친구가 돌 앞에 있을 때부터 친구 위에 덮였다.
- 모든 친구가 같은 그리기 경로를 써서 리들리·엘레판·베이치·코로나도 똑같았다(`docs/qa-0.8.6/runtime/before-*.png`). 다 자란 슈퍼범은 바위틈에 들어가지 않는다.

변경 내용(렌더 전용, 상태·난수·저장 불변):
- 쉬는 자리에서 틈까지 친구가 쉬러 갈 때의 느린 걸음(엔진의 '천천히' 속도)으로 걸어 들어간다(약 1.7초, 걷기 모션, 틈 쪽을 바라봄). 쉬기를 마치면 같은 걸음으로 걸어 나온다. 동작 줄이기에서는 바로 자리를 바꾼다.
- 작은 돌은 친구의 발이 돌 아랫단보다 뒤로 들어갔을 때부터 친구 위에 덮인다.
- 돌 아래 바닥 띠를 잘라 내는 처리는 친구가 틈에 다 앉았을 때만 한다.
- 버전 0.8.6 / versionCode 64.

검증:
- 자동 326/326, DOM UI PASS. `rock-rider` 바위틈 검사 갱신(0.7초에는 아직 걸어 들어가는 중, 다 들어가면 틈 안, 과제가 끝나면 걸어 나와 원래 자리).
- 화면(`tools/crevice-entry-review.cjs`, scene.js + 계절 그림, 0~3.4초 프레임): 수정 전 엘리시·리들리·엘레판·코로나에 네모 잘림, 수정 후 엘리시·리들리·엘레판·베이치·코로나(봄)와 엘리시(겨울) 모두 걸어 들어가고 잘림 없음(`docs/qa-0.8.6/runtime`).
