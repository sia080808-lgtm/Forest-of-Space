# 구현·검수 상태 · 0.4.3 · 2026-11-15

이번 변경은 통합 명세 v2.8 개정 1의 REV28-04(그림자·젖음), REV28-05/06(샘터·유입·음향), VFX-01~08 보완이다. 디자인 상세와 실제 프레임은 [SURFACES_0_4_3.md](SURFACES_0_4_3.md)를 따른다. 나머지 구현 범위는 IMPLEMENTATION_STATUS_0_4_2.md를 유지한다.

## 적용 완료

- 일곱 겹 단색 젖음 타원을 제거. 지형별 고정 윤곽과 방사형 농담으로 흙에 스며드는 젖음 표시.
- 접지 그림자를 오브젝트 하단에 밀착. 큰 잎 밑 넓은 원판을 두 잎의 부드러운 그림자와 줄기 접지로 분리.
- 샘터는 실제 배경의 돌 안쪽 윤곽을 기준으로 마스킹. 깊이별 반투명 녹청색, 바닥 질감, 가는 반사광을 적용.
- 실제 유입이 있을 때만 뒤쪽 돌 틈에서 물줄기·빛의 이동·접촉 파문 표시. 잔량 0이면 수면 제거. 수면 내 빗방울/음수 파문과 조경/동작 줄이기 조건 적용.
- 물·성장·기분·자원·배치·기존 입력 엔진의 수치와 저장 규칙은 유지. engine.js의 수정은 앱 버전 문자열뿐이다.

- Node 57개 검사 통과: 기존 50개(젖음 렌더 검사 개정 포함) + 실제 Canvas 픽셀/상태 불변성 검사 7개.
- DOM 입력 검사 통과: 부팅, 줌/지도, 카드 이동/직접 들기, 취소·저장 실패, 설정, 꾸미기, 잠금/복귀.
- 실제 scene.js/원본 이미지로 전체 화면, 확대, 밤·비, 마른/젖은 땅, 잔량/유입/동작 줄이기 상태를 렌더링해 확인.
- APK 직접 빌드·v3 서명·zipalign 검증 통과. 0.4.2와 인증서 일치. 패키지 com.ridleydesk.mobile, versionCode 8. 번들 웹 파일 36개 전부 소스 일치.
