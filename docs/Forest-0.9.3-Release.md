# APK0.9.3 · 호수 이벤트 4개와 친구별 반응, 비 오는 호수 물결, 베이치·코로나 새 얼굴

2026-11-20. SRS v2.33 초안 LK-07. 사용자 요청: "이벤트 4개 ㄱㄱ", 친구마다 다른 반응("다른 방향"), "비 올 때 호수에도 빗방울 파형 적용", 베이치·코로나 얼굴 다시 그리기 → "ㄱㄱ".

변경 내용:
- **개구리 깜짝(`world.js` `fxStep`):** 여름에 개구리 곁(0.12 안)으로 친구가 다가오면 개구리가 물로 퐁 뛰어들고(물보라), 친구가 깜짝 놀란다. 같은 친구는 하루 한 번. 안내 "(이름) · 개구리가 퐁 뛰어들어 깜짝 놀랐어요".
- **잠자리 날개돋이:** 잠자리 애벌레는 이제 아침(하루의 처음 400초)에만 날아오른다. 그때 부들 곁(0.3 안)에 있던 친구들이 멈춰 바라보고 기분이 4 오른다. 처음 보면 발견 기록 "잠자리 날개돋이를 지켜보았어요".
- **여름밤 반딧불:** 맑거나 흐리고 바람이 약한 여름밤의 절반쯤 물가 위로 반딧불이 천천히 떠다닌다(화면 조명 뒤에 그려 밤에 빛남). 그날 밤 물가 쪽(x 1.0 넘는 곳)에 있던 친구들이 한 번 올려다보고 기분이 3 오른다. 처음 보면 발견 기록.
- **겨울 얼음 놀이:** 겨울에 언 호수 위를 걸을 수 있다. 겨울 산책의 약 30%가 얼음 위로 간다. 얼음 위에서는 기분이 분당 0.5씩 80까지 오르고, 걷다가 가끔 미끄러진다(렌더 전용). 봄이 되면 물 위에 남은 친구는 물가로 걸어 나온다.
- **친구별 반응(`scene.js`, 렌더 전용):** 놀람·미끄러짐 동작이 친구마다 다르다.
  - 리들리: 뒤로 폴짝 물러나며 젖힘 / 크게 휘청
  - 엘리시: 움찔 움츠림 / 작은 발로 종종걸음
  - 엘레판: 후드를 덮으며 웅크림 / 무거워서 살짝만 기우뚱
  - 베이치: 두 손을 머리 위로 올리며 폴짝 / 팔을 벌려 미끄럼
  - 코로나: 늘어진 잎째 출렁 / 낮게 엎드려 미끄러짐
  - 슈퍼범: 폴짝 뛰며 둥지 물이 넘침 / 좌우로 기우뚱하며 물방울
  - 바라보기(잠자리·반딧불)는 모두 살짝 고개를 들고 웃는다.
- **비 오는 호수 물결:** 비가 오면 호수 물 위에 빗방울 동그라미가 퍼진다(빗줄기 세기만큼, 얼음 위에는 없음).
- **베이치 얼굴(`species-rig.js`):** 사용자 그림대로 몸 가운데에 동그란 흰 눈과 작은 입. 웃을 때는 입이 없고, 화날 때(슬픔 자리) -_-, 집중할 때 눈이 작아진다.
- **코로나 얼굴:** 사용자가 고른 짧은 세로 눈과 옅은 일자 입이 기본. 살짝 웃음(입 없음), -_-, 놀람, 집중, 졸림을 같은 얇은 선으로 그린다.
- 저장 스키마·규칙 식별자 불변(저장에 `world.lake.fx`, 개구리 `dive` 추가, 없으면 그대로 불러옴). 버전 0.9.3 / versionCode 69.
