# APK0.8.5 · 빈 땅 산책, 숲 전체에 내리는 눈·바람 잎, 고사리 액자 켜기/끄기

2026-11-20. 사용자 요청: 다음 업데이트 후보 중 "1번 ㄱㄱ"(빈 땅 산책). 작업 중 추가 요청: "나뭇잎같은 거 떨어지는 것도 지금 전체 맵만큼 범위 넓혀", "맵 전체에 곤충들 뜰 수 있는 가능성 영역확장", "하는 김에 고사리 프레임 적용 온 오프 기능 추가".

변경 내용:
- **빈 땅 산책(`objects.js`·`engine.js`):** 급한 필요가 없고 밤·비가 아닐 때, 자유 행동을 고르는 순간 30% 확률로 친구가 넓은 숲의 빈 땅(0.7.0에 넓힌 바깥 둘레, 지금 자리에서 0.25 이상 떨어진 걸을 수 있는 곳)으로 산책을 간다. 도착하면 15~30초 둘러보고 다시 행동을 고른다. 목마름·배고픔·밤·비·위험이 생기면 바로 산책을 그만둔다. 자원을 쓰거나 만들지 않는다. 카드 문구는 "숲 가장자리로 산책 가고 있어요" / "숲 가장자리를 천천히 둘러보고 있어요"다.
- **같이 고친 것:** 자유 행동이 끝난 순간에는 머리 정돈이 거의 고려되지 않았다(끝난 과제가 남아 있어서). 이제 끝난 자유 행동 다음에 머리 정돈·산책을 고를 수 있다. 이미 머물던 자리(예: 그냥 들른 쉼터)에서 큰비가 오면, 자리는 그대로 두고 이유를 '비 피하기'로 바꾼다.
- **눈·바람 잎·안개(`world-effects.js`·`scene.js`):** 예전 정원(0~1) 크기 안에만 그려지던 눈송이·바람에 날리는 잎·안개를 넓은 숲 전체에 그린다. 개수도 넓이(2.25배)에 맞춰 늘려 밀도를 같게 했다. 가을에 천천히 떨어지는 잎도 넓이에 맞춰 늘었다(4장 → 9장). 봄 꽃잎과 비바람 잎은 원래 화면 전체에 그려진다. 게임의 실제 낙엽(낙엽 칸 6×5)은 0.7.0부터 숲 전체에 떨어진다.
- **곤충이 나타나는 곳:** 출현 규칙에 정원 범위 제한은 없고, 숙주(낙엽 더미·친구·바위 등)를 따라 나타난다. 낙엽 더미의 이웃(뿌리날파리·흙지기·톡토기)은 이미 숲 전체에 나타났다. 친구 잎에 붙는 이웃(솜깍지·잎응애·점박이·잎지기)은 친구가 가운데에만 있어서 바깥에 거의 없었는데, 산책으로 친구가 바깥에 나가면서 함께 늘었다.
- **고사리 액자 켜기/끄기(`forest-app.js`·`scene.js`·`engine.js`):** 설정 '표시와 움직임'에 '고사리 액자' 스위치를 넣었다. 기본은 켜짐이고, 예전 저장도 켜진 채로 불러온다.
- 저장 스키마·규칙 식별자 불변(저장에 `p.stroll`, `settings.showFrame` 추가, 없으면 그대로 불러옴). 버전 0.8.5 / versionCode 63.
