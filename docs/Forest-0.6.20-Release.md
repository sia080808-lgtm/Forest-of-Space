# APK0.6.20 · 생태계 v2.24 1단계: 낙엽 구역

2026-11-18. 이슈 #15 패치 5. 사용자 결정에 따라 자연 낙하는 바닥 낙엽 L만 보고 판정하고, 기존 저장의 L70은 섹터 더미로 실제로 옮긴다. 설계안은 사용자 "ㄱㄱ"로 승인되었다. 규칙 전문은 `docs/Forest-Ecosystem-SRS-v2.24-L1.md`.

- 낙하: 월드를 4×3, 12개 섹터로 나눈다. 평균 60초에 한 장(레벨 1 하루 20장)씩 확률로 떨어지며, 날씨·바람 배율 F는 최대 2이고 바람이 불어 가는 쪽 섹터는 가중치 2다. 독립 난수 `rng.litter`를 쓴다.
- 상한: 바닥 낙엽(낱잎+더미+운반)은 40, 섹터당 12. 영양 U는 낙하를 막지 않는다. U가 레벨 용량(100/150/200)을 넘으면 넘는 분해량은 흙으로 스며든 유출(`ledger.soil`)로 기록한다.
- 더미: 한 섹터에 낱잎 5장이 모이면 더미가 된다. 분해는 더미와 기존 낙엽 자리에서만 일어나고 낱잎은 분해되지 않는다. 더미의 물기는 가장 가까운 지형을 따른다. 강풍(60 이상)에는 낱잎이 이웃 섹터로 날아가며 맵 밖으로 사라지지 않는다.
- 이용: 낙엽 놀이와 영양 흡수는 실제 더미(가까운 2곳)나 기존 낙엽 자리에서 한다. 들고 간 잎은 같은 더미로 돌아간다. 더미를 누르면 정보 카드가 열린다.
- 새 게임: 낱잎 3장 + 기존 자리 U10으로 시작한다(이전 70/30). 기존 저장: L을 가까운 섹터부터 더미 3개(각 12)로 한 번 옮기고, 남은 L과 U는 기존 자리(거름 자리)에 둔다. 합계는 보존된다.
- 화면: 낱잎과 더미(잎을 낮게 쌓은 모양 + 거름 점), 거름 자리의 바닥 표시. 낙엽 자리·더미 카드를 바닥 낙엽 40 기준으로 바꿨다.
- 저장 스키마 버전 불변(`objects.litter` 추가, 처음 불러올 때 한 번 이전). 버전 0.6.20 / versionCode 37.

검증: 자동 227/227(`litter-sectors` 7개 포함), DOM UI PASS. 기존 테스트 4개 파일은 새 규칙에 맞게 갱신했다.
- `tools/litter-review.cjs` 결과: 새 게임 8시드 3게임일 동안 낙하 54~60장, 첫 더미 687~1,370초, 보존식 오차 0. 기존 저장 8시드는 첫 낙하 9~36초, 합계 100 보존.
- 렌더 `docs/qa-0.6.20/runtime`.
- 성능(Node 1명): 틱당 1.77ms에서 2.18ms로 늘었다(행동 선택의 더미 후보 길찾기).
