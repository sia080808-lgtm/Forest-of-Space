# APK0.9.2 · 물가 이웃: 소금쟁이·물달팽이·개구리(알→올챙이→개구리)·잠자리(애벌레→잠자리)·물방개·송사리·장구벌레

2026-11-20. SRS v2.33 초안 LK-05. 사용자 요청: "물가 이웃 ㄱㄱ" → 시안 조트로프 확인·수정(개구리 뛰기, 장구벌레 꼬리, 잠자리 애벌레 다리 여섯 개 함께 위아래, 물달팽이 몸 늘었다 줄었다) → "ㄱㄱ게임에 넣어줘".

변경 내용:
- **물가 이웃(`world.js` `lifeStep`):** 물가가 열린 뒤 60초마다 확인한다(독립 난수 `rng.lake`, 저장 `world.lake.life`).
  - 봄: 물가 가까운 물에 개구리알 → 600초 뒤 올챙이(4마리) → 1,800초 뒤 개구리. 개구리는 수련 잎 위나 물가에 앉는다("올챙이가 개구리가 되었어요").
  - 늦봄~가을: 소금쟁이(최대 3), 물달팽이(최대 2). 물달팽이는 시든 수련에 다가가 먹는다(수련이 사라짐).
  - 여름: 송사리 떼(최대 2), 물방개(최대 1, 가끔 올챙이를 먹음), 부들 줄기의 잠자리 애벌레 → 900초 뒤 잠자리("잠자리가 날개를 말리고 날아올랐어요"), 잔잔하고 따뜻한 물의 장구벌레(해충, 최대 4).
  - 송사리·잠자리·개구리가 장구벌레를 먹는다. 장구벌레 곁(0.12 안)에 선 친구는 성가셔서 기분이 분당 0.5 떨어진다.
  - 가을 둘째 날부터 여름 이웃이 줄고, 겨울에는 얼음 아래로 모두 사라진다.
- **화면(`scene.js`, 렌더 전용):** 시안의 6칸 동작 그림을 그대로 돌린다. 소금쟁이는 미끄러지듯 맴돌고, 송사리 떼·올챙이는 둥글게 헤엄치고, 개구리는 9초에 한 번 폴짝, 잠자리는 물가 위를 8자로 난다. 큰비·강풍에는 소금쟁이·잠자리가 숨고, 잠자리는 밤에 쉰다. 동작 줄이기에서는 멈춘다.
- **개구리 헤엄(사용자 "개구리 모션 물에서 헤엄치는 것도"):** 24초에 한 번 앉아 있다가 물로 폴짝 뛰어들어 뒷다리를 접었다 펴며 둥글게 헤엄친 뒤 돌아와 다시 앉는다(헤엄 6칸 그림 `life-frogswim.png`).
- **그림(`tools/draw-lake-life.py`):** 숲 이웃 화풍(수채, 따뜻한 갈색 윤곽) 10가지, 개구리알만 한 장 그림이고 나머지는 6칸.
- 저장 스키마·규칙 식별자 불변. 버전 0.9.2 / versionCode 68.
