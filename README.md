2026-11-18. 사용자 결정: "두리 빼자. 그 자리를 엘리시로 대체." 두리(P. bifurcatum)는 SRS v2.22에 첫 손님으로 정의돼 있었으나 전용 승인 시안이 없었다(리들리 몸통에 분기잎만 얹은 형태).

- 영입: `recruitment.js`의 `retired=['duri']`. 두리는 방문 후보·친구들 화면 영입 목록에서 빠진다. 도감에는 이미 함께 사는 두리가 있을 때만 보인다.

- 기존 저장: 입구에서 기다리던 두리 손님이나 대기열의 두리는 엘리시 방문으로 바뀐다(엘리시가 아직 없을 때). '먼저 기다리기'가 두리였다면 해제한다. 이미 함께 사는 두리는 그대로 남는다(삭제·변환 없음, 리그·초상화 유지).

- 수정: `MainActivity.java`의 람다·메서드 참조 10곳을 같은 동작의 익명 클래스(Runnable·ValueCallback·OnApplyWindowInsetsListener·FilenameFilter·Comparator)로 교체. 웹 게임·에셋·저장 형식·저장 경로 불변. 시작 단계에서 종료되어 저장 데이터는 손상되지 않았을 것으로 판단.
- 재발 방지: `tests/forest/android-shell-dex.test.cjs`(셸 소스에 람다/메서드 참조 금지), `tools/build_apk_alt.sh`(대체 빌드 도구 사용 시 dex에 `LambdaMetafactory`가 있으면 빌드 실패).
- 버전 0.6.13 / versionCode 30. 0.6.12(29)를 설치한 기기와 0.6.11(28) 기기 모두 위에 업데이트 가능(같은 키 서명 시).

## APK0.6.5 쉼터 앞 경계 가림 수정

쉼터 앞 바닥/입장 경계는 모든 캐릭터 아래에 그린다. 이동 예약만으로 앞테두리를 캐릭터 위에 다시 그리지 않는다. 실제 내부 발 위치와 entering/restingInside/exiting 상태가 함께 맞을 때만 물리 나무 아치 부분을 캐릭터 앞에 표시한다. 원본 이미지의 바닥·종이 영역은 전경 가림에 포함하지 않는다. 전경 그리기는 해당 캐릭터 윤곽 범위로 한정한다.
